### Native C23 laboratory

`labs/native/sysadmin-readonly-text` implements bounded, read-only inspection of explicit local text files. It demonstrates error classification, caller-owned results, refusal of incomplete/binary content and positive/negative deterministic CTest cases. It is not a duplicate production Umicom Framework filesystem subsystem.
