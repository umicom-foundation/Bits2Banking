## Native C23 laboratory

The `operational-resilience` project imports prior C23 libraries, extends them with an offline review policy, and tests blocked/missing/stale/restored-only outcomes. It does not create a Python/PowerShell script or administer a host. The educational C23 checks are not operational authorisation.

## Compatibility and exclusions

New files only, no deletions or shortened replacements. Umicom Framework, Applications, OS, Kernel and the previously supplied New Project Beginner Guide are not modified. Windows UCRT64 validation and the complete MkDocs strict build require user-host verification. Use the build/test/Git guide before committing.
