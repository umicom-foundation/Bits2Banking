# Mobile application development

Choose one route and follow its lessons in order. Each route begins with installing its tools, creating a practice project and running the generated application before making changes.

1. [Android Development](learning-android/index.md): Kotlin, an Android application and screen state.
2. [Learning Flutter](learning-flutter/index.md): Dart, widgets, state and interaction tests.

[Learning Kotlin](../02-programming/learning-kotlin/index.md) explains values and functions separately. Consult it as needed; its completion is not required before opening either mobile course. [Terminal setup](../learning-c/terminal-lab.md) explains folders, commands and tool discovery. [Framework Development](../umicom-development/index.md) introduces shared services that future Umicom frontends can call.

The examples use small local counters to teach events. They do not yet implement a production mobile client, cloud synchronisation or a native Framework binding.
