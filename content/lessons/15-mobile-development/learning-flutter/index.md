# Learning Flutter

Create a small lesson counter using Dart and Flutter. Begin by running the generated project, then learn widgets, state, callbacks and automated interaction checks.

## Start here

No previous course is required. You may read without installing tools. To do the practical work: Install Flutter and a supported browser or device, then run flutter doctor and flutter devices. Create a project named lesson_counter. Lesson 1 explains the setup and lesson 2 repeats the commands needed to use the supplied example.

For a slower introduction to commands and files, use [the terminal setup lab](../../learning-c/terminal-lab.md). Return here afterwards; it is a reference, not another required course to finish first.

## Follow these lessons in order

1. [Install Flutter and run a first application](01-install-and-run.md)
2. [Build a counter and test its buttons](02-widgets-state-and-tests.md)
3. [Understand state, rebuilds and disposal](03-state-rebuild-and-disposal.md)
4. [Test an interface across rebuilds and restarts](04-test-widget-lifetime.md)

## What you will practise

Create and locate a source file, follow the build or run command, read the output, change one behaviour and check the result. Each lesson includes a setup recap and recovery steps. Use a separate practice directory so experiments do not overwrite the repository example.

## Continue after these lessons

Dart foundations, navigation, storage, accessible layouts and Framework service integration. These are planned topics; the two introductory lessons do not constitute a complete language or platform course.
