# Find a missing number and prove it

[Course contents](index.md) · [Previous lesson — Follow increases, decreases and grouping](03-signed-numbers-and-order.md) · [Next lesson — Make a function and read its graph](05-functions-tables-and-slopes.md)

## What you will learn

Use a letter for a missing number, then check the answer in the original equation.

## Read an equation

An **equation** says that two expressions have the same value. A letter such as x can stand for an unknown number. A correct change to both sides preserves equality.

## Work it through

The workshop pays a setup fee of 300 cents and 150 cents per badge. The total was 900 cents.

1. Let x stand for the number of badges. Write 300 + 150 × x = 900.
2. Subtract 300 from both sides. You get 150 × x = 600.
3. Divide both sides by 150. You get x = 4.
4. Put 4 into the original equation: 300 + 150 × 4 = 900. Also check that you can buy a whole number of badges.

If the bill was 950 cents, the algebra would give 4⅓ badges. This would tell you to check the bill or the price assumptions. A valid algebraic value can fail the situation’s rules.

## Try it and check

A setup fee of 120 cents and 180 cents per poster produce a 1020-cent bill. Find the number of posters. How would you spot a bill that cannot use whole posters?

**Check:** 1020 − 120 = 900; 900 ÷ 180 = 5. Check that 120 + 5 × 180 = 1020. A remainder after dividing the subtotal by the per-poster price flags a mismatch.

## Apply it to an Umicom project

In an Umicom Studio practice design, let a function accept setup cost, unit cost and bill. Write a test card for exact multiples and another for amounts with a remainder. The function should return a clear mismatch when the figures cannot represent whole items.
