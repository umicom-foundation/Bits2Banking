# Shell practice with Bash and PowerShell

You need to count approved entries in a short daily checklist. Work through that task by finding the file, filtering its lines and checking whether the shell completed the work. Each lesson shows both shells so you can use the one you have.

1. [Find and open a file whose name has a space](01-navigate-and-quote.md).
2. [Filter text and compare it with a file object](02-compare-pipelines.md).
3. [Tell no match apart from a command error](03-check-command-status.md).

If this is your first time at a prompt, open the [Bash introduction](../06-bash.md) or [PowerShell introduction](../05-powershell.md) first. The local exercises use Bash with `grep` and `wc`, or PowerShell 7. Each shell sets up its own practice copy. Keep the same terminal open through the course.

Use the [browser shell practice](../../../practice/shell/index.md) to try its listed commands without setting up a terminal. It uses a separate sample workspace. Go to the local lessons for commands and pipeline behavior beyond the browser exercise.
