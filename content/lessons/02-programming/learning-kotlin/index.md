# Learning Kotlin

Write and check a small lesson-progress program. Start with installing a JDK and the Kotlin compiler, then create a file, compile it and explain its values and functions.

## Start here

No previous course is required. You may read without installing tools. To do the practical work: Install a JDK and Kotlin command-line compiler; confirm java -version and kotlinc -version in a new terminal. Choose an empty practice folder. Lesson 1 explains every step and includes PowerShell and bash commands.

For a slower introduction to commands and files, use [the terminal setup lab](../../learning-c/terminal-lab.md). Return here afterwards; it is a reference, not another required course to finish first.

## Follow these lessons in order

1. [Install Kotlin and run a first program](01-tools-and-first-program.md)
2. [Calculate progress and check the result](02-values-functions-and-checks.md)
3. [Convert command-line text into checked values](03-convert-command-line-text.md)
4. [Test valid and invalid terminal input](04-test-valid-and-invalid-input.md)

## What you will practise

Create and locate a source file, follow the build or run command, read the output, change one behaviour and check the result. Each lesson includes a setup recap and recovery steps. Use a separate practice directory so experiments do not overwrite the repository example.

## Continue after these lessons

Decisions, repeated work, collections, nullable values and calling native services. These are planned topics; the two introductory lessons do not constitute a complete language or platform course.
