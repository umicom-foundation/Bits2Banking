# Lesson 158 — Stop a Unicode stream without inventing characters

**Bits to Banking · Umicom Foundation**  
**Author:** Sammy Hegab · **Implementation language:** C23

## Learning objectives

Understand the encoding and ownership invariant, follow a concrete example, identify the reusable Framework service and explain a safe failure outcome.

## 1. The engineering problem

A generative model can stop after any byte. It may end with a complete character, or it may stop while the first or second byte of a multi-byte character is still pending. A well-behaved UI must not silently claim the pending prefix is a complete UTF-8 string.

`UmiUtf8StreamFinish` checks that no incomplete scalar remains. If the stream contains only the initial `F0` byte of a four-byte emoji sequence, the call reports `UMI_STATUS_INVALID_STATE`. That is a validation result, not an instruction to emit fake text. The caller can preserve the original bytes for audit, report the truncated text to the user or apply a separately approved display policy.

Model generation cancellation and Unicode validation are also different actions. Destroying a stacked-generation session stops sampling; it does not automatically make the last partial UTF-8 prefix valid.

## 2. Use the existing Framework boundaries

The Framework-owned `UmiAiTrainingStackedGenerationSessionDestroy` cancels token generation. `UmiUtf8StreamReset` starts a fresh text-validation stream for another answer. The caller should keep those lifetimes distinct, because resetting one component must not alter the borrowed model, its checkpoint or an unrelated output.

Never treat `U+0000` as a C terminator just because it is valid UTF-8. Buffer capacity and reported byte count remain mandatory when handing the generated bytes to a GTK widget or to another Framework text service.

## Practice

**Question:** After receiving `F0 9F 92` without a fourth byte, should `Finish` succeed?

<details><summary>Reveal the worked answer</summary>

No. The stream still contains a three-byte prefix of a four-byte scalar and rejects finalisation as incomplete. No character is silently invented.
