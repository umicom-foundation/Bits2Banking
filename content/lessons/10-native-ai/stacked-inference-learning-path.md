# Stacked native inference — learning path

**Bits to Banking · Sammy Hegab · Umicom Foundation**

This study route begins with the already introduced multi-layer decoder and
proceeds to native C23 streaming, deterministic sampling, model identity,
held-out evaluation and reproducible evidence. Read each lesson in order;
the mathematical companion supplies worked examples when needed. The
implementation lives in Umicom Framework, not in these manuscripts.
