# Written lesson library

[Written courses in reading order](../start/written-courses.md) · [How the learning library is organised](../start/library-guide.md)

For a first visit, use [Your learning sequence](../start/learning-sequence.md). This library groups written chapters by subject so you can return to an explanation later. It is not one course to read from top to bottom.

## Subjects

- [Introduction to Computers](00-getting-started/index.md) — Begin here; no previous knowledge.

- [Learning C](learning-c/index.md) — Follow the introductory course order, then its optional systems studies.

- [Computer hardware and information](01-computers/index.md) — Further explanation after the first computer lessons.

- [Programming and command lines](02-programming/index.md) — Practise instructions and choose the command environment you use.

- [Native languages and memory](03-native-code/index.md) — Reference and further study after Learning C.

- [Web development](04-web/index.md) — Study HTML, then CSS, then JavaScript; PHP follows server requests.

- [Software engineering and build tools](05-engineering/index.md) — Use the introductory project first; return here for specialised build and diagnostics topics.

- [Developing with Umicom Framework](umicom-development/index.md) — Follow one project, then choose a focused source-study module.

- [Umicom products and system source](06-umicom/index.md) — Product introductions and advanced source walkthroughs.

- [Business and financial foundations](07-practical-domains/index.md) — Begin the financial route here before treasury or trading-system implementation.

- [System administration](08-system-administration/index.md) — After files, commands and operating-system basics.

- [Treasury management systems](09-treasury-tms-calypso/index.md) — After the business and financial foundations.

- [Mathematics for AI](11-maths-for-ai/index.md) — Mathematical preparation before model internals.

- [Language models and native AI](10-native-ai/index.md) — After mathematical and programming foundations.

- [Distributed learning](12-distributed-learning/index.md) — After learning how one model is trained.

- [AI research](13-ai-research/index.md) — Optional advanced reading after the model course.

- [Blockchain and ledgers](14-blockchain-ledgers/index.md) — Separate specialist reading after records and validation.

- [Learning C — earlier sequence](c-from-the-beginning/index.md) — Retained earlier material; new learners use Learning C above.

## Course and manuscript versions

[Courses](../courses/index.html) give the order, prerequisites and exercises. A manuscript is the Markdown text for a lesson; a browser lesson is its HTML presentation. Use the paired manuscript links where available. Books and teaching scripts can draw from these sources, but may add an introduction or spoken explanation appropriate to that medium.
