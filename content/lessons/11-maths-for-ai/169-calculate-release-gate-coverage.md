# Mathematics for AI — Unit 169: Calculate publication gate coverage

**Bits to Banking · Umicom Foundation**  
**Author:** Sammy Hegab · **Prerequisite:** Basic arithmetic and preceding course units.

## Learning outcome

Numbered course spans offer simple completeness invariants.

## Step-by-step worked calculation

A course range 281..296 inclusive has 296−281+1 = **16 lessons**. Each has one Markdown and one HTML companion, so there are **32 numbered artefacts**. If an audit finds 16 HTML and 15 Markdown files, companion completeness is 15/16 = **93.75%**. It must report the missing file rather than rounding 93.75% to a claimed full pass.

**Unit conventions.** Nanoseconds (ns), milliseconds (ms), bytes, MiB and token positions are not interchangeable. Unless otherwise stated, the displayed figures are illustrative computations rather than measured Umicom performance.
