# Build a weight-management companion with Umicom Framework

Build the native observation core for a weight-loss companion, then study desktop, web and mobile clients. The examples record synthetic observations; they do not prescribe targets, diets or treatments. The first practical client is a C console program. Platform interfaces, storage integration and deployment require their own qualification.
