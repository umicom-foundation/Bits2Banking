# Stage 6 glossary — remote administration from first principles

**Host:** Computer or virtual machine offering a service. **Client:** Program requesting the service. **Endpoint:** Address/protocol/port combination that receives network traffic. **Loopback:** Interface pointing to the same computer, such as IPv4 `127.0.0.1`. **Listener:** Process awaiting network connections. **SSH:** Encrypted protocol commonly used for remote administration and file transfer. **Host key:** Server-identity material checked by an SSH client. **Public key:** Key data that may be distributed to authorised access systems. **Private key:** Secret signing material that must not be published. **Passphrase:** Secret protecting stored private-key data. **Known hosts:** Client-side record of server identities observed and trusted. **Authentication:** Demonstration of identity credentials. **Authorisation:** Decision defining allowed activities. **Least privilege:** Restrict access to what a task requires. **Service identity:** Account or workload principal under which software runs.

**Firewall:** Policy mechanism controlling selected network flows. **Inbound rule:** Policy for arriving traffic. **Outbound rule:** Policy for departing traffic. **Allowlist:** Explicitly named permitted actors, paths, actions or addresses. **DNS:** Name-resolution infrastructure; it is not a source of user authentication. **Route:** Rule selecting the next hop toward an address. **TCP:** Ordered, reliable byte-stream protocol. **TLS:** Protocol providing authenticated encrypted transport when correctly verified. **SAN:** Subject Alternative Name; the names a certificate covers. **Certificate authority:** Trusted issuer within a particular validation context. **Expiry:** End of a certificate or approval validity window. **SFTP:** File-transfer protocol using SSH. **SHA-256:** Cryptographic digest for comparing observed file content, not proof of user authorisation.

**Uptime:** A process or service has remained available at a level being measured. **Readiness:** The service is prepared to perform a particular operation. **Business correctness:** The operation produced its intended controlled outcome. **Incident timeline:** Ordered and traceable observations about a problem. **Correlation ID:** Identifier linking logs and operations. **Redaction:** Removing sensitive data from a shared record. **Rollback:** Restore a previously accepted state after an unsuccessful change. **RESTORED_ONLY:** Classroom state indicating the previous release was restored, not that the new release passed. **REVIEWABLE:** Classroom state indicating all supplied fictional policy fields are present; no real approval has been granted.
