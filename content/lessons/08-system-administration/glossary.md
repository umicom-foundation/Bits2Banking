# Glossary — System Administration From Zero

Every term below is used somewhere in the course. Revisit the relevant chapter for examples.

| Term | Explanation |
|---|---|
| **Administrator** | A person/account granted elevated management rights. |
| **Application** | Program serving a particular user or business purpose. |
| **Argument** | Value sent to a command. |
| **Backup** | A separate recoverable copy of information. |
| **Bash** | Shell commonly used on Linux. |
| **Branch** | Named reference to Git commit history. |
| **Build** | Process of producing executables and other artefacts from source. |
| **CLI** | Command-line interface used from a shell. |
| **CMake** | Native build-configuration generator. |
| **CMD** | Traditional Windows Command Prompt shell. |
| **Commit** | Git revision with an identity and history. |
| **Compiler** | Tool converting source code to machine code. |
| **Computer** | Hardware running an operating system and programs. |
| **CTest** | CMake test runner. |
| **Directory** | Folder containing file entries. |
| **DNS** | Name-to-network-address resolution. |
| **Elevation** | Running a process with increased privileges. |
| **Event** | Time-stamped record of an observed occurrence. |
| **Filesystem** | Rules and structures for storing files. |
| **Folder** | Directory; a named container for files. |
| **Framework** | Umicom shared reusable C23 platform. |
| **Git** | Distributed version control system. |
| **GitHub** | Hosting and collaboration service for Git repositories. |
| **GitHub CLI** | The `gh` command-line tool for GitHub. |
| **Hash** | Value computed from bytes, used to check content identity. |
| **Home** | Private folder associated with a user account. |
| **Host** | Computer or service participating in a network. |
| **HTTPS** | HTTP protected using TLS. |
| **IP address** | Network-layer address for an interface. |
| **Kernel** | Privileged part of an operating system. |
| **Linux distribution** | Packaged Linux operating system and tools. |
| **Log** | Recorded sequence of events or messages. |
| **Memory** | Temporary working storage used by running programs. |
| **Ninja** | Build executor commonly used with CMake. |
| **Operating system** | Software that manages hardware and processes. |
| **PATH** | Locations searched for executable commands. |
| **Permission** | Rule controlling access to data or operations. |
| **PowerShell** | Microsoft shell for interactive commands and automation. |
| **PowerShell 7** | Modern cross-platform PowerShell, generally launched with `pwsh`. |
| **Windows PowerShell** | Legacy Windows-included PowerShell 5.1. |
| **Windows Terminal** | Terminal host supporting multiple shells in tabs. |
| **Process** | Running instance of a program. |
| **Privilege** | Authority to perform protected operations. |
| **RAM** | Volatile memory used while programs run. |
| **Remote** | External Git repository location. |
| **Repository** | Project whose history is managed by Git. |
| **Restore** | Recover information from a saved copy. |
| **Revision** | Identified state of source, configuration or data. |
| **Service** | Background program providing a capability. |
| **Shell** | Program reading and executing commands. |
| **SSH** | Protocol for authenticated remote command access. |
| **Staging area** | Git index specifying content in the next commit. |
| **Submodule** | Git repository pinned by another repository. |
| **Terminal** | Application/window displaying a command-line session. |
| **Toolchain** | Set of compiler, linker and build tools. |
| **Working directory** | Location used for relative paths. |
| **Working tree** | Files currently checked out from a Git repository. |
| **winget** | Windows Package Manager command-line interface. |
| **Workspace** | Location containing project files and related work. |
