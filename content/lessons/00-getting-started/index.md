# Computing from the Beginning

No previous computing knowledge is expected. Read, listen, discuss or draw. Paper is enough for the first activities; device exercises are optional. You do not need an account or an installation.

1. [Start with curiosity, not experience](01-learning-at-your-own-pace.md) — Find your way through a lesson and explain one thing you have learned.
2. [What does a computer do?](02-input-instructions-and-results.md) — Separate information going in, instructions being followed, and a result coming out.
3. [Keep something you can find again](03-files-folders-and-saving.md) — Explain a file, a folder and a path, and distinguish editing from saving.
4. [What the computer keeps while it works](04-memory-storage-and-information.md) — Distinguish working memory from storage and explain a bit and a byte.
5. [Give instructions and check what happens](05-instructions-and-checking.md) — Use order, a choice and repetition to describe a task, then test an expectation.
6. [Read a command before running it](06-commands-without-mystery.md) — Recognise a command name, an argument, a prompt and a working folder.
7. [How applications, an OS and a kernel fit together](07-applications-os-and-kernel.md) — Explain the role of each layer and distinguish Umicom OS from Umicom Kernel.
8. [Choose your next learning route](08-choose-your-next-project.md) — Choose an achievable next step and recognise which knowledge a practical lab expects.
