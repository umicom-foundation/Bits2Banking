Learn service boundaries, Java adapter design and controlled integration exercises using Umicom treasury training material. Vendor-specific compilation requires the matching licensed SDK.

## How to study

Read one lesson, predict the example result, then attempt the exercise before opening its explained answer. Save optional practice programs in a folder you choose. Expected outputs describe what to check; they are not a record that a command has run on your computer.

## Planned continuation

Next modules: licensed environment inventory; SDK-version mapping; read-only trade queries; pagination; workflow actions; permissions; static data; market data; events and engines; message mapping; reconciliation; deployment and rollback; C integration behind a stable service contract.

These opening lessons do not claim a complete pricing engine, Bitcoin node, blockchain network, Linux distribution or production web server. Each course develops the relevant part in order.
