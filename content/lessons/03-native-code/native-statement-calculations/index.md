# Native Statement Calculations

Use Umicom C and C23 to verify a statement total and preserve the last accepted value when arithmetic fails.

## Before you start

You can save a text file and recognise an integer, an if statement and a function. The first program uses the Umicom C command; the second uses a host C23 compiler.

Use only the supplied training figures in these activities. The paper exercises work without an account.

## Lessons

1. [Calculate posted cents in Umicom C](01-calculate-posted-cents-in-umicom-c.md). Return the posted total for a three-entry training statement and explain which entry was excluded.
2. [Keep the last valid total in C23](02-keep-the-last-valid-total-in-c23.md). Check the range before adding to a total, and prove that failure preserves the previous value.

Calculate the same posted total in two native environments and explain the boundaries of each.
