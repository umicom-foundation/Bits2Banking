# Rust 2024 Keywords for Beginners

A keyword is a spelling the language grammar gives a particular job. Rust 2024 has 39 strict keywords, 14 reserved keywords and five words with special meanings in particular contexts.

Start with a short programme and use the index when you meet an unfamiliar word. You can read and trace every exercise without installing anything. Use a Rust 2024 compiler for the Rust practice and the named C tool for each companion example.
