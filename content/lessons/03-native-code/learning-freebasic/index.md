# Learning FreeBASIC


## Foundations and practice

Begin with a source file and a compiler, then learn values, control flow, records and a reviewed C boundary.

Read without tools. Practical work needs a supported FreeBASIC compiler, a text editor and terminal; the C boundary additionally needs a compatible C toolchain.
