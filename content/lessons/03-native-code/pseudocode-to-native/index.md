# Run pseudocode with Umicom C

A rule describes what to do with an input. Pseudocode writes that rule in short, ordered instructions a reader can follow. In this course you will read one rule on paper, run it in Umicom C's pseudocode profile and recognise it in C, D, BASIC and Assembly.

1. [Write one rule in five forms](01-one-rule-five-forms.md). Learn declarations, an `IF` condition, assignment and a result.
2. [Trace a rule from words to machine operations](02-from-words-to-machine-operations.md). Follow parsing and checked operations one source step at a time.

Start with [Programming across languages](../programming-across-languages/index.md) if this is your first time seeing a variable. Continue with [Build a graphics library](../graphics-from-scratch/index.md) to apply the rule to an image row or the [Bitcoin learning route](../../14-blockchain-ledgers/bitcoin-study-route/index.md) to separate validation from presentation.
