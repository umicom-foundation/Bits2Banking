# SQL Statement Reconciliation

Group posted movements with SQLite, then compare calculated totals with a statement supplied for review.

## Before you start

You recognise a table with columns and can start the SQLite command-line tool. Learning SQL introduces basic queries if you need it.

Use only the supplied training figures in these activities. The paper exercises work without an account.

## Lessons

1. [Summarise posted movements](01-summarise-posted-movements.md). Show a posted movement per account, including a training account that has no entries.
2. [Distinguish mismatches and missing totals](02-distinguish-mismatches-and-missing-totals.md). Classify matching, mismatching and missing statement totals with their original values visible.

Explain why a missing account, a zero movement and a mismatch require different handling.
