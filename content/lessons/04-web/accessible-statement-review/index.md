# Accessible Statement Review

Create a small HTML and CSS statement page and add a progressively enhanced, keyboard-operable filter.

## Before you start

You can save and open a local HTML file. The introductory HTML and CSS courses explain elements, attributes and selectors.

Use only the supplied training figures in these activities. The paper exercises work without an account.

## Lessons

1. [Build a readable statement table](01-build-a-readable-statement-table.md). Describe a statement as a captioned table with explicit column headers and inspect it in a narrow window.
2. [Filter posted rows with a status message](02-filter-posted-rows-with-a-status-message.md). Use a native checkbox to show only posted rows and announce the number of visible records.

Check the same synthetic entries with a keyboard, a narrow window and a script-disabled view.
