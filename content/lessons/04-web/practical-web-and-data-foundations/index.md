# Practical Web and Data Foundations

Follow one small statement through text, a web page, a type check, a local program, a spreadsheet and a database.

## Before you start

Start by reading the examples or tracing the rows on paper. Each lesson explains the optional local tools it uses. Use a practice folder and the fictional records in the lessons.

## Lessons

1. [Read a statement as JSON](01-read-a-statement-as-json.md). Read a small text record and identify each field, each entry and the group they belong to.
2. [Put the entries on a web page](02-put-rows-on-a-web-page.md). Use HTML for a labelled table and JavaScript to add a row through the browser's document objects.
3. [Check a record with TypeScript](03-check-a-record-with-typescript.md). Describe the values a statement may contain and predict a type error before running the program.
4. [Read a local statement with Node.js](04-read-the-file-with-node.md). Use Node.js to read a practice text file and check values before adding cents.
5. [Add posted cents in a spreadsheet](05-add-posted-cents-in-a-spreadsheet.md). Read a range of spreadsheet cells and use one formula to add only the posted amounts.
6. [Compare SQL database dialects](06-compare-sql-database-dialects.md). Use a common SQL query to total the statement, then identify two different ways a database can assign record IDs.

## Check your work

Check the same posted total in two places. Start at zero and add 2600 and −850. Record 1750 cents, which tools you used and why the last entry is left out.
