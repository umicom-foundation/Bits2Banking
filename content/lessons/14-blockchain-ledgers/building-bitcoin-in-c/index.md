# Building Bitcoin from Scratch Using Assembly and C

Build carefully bounded Bitcoin-format learning components in C and study where Assembly can help. Start offline, with explicit compatibility checks and no real keys or funds.

## How to study

Read one lesson, predict the example result, then attempt the exercise before opening its explained answer. Save optional practice programs in a folder you choose. Expected outputs describe what to check; they are not a record that a command has run on your computer.

## Planned continuation

Next modules: SHA-256 known-answer checks through Framework; complete block-header vectors; compact targets; Merkle trees; transaction parsing; scripts and signatures; UTXO validation; regtest messages; storage and reorganisation; measured Assembly optimisation. A compatible full node is a later research milestone, not delivered by this opening module.

These opening lessons do not claim a complete pricing engine, Bitcoin node, blockchain network, Linux distribution or production web server. Each course develops the relevant part in order.
