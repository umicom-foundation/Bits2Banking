Building a Web Server in C

Where this course fits: 2. Building Umicom applications. A later project: requests, handlers and lifetime after C and Framework foundations.

Before you begin: C variables, decisions, loops, functions, arrays, pointers and separate source files.

Beginner sequence · Return to this subject

Follow the existing Umicom Framework local-service example. Learn requests, routes, callbacks and ownership before extending a network-facing program.

Read on screen or trace values on paper. No installation is needed to read. Optional commands use the desktop C compiler and Framework environment explained in lesson 3. Work through Learning C first if functions, pointers or structures are unfamiliar. This course follows one local service; it does not qualify an Internet-facing deployment.

  1. Follow a browser request into C
  2. Connect routes to ordinary C functions
  3. Start and stop a local service safely
  4. Recognise complete requests and honest results
