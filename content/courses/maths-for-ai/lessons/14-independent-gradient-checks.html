FOUNDATION MATHEMATICS · UNIT 14 OF 15

Verify gradients independently

Use two nearby loss measurements to check an automatic gradient and one SGD weight update.

No previous AI or calculus is required. Every symbol is defined where it first appears. If a step is unfamiliar, open the formula dictionary, practise the earlier unit, then return to this page.

1. Why check the training tape with a different method?

A developer might accidentally use an incorrect matrix orientation, forget to scale a score, or propagate a gradient with the wrong sign. If we test code by repeating the same implementation, the mistake may occur in both places. A useful independent test takes a different route: calculate the loss numerically, change one weight slightly, and estimate how that loss changes.

Vocabulary: A loss is the number our small model tries to reduce. A weight is a numerical parameter. A gradient describes how loss changes when a weight changes. The terms do not require prior calculus knowledge.

2. First use one ordinary number

Choose the simple loss L(w)=(w−3)². Here L is the name of our loss function, w is a single changeable weight, the superscript ² means square, and the number 3 is our target. At w=2 the loss is (2−3)² = (−1)² = 1.

Central finite differenceestimatedGradient = (L(w+ε) − L(w−ε)) / (2ε)ε, pronounced epsilon, is a small positive test change. The numerator subtracts two measured losses. The denominator is the total distance between the two test points; the bars or subtraction are not hidden operations.

Let ε=0.1. At w+ε=2.1 the loss is (2.1−3)²=0.81. At w−ε=1.9 the loss is (1.9−3)²=1.21. Therefore the estimated gradient is (0.81−1.21)/(2×0.1) = −0.40/0.20 = −2.

If you know calculus, the exact derivative of this square is 2(w−3), also −2 at w=2. If not, the two measurements already explain the direction: making w a little larger lowered the loss, so the gradient is negative.

3. Connect the gradient to one update

Gradient descentnewWeight = oldWeight − learningRate × gradientlearningRate is a positive step size chosen by the trainer. The minus sign means we move opposite the direction in which loss increases. A negative gradient therefore makes the update increase the weight.

With a learning rate of 0.1, the new weight is 2−0.1×(−2)=2.2. Its loss is (2.2−3)²=0.64. This example's loss fell from 1 to 0.64. That is evidence only for this specific objective and update, not a claim about any model's real-world intelligence.

4. Recover a gradient from two weight snapshots

Observed update gradientobservedGradient = (oldWeight − newWeight) / learningRateIf an update follows the gradient-descent equation, rearranging it gives the gradient used. With 2, 2.2 and 0.1, the result is (2−2.2)/0.1 = −0.2/0.1 = −2.

In Umicom Framework, the qualification test measures the change in each of the 16 query weights and 16 key weights after one UmiAiTrainingSgdStepMany call. It compares the observed update with an independent finite-difference estimate calculated from the loss. This exercises far more than a single trigonometric formula: it checks projection, RoPE, causal attention, mean squared error and backpropagation together.

5. Understand the size of an error

Suppose the numerical reference is −2.0000 while the calculated gradient is −1.9998. Their absolute difference is |−1.9998−(−2)| = 0.0002. If the engineering acceptance threshold is 0.0005, the check passes. The threshold must be chosen before seeing the result and justified by floating-point precision and finite-difference step size.

6. Practice with another target

Let L(w)=(w−4)² at w=3. Use ε=0.05. Find the finite-difference gradient and calculate the new weight for learning rate 0.2.

Reveal the full calculation

Higher test value: w+ε=3.05, giving (3.05−4)²=0.9025. Lower value: 2.95, giving (2.95−4)²=1.1025. The estimated gradient is (0.9025−1.1025)/(0.10)=−2. Update: newWeight=3−0.2×(−2)=3.4. The new loss is (3.4−4)²=0.36, below the original loss of 1.
