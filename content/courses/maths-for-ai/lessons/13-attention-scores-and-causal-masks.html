FOUNDATION MATHEMATICS · UNIT 13 OF 15

From attention scores to a weighted answer

Learn how two tokens produce one meaningful weighted result, with every symbol explained.

No previous AI or calculus is required. Every symbol is defined where it first appears. If a step is unfamiliar, open the formula dictionary, practise the earlier unit, then return to this page.

1. Start with two short records

Imagine a tiny Umicom Notes assistant. It has read two tokens: one represents a note about a payment; the other represents a note about its status. Each token has a value, a small list of numbers holding information the assistant may use later. This is a mathematical illustration, not a trained language model.

TokenKey KValue V
First token[1, 0][2, 4]
Second token[0, 1][6, 8]

We are going to calculate an output for a query Q=[1,1] belonging to the second token. The word query means the numerical question: “Which stored information should influence this position?” The keys are numerical descriptions used to compare candidates. The values are the content we combine.

2. Calculate two dot products

Attention scorescoreᵢⱼ = (qᵢ · kⱼ) / √di identifies the query row. j identifies an earlier or current key row. The centred dot means multiply corresponding numbers and add them. d is the number of channels in a head; here d=2. The square root √d means the positive number which, multiplied by itself, equals d.

The second query [1,1] compared with the first key [1,0] gives 1×1 + 1×0 = 1. Compared with the second key [0,1] it gives 1×0 + 1×1 = 1. Dividing each by √2≈1.414 gives two equal scaled scores, approximately 0.707 and 0.707. The two matching scores are equal even before this scaling.

Maths Unit 3 explains a dot product from the beginning; Unit 2 explains variables and the square-root symbol.

3. Convert scores into weights

Softmaxweightⱼ = exp(scoreⱼ) / Σₖ exp(scoreₖ)exp(x) means the exponential function applied to x; it always produces a positive number. Σ instructs us to add the values for all allowed keys. Each weight is the key's positive amount divided by the sum of all positive amounts.

Our two scores are equal, so the exponential function produces two equal positive numbers. Each gets half of their combined total: 0.5 and 0.5. We do not need to approximate exp(0.707) to see this. Open Maths Unit 5 for more about exponentials, probabilities and numerical stability.

4. Combine the two values

Weighted averageoutput = 0.5 × [2,4] + 0.5 × [6,8] = [4,6]Multiply each number in the first value vector by 0.5, do the same for the second vector, then add the matching positions. First output: 0.5×2 + 0.5×6 = 4. Second output: 0.5×4 + 0.5×8 = 6.

5. Understand the causal mask

A causal model must not use later tokens to predict an earlier token. Its first query can attend only to the first key and therefore returns the first value [2,4], not [4,6]. Its second query may use both keys and produces [4,6]. When testing a decoder, verify this directional restriction independently.

6. Practice, then check

If the two weights are still 0.5 and 0.5 but the value vectors become [10,2] and [4,6], what is the output?

Reveal the worked answer

First coordinate: 0.5×10 + 0.5×4 = 5+2 = 7. Second coordinate: 0.5×2 + 0.5×6 = 1+3 = 4. The answer is [7,4]. The weights determine how much each value contributes; they do not alter the values themselves.
