Attention, token positions and KV-cache work

How attention uses the mathematics together

Attention is a numerical method for choosing which available token representations to emphasise. Its three learned inputs are called query (Q), key (K), and value (V). You do not need to know programming to understand the arithmetic of a tiny example.

Query and key produce a score

Formulascore = (Q · K) ÷ √dQ · K is a dot product. d is the number of channels in one attention head, and √d scales the score so its size is better controlled.

Take Q=[1,0], K₁=[1,0] and K₂=[0,1], with d=2. The dot products are 1 and 0. Divide each by √2 ≈ 1.414 to get scores about 0.707 and 0.

Turn scores into attention weights

Softmax gives scores of 0.707 and 0 the approximate weights 0.670 and 0.330. The weights total 1 (rounding aside). Take values V₁=[10,0] and V₂=[0,20]. The weighted result is:

Worked result0.670 × [10,0] + 0.330 × [0,20] ≈ [6.70, 6.60]Multiply each value vector by its attention weight; then add matching coordinates.

Transformers perform this at many positions and usually across multiple attention heads. A causal mask prevents the current position from reading future tokens during ordinary left-to-right language modelling.

What the KV cache remembers

Instead of recalculating old keys and values for every newly generated token, a KV cache can retain valid representations. In an unpadded growing-prefix experiment, previously computed rows may be reused while their positions and context semantics remain valid. A cache is not a copy of the model or a guarantee that every change of context can reuse old hidden states.

The teaching measurement in our native Framework compares 96 computed rows in a full-context reference with 56 rows in an incremental example, avoiding 40 rows (about 41.7%). That is a workload comparison. Measure actual time separately and prove equal token outputs under the same positional policy.

Practice

A numerical experiment computes 100 token rows in a reference implementation and 75 using a cache. How many rows are avoided and what percentage of the reference is that?

Show the worked solution

Avoided rows = 100 − 75 = 25. Percentage avoided = (25 ÷ 100) × 100% = 25%.
