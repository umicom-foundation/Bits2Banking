Vectors, coordinates and dot products

Start with a plain-English idea, then a labelled formula, a worked example, and a solution you can reveal.

No mathematics qualification required. Read at your own pace. A symbol is explained the first time it appears; use the symbol guide whenever needed.

A vector is a list with a fixed order

An AI model cannot directly calculate with the sentence “help with a payment”. It works with a numeric representation. A vector is one small building block of that representation: an ordered list such as [1, 2]. In a document-retrieval system, numbers can encode learned properties of passages; they are not universal human-readable meanings.

Positions inside a vector

The vector v = [1, 2] contains two coordinates (sometimes called components): the first is 1 and the second is 2. Another vector w = [3, 4] also contains two. To add them, combine matching positions: v + w = [1+3, 2+4] = [4, 6].

The dot product

Formulav · w = v₁w₁ + v₂w₂Multiply the first pair; multiply the second pair; add the two results. The subscript ₁ means “first coordinate”.

Using v = [1, 2] and w = [3, 4]: (1 × 3) + (2 × 4) = 3 + 8 = 11.

Why is this useful? Transformer attention uses a dot product between a query and a key. Large positive scores can represent a strong numerical alignment, but the result depends on the learned vectors and scale; it is not automatically a factual judgment.

Length and dimensions

The vector [1, 2] has dimension 2, meaning two components. Its geometric length is √(1² + 2²) = √5 ≈ 2.236. “Length” can mean element count or geometric magnitude; the surrounding context tells you which meaning is intended.

Practice

A query vector is [2, 1] and a key vector is [3, −1]. Find their dot product.

Show the worked solution

(2 × 3) + (1 × −1) = 6 − 1 = 5. A negative coordinate contributes a negative product.
