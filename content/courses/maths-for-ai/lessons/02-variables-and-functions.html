Variables, expressions and functions

Start with a plain-English idea, then a labelled formula, a worked example, and a solution you can reveal.

No mathematics qualification required. Read at your own pace. A symbol is explained the first time it appears; use the symbol guide whenever needed.

A letter is a name for a number

When reading software, you already encounter variable names such as tokenCount. Mathematics often shortens such names to letters. In an expression, x is a placeholder for a number that can change; it is not a mysterious unknown object.

Replace the letter with a value

Formulaf(x) = 2x + 1“f of x” is the name of a rule. 2x means 2 multiplied by x; +1 means add one at the end.

Choose x = 3. First calculate 2 × 3 = 6, then 6 + 1 = 7. Therefore f(3) = 7. Change x to 5 and the same rule gives f(5) = 11. The rule has not changed; only its input has.

Maths and C23 describe the same calculation

float CalculateScaledScore(float input)
{
    return 2.0F * input + 1.0F;
}

Here input is the mathematical x. The return value is f(x). In C23, * is the multiplication operator; in maths it is often written as × or omitted between a number and a letter.

Powers, squares and a square root

A superscript ² means multiply a value by itself: 3² = 3 × 3 = 9. The square-root symbol √ asks which nonnegative value gives the original number when squared: √9 = 3. Attention uses √d as a scale factor, where d is the number of channels in a single head.

Where functions appear in AI

An LLM passes numbers through several functions: a projection converts a token representation into a query vector; a scoring rule compares query and key; a probability function turns scores into weights. Understanding functions as reusable transformations is enough to start.

Practice

Suppose a teaching model has the rule g(n) = 3n − 2. Find g(4) and explain each operation.

Show the worked solution

Replace n with 4: 3 × 4 − 2 = 12 − 2 = 10. The letter n stands for the chosen input.
