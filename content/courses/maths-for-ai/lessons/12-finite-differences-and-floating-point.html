FOUNDATION MATHEMATICS · UNIT 12 OF 12

Finite differences, numerical tolerance and fair tests

Understand and measure numerical agreement.

You can start here, whatever your background. Terms and symbols are defined beside the calculations. Open the formula guide or step into an earlier unit whenever needed.

1. How can we check a gradient independently?

A program may calculate a number quickly and still be wrong. To test automatic differentiation, we can calculate an approximate slope without using its gradient implementation. We evaluate the loss just above and just below the parameter and compare the two results.

Central finite differencegradient ≈ (L(w+ε) − L(w−ε)) / (2ε)L is the loss function. w is the parameter being tested. ε (epsilon) is one small positive change. “≈” means approximately equal. The numerator subtracts two observed losses; the denominator describes the distance between the two tested values.

2. Work through every number

Let L(w)=(w−2)² and test at w=1 using ε=0.01. The slightly larger parameter is 1.01; its loss is (1.01−2)² = (−0.99)² = 0.9801. The slightly smaller parameter is 0.99; its loss is (0.99−2)² = (−1.01)² = 1.0201.

Subtract: 0.9801−1.0201 = −0.0400. The distance between the two test points is 2×0.01=0.02. Divide: −0.0400/0.02 = −2. The exact analytical gradient is 2×(1−2)=−2. They agree here.

3. Why not use an infinitely tiny epsilon?

Computers store many fractional numbers approximately in finite memory. If epsilon becomes extremely small, the two losses can round to the same representable value even though the true mathematical results differ. Their subtraction may then produce zero. Conversely, a very large epsilon measures a broad interval and can miss the local slope. A useful epsilon balances both sources of error.

4. Exact agreement versus tolerance

Two mathematically equivalent calculations can produce slightly different floating-point values because they add and multiply numbers in different orders. A numerical test should specify a justified tolerance. For example, if a reference is 0.50000 and the implementation returns 0.50002, the absolute difference is 0.00002. With an agreed tolerance of 0.00005, this result passes; with 0.00001, it does not.

Absolute-error testabsoluteError = |actual − reference|The vertical bars mean the nonnegative magnitude of the difference. A test passes only when absoluteError is less than or equal to a justified allowed tolerance.

5. Measure the right thing

Do not confuse fewer computed token rows with less elapsed time. A cached decoder might avoid matrix work but incur memory-copy or synchronisation overhead. Likewise, a lower training loss on one short sample is not proof of strong generalisation or language understanding. Report separately: correctness tests, actual observed time, memory peaks and the particular learning objective.

/* Native C23 check, using standard-library floating-point maths. */
#include <math.h>
float actual = 0.50002F;
float reference = 0.50000F;
float tolerance = 0.00005F;
int agrees = isfinite(actual) &&
             fabsf(actual - reference) <= tolerance;

6. Practice and reveal

A test reports reference=0.75, actual=0.75008 and allowed tolerance=0.0001. Does it pass? What if the allowed tolerance is 0.00005 instead?

Show the worked solution

The absolute difference is |0.75008−0.75| = 0.00008. This is less than or equal to 0.0001, so it passes the first threshold. It exceeds 0.00005, so it fails the second. The tolerance must be chosen for the expected numerical method, not changed after seeing a test failure.
