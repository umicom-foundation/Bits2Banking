FOUNDATION MATHEMATICS · UNIT 15 OF 15

Repeatability, precision and trustworthy evidence

Understand exact repeats, acceptable numerical differences, memory accounting and honest limits.

No previous AI or calculus is required. Every symbol is defined where it first appears. If a step is unfamiliar, open the formula dictionary, practise the earlier unit, then return to this page.

1. A mathematical value and a computer value are not identical concepts

Mathematics describes ideal numbers. Computers store a finite number of bits; many decimal fractions cannot be represented exactly in binary floating point. This means two correct implementations may round at slightly different intermediate steps, especially if they use different compilers or CPU instructions.

For example, the decimal value 0.1 is represented approximately by ordinary IEEE-754 binary32. Repeating an operation many times may accumulate small rounding differences. That does not excuse any arbitrary error, but it explains why good numerical tests compare with a justified tolerance instead of insisting every cross-platform floating-point bit must match.

3. Relative and absolute tolerances

Combined tolerance|actual − reference| ≤ absTol + relTol × |reference|Vertical bars mean distance from zero, without the sign. absTol is the allowed fixed difference. relTol scales the allowed difference with the magnitude of the reference. The symbol ≤ means “less than or equal to”.

Take reference=0.010000 and actual=0.010002. The absolute difference is 0.000002. Choose absTol=0.000001 and relTol=0.001. The allowed difference is 0.000001+0.001×0.010000 = 0.000011. Because 0.000002≤0.000011, this example passes its declared tolerance.

Do not change tolerances merely to make a failing test pass. Study why the comparison differs and whether the application needs a tighter contract. For the 32 gradients in the native RoPE audit, the test declares its fixed bound beside the calculation.

4. Relative-position invariance in plain English

Rotary positional encoding attaches angle information to key and query vectors. If two positions are shifted forward by the same number of places, their difference remains unchanged. For example, positions 5 and 3 differ by 2. Positions 15 and 13 also differ by 2. Ideal RoPE query–key dot products depend on the difference between their positions, so their result should be the same. On finite computers, tiny differences are expected and checked with tolerance.

Equal shift property(5−3) = (15−13) = 2Both pairs are separated by two token positions. Changing both indices by +10 is not the same as changing only one; the latter changes the relative position and usually changes the attention score.

5. Repeating a test and checking memory

One passing run does not reveal every lifetime error. A test should create a tape, perform training, destroy the tape, and repeat. Sanitiser-enabled builds can detect some memory leaks and invalid accesses. Reported peakTapeBytes should also remain stable for repeated runs of the same graph shape, but a stable peak alone does not prove there are no leaks.

6. Practise reading evidence

A report gives reference loss 0.50, measured loss 0.5003, absTol=0.0001 and relTol=0.0002. Does the report pass? Should a smaller final loss be described as proof of a production LLM?

Reveal the explanation

The difference is |0.5003−0.50| = 0.0003. The allowed difference is 0.0001 + 0.0002×0.50 = 0.0002, so it fails. A smaller loss in a small training exercise is not proof of a production language model; it measures only the declared test objective.
