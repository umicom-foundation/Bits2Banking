Gradient descent and the learning rate

One small improvement at a time.

You can start here, whatever your background. Terms and symbols are defined beside the calculations. Open the formula guide or step into an earlier unit whenever needed.

1. Begin with an everyday goal

Imagine Umicom Studio has a numerical control that should display 3, but it currently displays 1. The difference is 2. A learning system uses a loss function to measure how far it is from the desired output. Training then changes a parameter to reduce that measured loss. A loss is just a number describing an error according to a particular definition; a smaller loss does not automatically mean a model is safe or useful.

For this first example, the single model parameter w is also its output. We want w to approach 3. Choose squared error so a mistake of 2 counts more strongly than a mistake of 1.

The loss — every symbol explainedL(w) = (w − 3)²L means “loss”. w is the parameter we may change. 3 is the desired value. The superscript ² means multiply the difference by itself. At w=1: (1−3)² = (−2)² = 4.

2. What is a gradient?

A gradient tells us how the loss changes locally when we change a parameter. For one parameter, it is an ordinary derivative. We can calculate it with a rule for squaring or estimate it with two nearby measurements (see Unit 12).

The slope of this particular lossdL/dw = 2(w − 3)Read dL/dw as “the rate of change of loss when w changes”. At w=1, this is 2×(1−3) = −4. The negative sign tells us increasing w initially decreases the loss.

3. Make one careful training update

The learning rate, written α (alpha), controls the size of a step. A negative gradient means a step upwards in the parameter value. A positive gradient means a step downwards. The update rule always subtracts the gradient multiplied by the learning rate; the sign handles the direction.

One stochastic-gradient-descent updatew(new) = w(old) − α × gradientα is a positive learning rate. With w=1, α=0.1 and gradient=−4, the new w is 1 − (0.1×−4) = 1.4.

Now recalculate the error with the new value: (1.4−3)² = 2.56. The loss fell from 4 to 2.56. We have evidence of improvement for this step, not a guarantee about every future step.

4. Repeat, then stop and verify

The gradient at w=1.4 becomes 2×(1.4−3)=−3.2. The second update is 1.4−0.1×(−3.2)=1.72. Its loss is (1.72−3)² = 1.6384. This demonstrates repeated improvement with a gentle learning rate. A very large learning rate may overshoot the best value; a very small one can make learning slow. The correct choice is a measurement problem.

5. Connect the mathematics to Umicom Framework

In the native C23 training tape, UmiAiTrainingBackward computes gradients and UmiAiTrainingSgdStepMany updates several trainable tensors together. The experiment in LLM Lesson 87 updates two 4×4 projection matrices instead of one scalar w. It follows the same principle.

/* Conceptual C23 arithmetic for one scalar; Framework owns real tape updates. */
float weight = 1.0F;
float learningRate = 0.1F;
float gradient = 2.0F * (weight - 3.0F);
weight = weight - learningRate * gradient; /* 1.4 */

6. Practice and reveal

A simple loss is L(w)=(w−4)². Start with w=2 and learning rate 0.25. What is the first gradient, updated w and new loss?

Show the worked solution

Gradient = 2×(2−4)=−4. Updated w = 2−0.25×(−4) = 3. New loss = (3−4)² = 1, down from 4. The sign of the gradient determines the movement.
