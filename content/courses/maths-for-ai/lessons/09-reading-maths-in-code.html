One statement from maths to C23

Formulay = 2x + 1Choose x=3: y=2×3+1=7.
float CalculateExample(float x)
{
    const float y = 2.0F * x + 1.0F;
    return y;
}

float stores a floating-point approximation, const prevents this local variable from being reassigned, * means multiply, and return sends the result back to its caller. One line of C23 implements the entire formula.

Check answers instead of merely trusting an implementation

Floating-point results may differ by small amounts because the computer has finite precision. A test should compare against an independently derived expected result with a justified tolerance; it should not simply compare a function against itself.

For example, a rotation by 90° should take [1,0] close to [0,1]. If a computed result is [0.00000004,0.99999994], that is often an acceptable numerical approximation; deciding the tolerance depends on the operation and accuracy requirements. Near-equality is not appropriate for account identifiers, monetary minor units, or cryptographic hashes, which normally require exact matches.

Final practice

Explain the meaning of the formula L = (1/n) × Σᵢ (predictionᵢ − targetᵢ)² without using a symbol that has not been defined.

Show the worked explanation

L is an average squared-error loss. For each entry i, subtract its target from its prediction, square that difference, add all n squared differences and divide by n. Large errors count more because they are squared. The formula specifies an average across n measured entries.
