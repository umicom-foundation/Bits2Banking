FOUNDATION MATHEMATICS · UNIT 11 OF 12

From matrix projections to trainable weights

See precisely how training changes weights.

You can start here, whatever your background. Terms and symbols are defined beside the calculations. Open the formula guide or step into an earlier unit whenever needed.

1. Why do neural networks use matrices?

Instead of learning one number, an AI model may learn thousands or millions of weights. A weight matrix arranges the numbers in rows and columns. Each output is a weighted combination of input numbers. We will begin with only two inputs and two outputs, so every multiplication fits on the page.

Suppose Umicom's note classifier receives two numerical features: x=[2,1]. We will not claim these numbers have a special meaning; they are a controlled mathematical example. Our weight matrix is:

Initial datax = [2,1], W = [[0.5,0.1],[0.2,0.3]]x is one row with two features; W is a 2×2 matrix with two rows and two columns. The output is y=xW (row-vector convention).

2. Calculate the predictions one column at a time

The first output uses the first column: (2×0.5)+(1×0.2)=1.2. The second uses the second column: (2×0.1)+(1×0.3)=0.5. The predictions are therefore y=[1.2,0.5]. Suppose our desired outputs are t=[1.0,0.6].

Mean squared errorL = ((1.2−1.0)² + (0.5−0.6)²) / 2 = 0.025The first squared difference is 0.04, the second is 0.01. There are 2 outputs, so divide their sum 0.05 by 2.

3. How does one weight affect an output?

Each weight contributes to its corresponding output. Changing W₀₀ (first row, first column) changes the first output by input feature 0 times the weight change. For MSE with two outputs, the gradient for the first output equals (prediction − target): 0.2. For the second, it is −0.1. The matrix gradients are the input values multiplied by these output gradients.

4. Make one SGD update and check the result

Choose learning rate α=0.1. Subtract 0.1 times each gradient from its weight. The new matrix is [[0.46,0.12],[0.18,0.31]]. Recalculate from scratch: new first output = 2×0.46 + 1×0.18 = 1.10; new second output = 2×0.12 + 1×0.31 = 0.55.

Our new MSE is ((1.10−1.0)²+(0.55−0.6)²)/2 = (0.01+0.0025)/2 = 0.00625. The smaller value is evidence that this particular update improved this particular training example.

5. Translate the method into native C23

/* Conceptual 2×2 row-major multiplication; the Framework uses
 * UmiAiTrainingMatmul for actual training graphs. */
float x[2] = {2.0F, 1.0F};
float w[4] = {0.5F, 0.1F, 0.2F, 0.3F};
float y0 = x[0]*w[0] + x[1]*w[2];
float y1 = x[0]*w[1] + x[1]*w[3];

In the RoPE training experiment, query and key projections each own a 4×4 matrix. The existing tape's reverse-mode differentiation calculates gradients through matrix multiplication, rotary attention and the scalar loss. The two matrices are updated together using UmiAiTrainingSgdStepMany.

6. Practice and reveal

With input x=[1,2] and weights W=[[1,0],[0,1]], what outputs do you obtain? Then explain why changing the first weight changes only the first output.

Show the worked solution

First output = 1×1+2×0 = 1. Second output = 1×0+2×1 = 2. The first weight sits in the first output column, so it contributes only to the first output in this simple linear projection.
