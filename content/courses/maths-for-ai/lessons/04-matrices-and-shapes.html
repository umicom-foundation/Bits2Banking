Matrices, shapes and multiplication

Start with a plain-English idea, then a labelled formula, a worked example, and a solution you can reveal.

No mathematics qualification required. Read at your own pace. A symbol is explained the first time it appears; use the symbol guide whenever needed.

A matrix is a table of numbers

A matrix arranges numbers in rows and columns. A small matrix can represent the weights of a software transformation. For example, A = [[1, 2], [3, 4]] has two rows and two columns; we describe its shape as 2 × 2.

Matrix multiplication one cell at a time

ExampleA = [[1, 2], [3, 4]]   B = [[2, 0], [1, 2]]To calculate one cell of A × B, multiply one row of A with one column of B and add the products.

Top-left cell: (1 × 2) + (2 × 1) = 4. Top-right: (1 × 0) + (2 × 2) = 4. Bottom-left: (3 × 2) + (4 × 1) = 10. Bottom-right: (3 × 0) + (4 × 2) = 8.

Therefore A × B = [[4, 4], [10, 8]]. The order matters: B × A generally gives a different result.

Why the inner dimensions must match

A matrix with shape 2 × 3 may multiply a matrix with shape 3 × 4, producing shape 2 × 4. The adjacent 3s must agree: each row contains three values to pair with each column's three values. If the shapes were 2 × 3 and 2 × 4, there would be no matching three-value pair.

Transpose: switch rows and columns

The transpose of a matrix swaps row and column positions. If A = [[1, 2], [3, 4]], then Aᵀ = [[1, 3], [2, 4]]. The raised T is read “transpose”. In backpropagation, a fixed rotation uses its transpose to carry a gradient backwards.

Practice

What is the output shape of a 5 × 3 input matrix multiplied by a 3 × 2 weight matrix?

Show the worked solution

The inner dimensions are both 3, so multiplication is defined. The outer dimensions are 5 and 2, giving 5 × 2.
