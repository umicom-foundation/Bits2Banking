Units 125–136 explain dimensions, scaled dot products, online softmax, value accumulation, masking, parity, memory, positions, operation counts and benchmark uncertainty.

Course sequence

  1. Identify single-query attention dimensions · Learn to read shapes for queries, retained keys, values and one output row.
  2. Calculate scaled dot products and temperature · Understand why attention scores divide the query–key dot product by square root of head width.
  3. Derive stable online softmax · Calculate a running softmax numerator without materialising every normalised score.
  4. Accumulate weighted value vectors · Multiply attention probabilities by values and sum coordinate-wise.
  5. Reason about masked softmax and invalid rows · Distinguish a valid masked score from a broken numerical input.
  6. Reconstruct multi-head output shapes · Concatenate attention heads without changing their order.
  7. Calculate absolute and relative parity errors · Make numerical comparison rules explicit and handle near-zero reference values.
  8. Calculate cache and scratch memory separately · Budget persistent K/V bytes and temporary operator workspaces independently.
  9. Prove prefix-position invariance for appends · Recognise when previously cached token-position pairs stay unchanged.
  10. Count rollover rebuilds for bounded context · Predict full-window fallback frequency from the context capacity.
  11. Estimate attention arithmetic and memory traffic · Distinguish operation counts from bytes read and runtime.
  12. Read paired latency measurements and uncertainty · Calculate medians and refrain from over-generalising small benchmark samples.

Before interpreting results

The calculations are illustrative. Unit exercises are independent of the decoder, and do not demonstrate a measured speedup or numerical parity in the real Framework.
