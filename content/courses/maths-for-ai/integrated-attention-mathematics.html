Mathematics Units 149–160 · Open educational curriculum · Sammy Hegab

This study route develops a forward-only single-query attention calculation within a real multi-layer decoder. Learn the differences between arithmetic correctness, K/V integrity, deterministic generation and measured runtime performance.

  1. 149 — Locate the newest query row
  2. 150 — Calculate final-row attention weights
  3. 151 — Count single-query head operations
  4. 152 — Compare full-query rows with one row
  5. 153 — Calculate operator scratch bytes
  6. 154 — Compute absolute-plus-relative error
  7. 155 — Track window-rollover position indices
  8. 156 — Calculate grouped-query cache ratios
  9. 157 — Estimate KV read bandwidth floors
  10. 158 — Bound reused prefix validity
  11. 159 — Distinguish logit and token agreement
  12. 160 — Construct an integrated evidence matrix

Prerequisites and scope

Read the preceding efficient-decoding lessons and basic softmax mathematics first. Examples use bounded C23 numerical components in Umicom Framework. Model architecture changes such as grouped-query attention require distinct checkpoints and are taught as separate designs, not silently enabled on existing weights.
