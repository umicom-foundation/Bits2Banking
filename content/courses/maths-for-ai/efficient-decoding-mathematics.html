Author: Sammy Hegab · Service to Many Leads to Greatness.

Units 137–148 work from stable softmax and weighted vectors to grouped KV head mapping, memory budgets, quantisation, paging, rotary geometry, arithmetic intensity and inference-service metrics.

Learning sequence

  1. Derive a stable softmax normaliser

    Normalise exponentially weighted scores without overflow.

  2. Calculate a probability-weighted value vector

    Turn attention probabilities into a vector.

  3. Count prefill and decode score pairs

    Compare triangular causal work with a last-query-only calculation.

  4. Map grouped-query head indices

    Calculate the shared KV head used by each query head.

  5. Calculate model-wide KV-cache bytes

    Account for K, V, layers, context and precision.

  6. Quantise a float with a symmetric scale

    Work through one element and state the approximation error.

  7. Measure absolute and scale-aware error

    Avoid invalid relative-error conclusions near zero.

  8. Calculate paged KV internal fragmentation

    Count allocated blocks and unused token slots.

  9. Rotate a two-dimensional positional pair

    Compute the basic rotation used to explain rotary embeddings.

  10. Compare arithmetic intensity with bandwidth

    Recognise when bytes moved dominate the execution limit.

  11. Follow greedy speculative token verification

    Identify which proposed tokens are safe to commit.

  12. Separate TTFT, TPOT and throughput

    Calculate distinct inference-serving measurements.

How to study

Read the explanation, reproduce the numerical example, answer the question before revealing the explanation, and compare the stated mathematical contract with an independently tested implementation. The worked values are examples, not measured production performance.
