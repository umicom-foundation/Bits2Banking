About this learning sequence

These units derive memory accounting, raw-byte budgets, cache reuse ratios, stale-lease generations and careful performance comparisons using explicit units and worked arithmetic.

  5. 213 — Bound hypothetical allocation savings
  6. 214 — Combine session-slot and memory ceilings
  7. 215 — Measure the peak physical-memory watermark
  8. 216 — Count reset FP32 elements and state
  9. 217 — Analyse lease generations across slot reuse
  10. 218 — Compare warm and cold median latencies
  11. 219 — Compute idle trimming with live leases
  12. 220 — Complete a cache-reuse accounting table
