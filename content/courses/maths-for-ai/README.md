# Maths for AI — From the Beginning

Part of **Bits to Banking**, Umicom Foundation. Author: Sammy Hegab.

Open [`index.html`](index.html) in a web browser. All resources are local;
no external fonts, network calls, scripts, account or login is required.

The twelve units begin with fractions and finish with reading the mathematics
behind native C23 transformer code. Every unit contains an accessible diagram,
formula symbols explained in words, step-by-step numbers, one learner exercise
and an expandable answer. Use it as a complete introductory course or jump to
an individual unit from the main native LLM lessons.

**Curriculum:** numbers/percentages; functions; vectors/dot products;
matrices/transposes; probability/softmax/loss; derivatives/chain rule;
trigonometry/RoPE; attention/KV workload; formula-to-C23 translation;
gradient descent and learning rates; trainable matrix weights; finite
differences, floating-point tolerances and experiment integrity.

This course illustrates computer science and finance with synthetic values.
It does not teach financial decision-making or constitute a complete course
in statistics, linear algebra, numerical analysis, or machine learning.

The shared stylesheet and SVG map remain editable source assets. New units
10–12 and the Maths for AI index are added or updated without removing any
prior unit. The companion native LLM Lessons 87–88 link directly to these
mathematics explanations, and a separate recent-lesson catalogue keeps
Lessons 69–88 discoverable without replacing the historic course map.
