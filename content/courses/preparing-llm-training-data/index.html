Preparing Data for LLM Training

Distinguish retrieval from training, review documents, choose record formats and preserve independent evaluation groups before tokenization.

A text editor is enough for the early exercises. The native group-partition lab needs CMake, a C23 compiler and the matching Framework source checkout; no model download is required.

  1. Choose retrieval, fine-tuning or training from scratch
  2. Turn documents into reviewed text without losing provenance
  3. Read JSON, JSONL and conversational records
  4. Review quality, duplicates and allowed use
  5. Keep related sources out of different partitions
  6. Run a native Framework dataset-partition lab
  7. Understand tokens, chat templates and loss masks
  8. Plan batches, epochs and memory before training
  9. Choose a fine-tuning method and save recoverable state
  10. Evaluate changes and publish a reproducible dataset package
