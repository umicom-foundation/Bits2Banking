C words explained

Use these short reminders alongside the worked examples. A definition is a starting point; follow the lesson to see the rule used.

Argument

A value supplied to a function when it is called.

Array

An ordered collection of elements of the same type, accessed by position. A valid position must remain within the collection's bounds.

Assignment

Storing a value in an object, commonly written with = in C. It is different from the == comparison.

Boundary

An edge of an allowed range, such as the lowest or highest permitted count.

Buffer

Storage that temporarily holds data, for example output waiting to be delivered.

Build

The process of preparing a program, including compilation and linking. A build does not necessarily run the program.

Caller

The code that invokes a function and receives its result.

Compilation

Translation of a source file into another representation, commonly an object file.

Compiler

A tool that performs compilation and diagnoses source it cannot translate as requested.

Condition

An expression used to choose whether a body executes. C treats zero as false and nonzero as true.

Contract

The agreement describing accepted inputs, results, rejected cases and ownership responsibilities.

Declaration

A statement making a name and its type known to the compiler.

Diagnostic

A message describing a problem or observation, such as a warning, error or failed check.

Executable

A prepared program that the environment can launch. It is distinct from the source file you edit.

Expression

Code that computes a value or designates an object.

Function

A named piece of work with parameters, a body and a return type.

Header

A source file commonly ending in .h that makes shared declarations available.

Hosted program

A C program running with the hosted implementation's startup and library environment, normally above an operating system.

Initialisation

Giving an object its initial value when it is created.

Integer

A whole number. A C integer type has a finite representable range.

Iteration

One execution of a loop's body.

Linking

Combining compiled pieces and resolving references to required functions or data.

Loop

A control structure that repeats a body according to a rule.

Object

In C, a region of data storage whose contents can represent values. This use does not require object-oriented programming.

Parameter

A named input declared by a function. A call supplies arguments for its parameters.

Regression test

A retained check intended to expose behaviour that would return if an earlier defect were reintroduced.

Scope

The region of source code in which a name can be used.

Source file

An editable text file containing program instructions and comments.

Standard error

The program's conventional stream for diagnostics, separate from ordinary output.

Standard output

The program's conventional output stream; it can lead to a terminal, file or another destination.

Stream

A sequence of characters or bytes accessed through library input/output operations.

Target

A named build result, such as an executable or library, described to the build system.

Test case

A particular set of inputs and expected observations.

Type

A description constraining the representation and permitted use of values.

Variable

A named object holding a value. A const-qualified object cannot be modified through that declared name.

Borrowing

Temporarily allowing access while another owner keeps the storage valid. The contract says whether access is read-only and whether it may continue after return.

Lifetime

The period during which an object exists. A formerly valid address is not enough after that period ends.

Pointer

A value used to access an object or function under C rules. It does not automatically provide an allocation size or an ownership contract.

Span

A starting location and an explicit count of elements. Always identify whether the count is bytes or another element type.

Undefined behaviour

An operation for which the language imposes no requirements on the result, such as an out-of-bounds array access. Prevent it rather than treating a crash as a reliable check.
