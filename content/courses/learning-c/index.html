Learning C: For beginners

Read small programs, predict their results and understand each step. No previous programming experience is assumed.

If files, commands or an operating system are unfamiliar, start with Introduction to Computers. Every lesson can be read or traced on paper. Practical work requires a prepared compiler environment; it is optional while learning the concepts.

  1. Read a C program before running it
  2. Prepare, build and run without mixing the steps
  3. Give values names and calculate a result
  4. Make a decision before calculating
  5. Repeat work without losing the stopping rule
  6. Give reusable work a clear contract
  7. Test what you promised and understand failures
  8. Move from small programs to OS and Kernel source
  9. Keep several values in an array
  10. Let a function read memory you still own
  11. Connect borrowed memory to bounded system input
  12. Group related values in a structure
  13. Pass a function to separate policy from mechanism
  14. Storage duration and freestanding code
  15. Connect declarations, source files and the linker
  16. Keep counts, offsets and progress separate

Choose how to learn

Speak, draw or write a prediction before looking at an explanation. Work at your own pace. The course does not save progress automatically; use a notebook or bookmark. Each lesson links previous, next, contents and a glossary. Reading the material does not establish programming or product qualification.

What comes next

The existing note-saving chapter introduces file input and output. Safer-C and borrowed-memory lessons prepare you for OS and Kernel source exercises. This course introduces a limited foundation; it is not a complete C reference or a finished OS course.
