Learning C

Learn to read and write small C programs, one idea at a time. Start with First programs and follow its numbered lessons in order. You do not need banking knowledge or an account.

How to use this course

  1. Read the explanation before copying code.
  2. Predict the example's result.
  3. Try the exercise in your own practice folder or on paper.
  4. Compare your result with the worked answer.
  5. Use Previous, Next and Course contents to keep your place.

Reading requires only a browser or Studio's learning reader. Running examples requires a C compiler; Lesson 2 explains that step. If files and folders are unfamiliar, begin with Introduction to Computers in the web library.

First programs

Read, build, calculate, choose, repeat and call functions.

  1. Your first C program
  2. Build and run your first C program
  3. Variables and simple calculations
  4. Making decisions with if
  5. Repeating work with a loop
  6. Writing and calling a function
  7. Test what you promised and understand failures

Working with more information

Learn arrays, structures, pointers and separate source files after the first programs.

  1. Keep several values in an array
  2. Group related values in a structure
  3. Let a function read memory you still own
  4. Connect declarations, source files and the linker

Further study: systems programming

Optional source studies after the introductory modules. These are not required to finish your first C programs.

  1. Connect borrowed memory to bounded system input
  2. Pass a function to separate policy from mechanism
  3. Storage duration and freestanding code
  4. Keep counts, offsets and progress separate
  5. Represent bytes with bits and hexadecimal
  6. Move from small programs to OS and Kernel source

After this course

Study CMake as a separate build-tools course, then GTK4 when you are ready to create windows and buttons. Framework source studies come after those foundations. You do not need to study treasury, blockchain or AI to learn C.
