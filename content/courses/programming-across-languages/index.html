Programming across languages

Learning pathways

Learn one idea at a time, trace it on paper, then read the same idea in several programming languages. Each lesson uses an imaginary savings club so you can focus on the procedure.

Start with pencil and paper or a notes app. You can read every example before choosing a compiler, which turns source code into a program, or an interpreter, which runs source through another program.

Lessons in order

  • Follow instructions on paper
  • Give values names and units
  • Make a decision with if
  • Compare one for loop in six languages
  • Visit a list and skip a row
  • Give a task a name and a result
  • Plan a first Umicom change
  • Pass two integers through the C ABI
  • Keep a signed difference in range
