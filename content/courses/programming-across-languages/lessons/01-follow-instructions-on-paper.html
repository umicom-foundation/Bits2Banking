Follow instructions on paper

Course contents · Next · Give values names and units · Markdown edition

Turn a short everyday task into exact steps that another person can follow.

Make a first plan

Write the number 200 on a sheet of paper. It stands for 200 cents in an imaginary envelope. Add 50 cents. Write the result on a second line. The second line should say 250.

A program is a set of instructions written in a language a computer can use. An algorithm is the plan those instructions carry out. Pseudocode records the plan in plain language with a clear order.

SET envelope cents TO 200
ADD 50 TO envelope cents
SHOW envelope cents

Check each step

  • Before the first line, there is no stored amount.
  • After the first line, the stored amount is 200 cents.
  • After addition, the stored amount is 250 cents.
  • The last line shows the stored amount.

Try it

Change 50 to 25 and ask someone else to follow the plan. Compare the paper total before discussing any programming syntax.

Answer to check after trying: 225 cents. In a real application, save the initial amount, the update and the expected result as separate test inputs.
