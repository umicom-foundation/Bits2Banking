Compare one for loop in six languages

Course contents · Previous · Make a decision with if · Next · Visit a list and skip a row · Markdown edition

Count three receipt lines with pseudocode, C, C++, Java, Python, Go and D.

Trace the common behaviour

A loop repeats an action. This one starts at receipt position 1, shows each position through 3 and stops before showing 4. One pass through the action is called an iteration.

FOR each whole number from 1 through 3
    SHOW the number
END FOR
  • C, C++, Java and D use a three-part header in parentheses: start value, continuing condition, and update. The code tests the condition before each pass and runs the update after each completed pass.
  • Go has the same three-part form, with braces around the body and no parentheses around the header. Go uses position++ here as a statement and introduces position with :=.
  • Python takes each value supplied by range(1, 4). The stopping value 4 is excluded. A colon and indentation introduce the repeated action. range is a built-in name.

C

#include <stdio.h>

int main(void)
{
    for (int position = 1; position <= 3; ++position) {
        printf("%d\n", position);
    }
    return 0;
}

C++

#include <iostream>

int main()
{
    for (int position = 1; position <= 3; ++position) {
        std::cout << position << '\n';
    }
    return 0;
}

Java

public class CountEntries {
    public static void main(String[] args) {
        for (int position = 1; position <= 3; ++position) {
            System.out.println(position);
        }
    }
}

Python

for position in range(1, 4):
    print(position)

Go

package main

import "fmt"

func main() {
	for position := 1; position <= 3; position++ {
		fmt.Println(position)
	}
}

D

import std.stdio : writeln;

void main()
{
    for (int position = 1; position <= 3; ++position) {
        writeln(position);
    }
}

Run one version

Copy the code for the language you have into the exact file name below. A terminal is a window in which you type commands. Open it in the folder containing the file. Select one command set, or use only the paper trace.

  • C: save for_count.c and use clang -std=c23 for_count.c -o count-c.exe.
  • C++: save for_count.cpp and use clang++ -std=c++20 for_count.cpp -o count-cpp.exe.
  • Java: save CountEntries.java. With a JDK, use javac CountEntries.java, then java CountEntries.
  • Python: save for_count.py and use python for_count.py with a Python 3 installation.
  • Go: save for_count.go and use go run for_count.go with Go installed.
  • D: save for_count.d and use dmd -offor-count-d.exe for_count.d with DMD installed.

On Windows, Clang needs a configured C or C++ development toolchain with its standard headers. If it cannot find stdio.h or iostream, use a configured UCRT64 terminal and try gcc -std=c23 for_count.c -o count-c.exe or g++ -std=c++20 for_count.cpp -o count-cpp.exe. Use the version that agrees with your Studio project's compiler settings.

For a compiled Windows executable, type its path in PowerShell, for example ./count-c.exe. If a command is unrecognised, replay the trace on paper and check which tool your Studio project is configured to use. If a C compiler only recognises -std=c2x, use a supported compiler for the C23 course reference.

Try it

Extend the loop to show five rows. C, C++, Java, Go and D change the continuing bound to 5. Python changes the exclusive stop to 6. Verify that 5 appears once and 6 never appears. A Studio IDE smoke test can compare all five output lines.
