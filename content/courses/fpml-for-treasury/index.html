FpML for Treasury and Trade Confirmation

Read the two sides of a fictional interest rate swap, preserve the contract terms at import and check the record in C23.

Before you start

Start on paper with the swap drawing. For the optional native exercise, use a C23 compiler that supports -std=c23 in a private practice directory. The examples use fixed synthetic values and need no treasury platform.

Lessons

  1. Read the Two Sides of a Swap

    Follow payer, receiver, currency and rate terms before opening a schema.

  2. Read and Validate the Import Boundary

    Trace a versioned XML document to a smaller record a treasury service can review.

  3. Check the Mapped Terms in C23

    Keep amounts and basis points exact at the native boundary and trace rejects without overwriting the result.
