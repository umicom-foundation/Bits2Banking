UK Open Banking Account Access

Trace a customer's consent, make a synthetic read request and practise the native decision that separates allowed accounts from denied ones.

Before you start

Start with pencil and paper. A C23 compiler is optional for exercise three. The examples use a fictional UK account-information service, with no real accounts, certificates or access tokens.

Lessons

  1. Follow Account Access Consent

    Identify the customer, the account provider and an account information provider in the UK v4.0.1 profile.

  2. Request a Minimal Account View

    Map one read permission to a small account response and preserve the access decision in a review trace.

  3. Check the Trusted Consent in C23

    Check client, account, permission, active state and expiry before offering a local account projection.
