Words explained

Use this as a reminder, then return to the lesson for a worked example. A short definition is a beginning, not a substitute for practice.

Algorithm
A sequence of steps for solving a task.
Application
A program made to help with an activity, such as writing a note.
Argument
Information supplied to a command or function.
Array
An ordered group of values. Its size and valid positions matter when programming.
Bit
A unit with two possible values, conventionally 0 and 1.
Boot
Start a system so that its software can perform useful work.
Browser
An application used to read and interact with websites.
Byte
A group of eight bits.
Command
An instruction supplied to a program such as a shell.
Compiler
A tool that translates source code into another form, often machine instructions.
Data
Information represented so it can be stored or processed.
Directory
Another name for a folder.
Encoding
An agreed way of representing information.
File
A named collection of stored information.
Firmware
Software used for early or device-specific machine control.
Folder
A way of grouping files and other folders.
Function
A named part of a program that performs work and may return a result.
Guest
The environment running inside an emulator or virtual machine.
Hardware
Physical computing equipment.
Host
The computer or environment running tools; in an emulator exercise it runs the emulator.
Input
Information supplied to a system.
Kernel
Central software controlling important machine resources and access to them.
Library
Code that other programs can use.
Link
A reference that lets you open another page or resource.
Linker
A build tool that connects compiled parts and resolves references between them.
Loop
Instructions that repeat, usually with a stopping condition.
Operating system
Software that manages resources and provides services to programs and people.
Output
A result produced by a system.
Path
A description of where to find a file or folder.
Pointer
A value used to refer to a location; using it correctly requires valid bounds and lifetime.
Prerequisite
Knowledge or equipment an activity expects before you begin.
Process
A running instance of a program with its execution state and resources.
Program
Instructions a computer can carry out.
RAM
Random-access memory, commonly used to hold working information while programs run.
Shell
A program that interprets commands, such as PowerShell or Bash.
Source code
A program expressed in a language people can read and edit.
Storage
Resources used to keep information; persistent storage retains it across normal power-off.
Test
An activity that compares an observed result with an expected one.
Variable
A named place for a value that may change during a task.
Working directory
The selected folder from which relative paths are interpreted.
