D Keywords for Beginners

Find each keyword in the D reference table and read a small example that explains its role.

This course covers the 111 spellings in the D lexical reference’s keyword table as published in November 2026. It includes the reserved macro spelling and the ten entries marked as historical. The separate special-token course covers the six replacement tokens and the #line form.

A keyword is a word that the language grammar reserves for a specific job. A value name such as cents is a name you choose. Syntax describes where the pieces can go. Meaning describes what happens when the program runs.

Begin by reading the example aloud. To run it, save the full code to a plain text file named practice.d and open a terminal in the folder that contains it.

Follow the lessons

  1. Name values and choose D types Give a value a name and choose words that fit numbers, truth flags and text units.
  2. Choose, repeat and stop in D Trace a decision and a loop over a short practice statement before reading the whole program.
  3. Pass values and describe function promises Trace a call, then see what parameter words tell the person reading it.
  4. Group and protect related data Distinguish a structure, a union, a class and an interface using familiar parts of a statement.
  5. Organise source and name a boundary Separate helpers from interfaces and recognise words that depend on a build or target.
  6. Ask the compiler about a type Use a short template, a compile-time assertion and keywords that report what the compiler sees.
  7. Handle a failure and plan shared work Read a deliberate classroom error, then see why shared state needs explicit coordination.
  8. Recognise reserved and historical D words Read an older source listing and choose a current teaching form for new code.
