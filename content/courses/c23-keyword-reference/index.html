C23 Keywords for Beginners

Learn how C uses reserved words to name values, repeat steps, group data and describe storage.

This reference covers all 54 primary keyword spellings and the five older alternate spellings listed in the C23 lexical grammar. Optional and reserved forms are identified alongside the basic language.

A keyword is a word that the language grammar reserves for a specific job. A value name such as cents is a name you choose. Syntax describes where the pieces can go. Meaning describes what happens when the program runs.

Paper and pencil are enough to start. To run a program, save it as a plain text file with the .c ending. The compiler translates the text, then the second command starts the saved executable in PowerShell.

Follow the lessons

  1. Name values and choose their types Read a first C declaration, then choose between whole numbers, truth values, characters and measurements.
  2. Choose an action and repeat it Make one decision, then repeat safe actions over a short list of pretend entries.
  3. Group data and return results Read short functions, group related facts and distinguish a missing object from a real one.
  4. Control lifetime and access Tell apart where a name can be seen, how long data survives and which code can use it.
  5. Check types and representations Inspect memory requirements and types, then make a build reject a broken assumption.
  6. Read optional and older forms Identify an optional feature, a reserved spelling or a compatibility spelling before you try to use it.
