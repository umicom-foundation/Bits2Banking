Bits2Banking

Learning NoSQL and MongoDB

Learn how applications store documents, find records and manage database connections. Start with an invented lesson catalogue, then inspect the real Umicom Framework connector boundary. Each lesson includes its own setup summary and a small exercise.

Follow lessons 1–5 for document modelling and database operations, then lessons 6–8 for C adapter ownership and feature review. The database exercises use separate training collections. The C example uses an in-memory fixture, so its result does not establish a working network provider.

  1. Documents, collections and the questions an application asks
  2. Create and read a training document
  3. Ask precise questions and limit the result
  4. Validate records and keep identity stable
  5. Indexes, duplicate identities and concurrent edits
  6. Follow a database adapter lifetime in C
  7. Plan a real document-database provider
  8. Review and extend an Umicom data feature
