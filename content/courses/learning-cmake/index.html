Learning CMake

CMake describes how a software project is prepared for building. In this course you will follow a small C project from source files to executables, understand dependencies, run tests and record useful evidence. Every chapter includes the setup needed to enter the exercise directly.

Begin with chapters 1–3 for files and commands, then 4–8 for targets and tests. Chapters 9–12 cover diagnosis, the Framework SDK, generated outputs and evidence. The core lab parses fictional ledger messages. It runs independently, so learning its build graph does not require compiling every Umicom application. Keep an exercise notebook containing each command, expected result and explanation.

  1. Follow source files to a running program
  2. Read a CMake project one command at a time
  3. Keep source and build directories separate
  4. Build a target and its required dependencies
  5. Understand PUBLIC and PRIVATE usage requirements
  6. Register tests that check observable behaviour
  7. Observe which files an incremental build rebuilds
  8. Choose tests using evidence about a change
  9. Locate a failure in configuration, compilation or linking
  10. Use an installed Framework library from a small project
  11. Give generated files one owner and complete dependencies
  12. Keep build results useful for the next developer
