First time studying computers?

Start with Introduction to Computers, which introduces files, memory, instructions and system layers without prior knowledge. Then follow the first-programming route for C functions, arrays, return values, pointers and build tools. The existing prerequisites below apply to the practical labs, not to your ability to begin learning.

Connected written lessons and this course — revisit the explanation you need and return here when ready.

Prerequisites

Basic C arrays, functions and return values; a C23-capable compiler, CMake and Ninja; the corresponding Umicom source checkouts. You do not need administrator rights for these hosted labs.

Work with the source

The lab lives at labs/native/kernel-bounded-input in Bits2Banking. It links source from the named OS or Kernel checkout. It does not carry a diverging copy of the implementation. Use a new build directory and keep logs from your own runs.

Expected results in lessons describe what to check; they are not evidence that a compiler, guest or hardware run has already succeeded.
