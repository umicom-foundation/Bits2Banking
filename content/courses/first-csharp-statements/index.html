First C# Statements

Read and check fictional receipt records while learning names, types, loops, lists and expected results in C#.

Before you start

Start on paper if you are new to coding. To run an exercise, use a text editor, a terminal and an installed .NET SDK. Each C# example is a complete program for a private practice project.

Lessons

  1. Name values in a receipt

    Read one C# declaration and use a small console program to display three parts of a fictional receipt.

  2. Count posted receipts

    Trace a counting loop and read the matching structure in C and Java.

  3. Keep only the posted receipts

    Build a new typed list of the posted amounts and preserve all original entries.

  4. Check the posted total

    Run small checks for normal input, a pending receipt, an unknown status and an amount outside the supported total.
