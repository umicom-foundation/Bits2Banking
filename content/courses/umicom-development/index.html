Umicom Framework Development

Learn how a small C program becomes an application that shares Umicom Framework logic between a terminal and a GTK4 window. Read the explanations first, then build the supplied source when you are ready. Each lesson includes a question with an answer so you can check the idea before moving on.

Prepare at your own pace

Start with Introduction to Computers if files and commands are new. Use Learning C: For beginners for more practice before the later chapters.

One application, two presentations

The supplied exercise counter uses Framework status values and shares one checked rule between a console and a GTK4 window. The examples are original Umicom teaching code. Console tests do not establish that the graphical interaction works.
