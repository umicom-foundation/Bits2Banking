Umicom Framework Development

Build understanding around one small application: an exercise counter. Its console and GTK4 window use the same counting function. Follow First application in order, then Build, test and investigate a change. The later sections are separate source-study projects.

Before you begin: Complete Learning C through arrays, structures, pointers and separate source files. Learn the difference between an editor and a compiler before starting the practical project.
