Learning Motorola 68000 Assembly

Assembly language gives readable names to instructions a processor can carry out. In this introduction you will follow a calculation, read a memory diagram and trace a loop. A pencil and paper are enough for every exercise here.

Begin with Introduction to Computers if files, programs or numbers stored in a computer are unfamiliar. The first lesson below introduces registers, bits and instruction notation before using them. You do not need to buy hardware or install an emulator.

Read in this order

  1. Registers and a first calculation: describe where a calculation keeps its values.
  2. Addresses and bytes in memory: distinguish a location from the value stored there.
  3. Comparisons and a bounded loop: predict when repeated work stops.

These three lessons use the original MC68000 instruction set and GNU assembler notation. The examples are reading exercises, not complete boot programs. A future practical module will specify an assembler, an emulator, a memory map and a verified launch procedure together.

Connect this subject to Umicom

The examples use the same arithmetic and loop ideas as the existing Learning C laboratory. Follow the source links inside each lesson to compare a high-level instruction with smaller machine-level steps. The C examples are real Bits2Banking source files; the Assembly examples are teaching fragments and do not claim an existing Umicom Kernel 68000 port.
