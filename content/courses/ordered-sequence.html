Follow a course sequence

A lesson teaches one idea. A course puts related lessons in a useful order. A book collects longer reading. A lab is a practical example you can inspect and try. Start with one course; you do not need to study every subject at once.

Start with the guided learning sequence. It leads from computer basics to a small Umicom application. The specialist routes below branch from those foundations.

  • 1. Computers and first programs
  • 2. Building Umicom applications
  • 3. Web development
  • 4. Other programming languages
  • 5. Systems, processors and compilers
  • 6. Mathematics and AI
  • 7. Financial systems and ledgers

1. Computers and first programs

Before you begin: No previous computing or programming knowledge.

What you will work towards: Find a saved file, follow a command, and explain a small program.

  1. Introduction to Computers

    Start here. Learn files, folders, instructions, memory and commands through eight introductory lessons.

  2. Learning C

    Continue with First programs, then Working with more information. Leave systems studies until later.

  3. Introduction to Version Control

    After editing and saving files, learn how to record and review changes.

2. Building Umicom applications

Before you begin: C variables, decisions, loops, functions, arrays, pointers and separate source files.

What you will work towards: Understand one small Framework application from source to a tested console program and a GTK4 window.

  1. Umicom Framework Development

    Follow the introductory project first. Choose the later source studies only after completing it.

  2. Building a Web Server in C

    A later project: requests, handlers and lifetime after C and Framework foundations.

3. Web development

Before you begin: Files and folders. Learn HTML before CSS, and both before browser JavaScript.

What you will work towards: Read the task-board example as a page, its presentation and its behaviour.

  1. Learning HTML

    Begin with meaningful page structure, links and images.

  2. Learning CSS

    Style an HTML page, then check resizing and keyboard access.

  3. Learning JavaScript

    Add events and visible state to the page; then examine local storage.

  4. Learning PHP

    Continue on the server after learning forms, requests and basic programming.

4. Other programming languages

Before you begin: Some programming experience helps with the current code-study chapters. Return to Learning C for a fuller introduction to variables, functions and control flow.

What you will work towards: Compare how existing note and journal examples express similar operations in another language.

  1. Learning Python

    Introductory code studies of a notes example, followed by JSON and file errors.

  2. Learning C++

    After C, study objects and resource lifetime through a note journal.

  3. Learning Java

    Study records, a journal and decimal calculations. These are initial chapters, not a complete language course.

5. Systems, processors and compilers

Before you begin: Complete C foundations and the further systems studies. Understand memory, bytes, pointers, functions and build tools.

What you will work towards: Trace real system boundaries and carry out a small, separately documented experiment.

  1. Introduction to RISC-V

    Learn registers, memory and privilege before Assembly source studies.

  2. Learning RISC-V Assembly

    Follow calls, returns and interrupted registers using Kernel examples.

  3. Umicom Kernel from Scratch

    A specialist route through hosted checks and native Kernel code. Read each lab prerequisite first.

  4. Umicom OS from Scratch

    A parallel systems route: startup, services, recovery and image evidence.

  5. Building a Compiler in C

    A separate project using Umicom C: source, tokens, expressions, execution and diagnostics.

6. Mathematics and AI

Before you begin: Start with the mathematics course. For programming chapters, also complete C foundations and build tools.

What you will work towards: Explain a small model, inspect its native implementation and distinguish training from evaluation.

  1. Mathematics for AI

    Build mathematical foundations before model internals.

  2. Building an LLM from Scratch

    Learn the model pipeline before choosing advanced native source studies.

  3. Introduction to Distributed Learning

    After one model and its training loop, study workers, communication and verification.

  4. Guide to AI Research

    Further reading after the model course; research topics are not prerequisites for a first program.

7. Financial systems and ledgers

Before you begin: Begin with the business and financial lessons. C and Framework knowledge are needed for the software exercises.

What you will work towards: Follow fictional accounts, trades and payments through explicit rules and records.

  1. Umicom application and financial-system studies

    Choose the software or financial route inside this collection. They are separate subjects, not a single beginner course.

  2. Introduction to Blockchain and Distributed Ledgers

    Study records and validation first, then choose the later consensus and implementation topics.

Finance, Bitcoin and systems

Mobile and native-language starter courses

Each course starts with its own setup summary and ordered practical work.

  • Learning Kotlin — Write and check a small lesson-progress program. Start with installing a JDK and the Kotlin compiler, then create a file, compile it and explain its values and functions. Two introductory lessons; later topics are listed separately.
  • Learning D Language — Create a native program with the D compiler. Learn how source becomes an executable, then check a function with input validation and unit tests. Two introductory lessons; later topics are listed separately.
  • Android Development — Build a small lesson counter for an Android device or emulator. Begin with the development tools, run the generated application, then connect a button to visible screen state. Two introductory lessons; later topics are listed separately.
  • Learning Flutter — Create a small lesson counter using Dart and Flutter. Begin by running the generated project, then learn widgets, state, callbacks and automated interaction checks. Two introductory lessons; later topics are listed separately.
