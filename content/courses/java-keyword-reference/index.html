Java SE 25 keyword reference

Learning pathways

Practise all 51 reserved spellings and all 17 contextual keywords in Java SE 25. Read an example or an intentional compiler rejection for each spelling.

Start on paper, then use a Java SE 25 JDK to compile a practice file. The short examples describe the location they belong in. Module descriptors depend on the named packages and types.
