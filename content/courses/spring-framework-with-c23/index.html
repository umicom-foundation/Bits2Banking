Spring Framework with a Native C23 Receipt Rule

Learning pathways

Keep a receipt limit in one C23 function and learn how a Spring container supplies it to Java application code.

Start with the invented data and trace the steps on paper. Optional compiler, SDK and adapter steps are for your own practice environment. A JDK, the framework dependencies and a native compiler are needed only for the adapter exercise.

Lessons in order

  • Put a receipt rule behind one native function
  • Pass the same units through JNI
  • Supply the native rule through a Spring bean
