Swift Payment Messages and ISO 20022

Follow a fictional cross-border payment instruction, a status report and separate settlement evidence, then implement a native reconciliation gate.

Before you start

Start with pencil and paper. An optional C23 compiler is enough for the final local exercise. The examples use made-up references and no network or payment account.

Lessons

  1. Follow the Payment and Message Roles

    Identify who sends the instruction, status and statement in a fictional cross-border flow.

  2. Normalize Message Evidence for Review

    Link local evidence by a known reference, currency and amount before changing a payment view.

  3. Apply Payment Evidence in C23

    Write a native status gate that keeps repeats and mismatches from posting a second result.
