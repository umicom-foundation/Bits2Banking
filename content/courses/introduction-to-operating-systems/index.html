Introduction to Operating Systems

An operating system coordinates programs, memory, devices and access to resources. This course introduces each idea using a small Umicom example. It assumes no previous operating-system or C experience. Definitions and setup are repeated where a lesson can be read independently.

Follow the sequence from programs and resources to booting, memory, scheduling, files, isolation and evidence. The course uses a small read-only report client, then points to native Kernel and Linux-based OS source. Physical installation and account management remain separate development milestones.

  1. Understand programs and the resources they use
  2. Distinguish the development host, guest and build target
  3. Follow the path from firmware to a working console
  4. Understand memory, addresses and ownership
  5. Understand processes and taking turns on a processor
  6. Understand interrupts and device events
  7. Distinguish a file interface from durable storage
  8. Locate the boundary between kernel services and Framework
  9. Read a boot observation without overstating its meaning
  10. Build a small OS observation application
  11. Understand recovery, users and permission boundaries
  12. Plan the route from a learning guest to an OS release

Continue with Umicom Kernel from Scratch or Umicom OS from Scratch.
