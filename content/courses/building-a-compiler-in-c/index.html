Building a Compiler in C

Build understanding by following the real Umicom C prototype from a short program to a checked result. A compiler translates a program into another representation. An interpreter reads that representation and carries out its instructions. You will study both, then see how the interpreter can become an application on Umicom Kernel.

This course covers a small arithmetic language written with C-like syntax. It does not describe a complete C compiler, a desktop operating system or finished support for every processor.

Choose how to begin

  1. Read each lesson and complete its paper exercise. No installation is needed for that route.
  2. If code is unfamiliar, visit Learning C for values, functions, arrays and return values. Each compiler lesson also explains the terms it introduces.
  3. For practical exercises, use the corresponding umicom-c source and follow its docs/first-program.md guide. Keep the application and compiler source versions together.

Lessons

  1. From source text to a result
  2. Read one token at a time
  3. Give expressions an unambiguous meaning
  4. Execute instructions with checked arithmetic
  5. Store a program as portable bytes
  6. Explain failures and test the boundaries
  7. Run the interpreter as a native Kernel program
  8. Understand architectures, firmware and boot media
  9. Design a small programming language in C
