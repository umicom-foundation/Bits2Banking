What you will learn

Use a signed number to describe a direction of change and use parentheses to explain an arithmetic decision.

Read the signs

Picture a number line with zero in the middle. Positive numbers lie to the right of zero and negative numbers lie to the left. A signed movement describes a change, even when the running total stays above zero.

Work it through

  1. Start with 1750 cents. Add a receipt of 400 cents to reach 2150 cents.
  2. A refund of 275 cents moves the balance left by 275. Write the refund as −275 cents. Adding that signed movement leaves 1875 cents.
  3. A workshop packs 3 kits. Each kit costs 250 cents plus a 50-cent label. Calculate 3 × (250 + 50) = 900 cents. The parentheses group one kit so all three include a label.
  4. The expression 3 × 250 + 50 totals 800 cents. It describes three kits and one label for the order. The grouping changed the story.

Try it and check

Start with 900 cents, refund 110 cents, and receive 60 cents. Write the signed movements and the ending amount. Then write an expression for four kits that each use two 25-cent labels.

Check: −110 and +60 give a combined movement of −50 cents, so the ending amount is 850 cents. Four groups of two labels cost 4 × (2 × 25) = 200 cents. Draw a small number line if the refund sends you in the wrong direction.

Apply it to an Umicom project

Use the results as expected values for a small synthetic Bank receipt test. Record both movement and closing amount so a reviewer can see what each figure represents.
