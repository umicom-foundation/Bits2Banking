What you will learn

Turn an input rule into a table and explain the slope using its units.

Read a function

A function is a rule that gives one output for each permitted input. In C(n) = 300 + 150 × n, the input n is a whole number of badges. The output C(n) is the total in cents. Read C(2) as “the cost when n is 2.”

Work it through

  1. Put badge counts along a horizontal number line and cost in cents up a vertical number line. Each line is called an axis. A point such as (2, 600) has two coordinates, one on each axis.
  2. Compare (1, 450) and (3, 750). The cost rises by 300 cents when the quantity rises by two badges.
  3. Divide the change in cost by the change in quantity: 300 ÷ 2 = 150 cents per badge. This slope describes how quickly the straight-line rule increases.
  4. Read the starting cost at zero badges. It is 300 cents. Mark just the whole-number points when you mean actual allowed badge orders.

Try it and check

A different order follows C(n) = 500 + 80 × n. Find C(0), C(3), and the slope. Name the unit of each answer.

Check: 500 cents, 740 cents, and 80 cents per item. If your slope is 240, divide the 240-cent change by the three-item change.

Apply it to an Umicom project

Create a two-column practice table for a future Umicom Trader or Media chart. Use axis labels with units and include the data table alongside the chart so a learner can read the points without relying on colour.
