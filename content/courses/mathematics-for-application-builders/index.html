Mathematics for Application Builders

Begin with counting and money. Follow the same community workshop into algebra, functions, graphs and first calculus.

Before you start

No programming or earlier maths course is assumed. Use paper and a pencil, a calculator if you like, and the answer checks. The quantities are fictional.

Lessons

  1. Count, group and keep track of units

    Read place value and use addition, subtraction, multiplication and division while keeping track of units.

  2. Describe a part in three ways

    Convert between a fraction, a decimal and a percentage, then calculate a part of an amount.

  3. Follow increases, decreases and grouping

    Use a signed number to describe a direction of change and use parentheses to explain an arithmetic decision.

  4. Find a missing number and prove it

    Use a letter for a missing number, then check the answer in the original equation.

  5. Make a function and read its graph

    Turn an input rule into a table and explain the slope using its units.

  6. Zoom in on a changing rate

    Understand a limit by shrinking an interval and find the derivative of a simple square rule.

  7. Build up a total with integrals

    Use rectangles to approximate how much has accumulated and connect that sum to a definite integral.
