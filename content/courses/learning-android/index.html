Android Development

Build a small lesson counter for an Android device or emulator. Begin with the development tools, run the generated application, then connect a button to visible screen state.

Start here

No previous course is required. You may read without installing tools. To do the practical work: Install Android Studio, its recommended Android SDK and an emulator system image, or prepare a supported Android device. Create an Empty Activity project in Kotlin and run the unchanged template first. Lesson 1 describes the process; lesson 2 repeats the required project settings.

For a slower introduction to commands and files, use the terminal setup lab. Return here afterwards; it is a reference, not another required course to finish first.

Follow these lessons in order

  1. Set up Android development and launch a small app
  2. Connect a button to visible Android screen state

What you will practise

Create and locate a source file, follow the build or run command, read the output, change one behaviour and check the result. Each lesson includes a setup recap and recovery steps. Use a separate practice directory so experiments do not overwrite the repository example.

Continue after these lessons

Navigation, durable progress, accessibility, device testing and Framework service integration. These are planned topics; the two introductory lessons do not constitute a complete language or platform course.
