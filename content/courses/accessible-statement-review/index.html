Before you start

You can save and open a local HTML file. The introductory HTML and CSS courses explain elements, attributes and selectors.

Use only the supplied training figures in these activities. The paper exercises work without an account.

Lessons

  1. Build a readable statement table

    Describe a statement as a captioned table with explicit column headers and inspect it in a narrow window.

  2. Filter posted rows with a status message

    Use a native checkbox to show only posted rows and announce the number of visible records.
