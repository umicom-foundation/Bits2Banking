Multikernel systems and workload isolation

Study processes, virtual machines and native kernel instances through a six-lesson learning path. Run a short C23 exercise and design a follow-up functional experiment.

The six core lessons are followed by two practical lessons on memory authority and independent boot evidence.

Before you begin

Review Learning C and Introduction to Operating Systems as needed.

Lessons

  1. Choose an execution boundary
  2. Tell startup from readiness
  3. Design a small control message
  4. Track buffer ownership
  5. Recover a domain without losing evidence
  6. Qualify a kernel experiment
  7. Check a core-owned memory range
  8. Qualify a bootable release in stages
  9. Separate firmware inventory from hart entry

Run the lab and study offline

Lesson three explains how to compile and run the local byte-validation example. The last lessons design experiments and identify the additional evidence needed to qualify a guest or hardware.
