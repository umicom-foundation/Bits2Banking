Observe a bank account at a retained revision

A ledger revision counts accepted operations in one practice database. An account can have the same booked balance at two revisions and a different amount available to spend. You need the revision, the currency and the scale to understand what a balance means.

Calculate the three amounts

Booked is the amount recorded by completed postings. Reserved is the part set aside for an outstanding operation. Available is booked minus reserved in this practice ledger. GBP at scale 2 uses pence, so 15,000 minor units is GBP 150.00.

Run the practice checks

  1. Use the Umicom Framework source directory with CMake, Ninja, a C23 compiler and SQLite development files available.
  2. Configure and build the standalone review. It creates synthetic accounts and uses disposable SQLite files for its tests.
  3. Run the selected tests. Expect five passes. One test reopens the saved practice ledger before comparing the reserved balance with the balance after posting.
cmake -S examples/bank_review -B build/bank-history -G Ninja -DUMICOM_BANK_REVIEW_SQLITE=ON
cmake --build build/bank-history
ctest --test-dir build/bank-history --no-tests=error --output-on-failure -R 'account-observation'

Read your own practice database

When your Umicom Bank installation includes the historical account command, supply an existing practice database, an account ID and a retained decimal revision. Replace the example path and account with your own practice values.

.\umicom-bank-console.exe --observe-account 'C:/practice/bank.sqlite' a1 7

Observed revision is the point in history you requested. Loaded revision is how far the local ledger had advanced when you opened it. If the account was opened later than the requested point, the command reports that it cannot find the account at that revision. If the revision is beyond the loaded ledger, enter an earlier decimal revision. Use only local practice data for this exercise.

Read the Framework contract

UmiBankOperationsObserveAccountAtRevision reconstructs earlier state by applying the retained operations in order to a separate copy. The returned balance includes its revision. A refused query leaves the caller's earlier result intact.

Practice

Explain why revisions 7 and 9 give the same available amount but different booked and reserved amounts. Then describe what you expect if you request revision 2 for an account opened at revision 3. Write the revision beside every amount you quote.
