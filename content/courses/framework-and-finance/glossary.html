Words used in these courses

Read these definitions alongside the worked examples. A word can have a more specialised meaning in a particular system.

API

An interface through which one part of a program requests work from another.

Archive

A stored representation of data; reading it does not execute a business action.

Balance

An amount measured under stated accounting rules at a particular point.

Callback

A function supplied so another component can call it when an event occurs.

Contract

The inputs, outputs and guarantees promised by an operation.

Currency

The unit identifying a kind of money.

Draft

An editable working copy that may differ from its saved file.

Event

A record that something happened, such as an acknowledgement or a file change.

Framework

Reusable services and contracts shared by applications.

Idempotency

A property in which repeating the same logical request does not repeat its business effect.

Inference

Using a trained model to calculate an output.

Journal

A record of accounting entries belonging to a transaction.

Ledger

An organised collection of posted accounting records.

Lifecycle

The states and events through which an item progresses.

Model

A representation of information used by software; its meaning depends on the domain.

Reservation

Funds set aside for an action without necessarily posting a debit yet.

Revision

An identifier for a particular version of state.

Settlement

Fulfilment of obligations under the applicable process; not merely receipt of a message.

Snapshot

A captured view of state that can become stale.

Transaction

A group of operations with defined completion rules; database and business transactions have different scopes.
