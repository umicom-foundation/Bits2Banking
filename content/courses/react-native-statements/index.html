React and Native Statement Data

Applied native courses · Connected learning paths

Build a small React view for a fictional statement produced by C23. Read props, filter a table by state, and keep loading and error messages distinct from posted totals.

Start on paper with the practice snapshot. Optional browser work requires an existing local React project that supports JSX and JSON imports. The native exercises use C23 and D. Reading requires no accounts or packages.

Learn in order

  • Pass the native result as props
  • Filter rows without changing the posted total
  • Show loading, empty and error states
