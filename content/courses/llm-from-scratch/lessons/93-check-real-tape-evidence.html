1. What does “passed” mean?

An application may compile successfully without calculating the right answer. A test may be not run, may fail, or may pass. We must not turn the first two outcomes into a passing result. This lesson introduces a bounded Framework acceptance contract, not a second testing engine.

2. Three real tests that must run

TestBusiness analogyEngineering question
GradientsRecalculate the totals on a financial report independentlyDo the derivatives agree with finite differences?
Memory budgetA payment must not partially post if funds are unavailableDoes failure preserve the previous tape state?
RewindRepeatedly opening a saved document must not duplicate its contentsDoes each cycle restore retained allocations?

3. Formula explained

error = |analytical gradient − numerical gradient|

A gradient is a number describing how changing a model weight changes the loss. The vertical bars mean absolute value—ignore whether the difference is positive or negative. If the analytical gradient is 0.0234 and the numerical gradient is 0.0231, error = 0.0003. If the approved threshold is 0.0008, then 0.0003 is within the permitted difference.

4. Native C23 contract

#include "umicom/ai/training/rotary_acceptance.h"
/* The three observations below are ILLUSTRATIVE.
   They are not actual CTest results. */
UmiAiTrainingRotaryAcceptanceObservation example[3] = {
    {0U, 1, 1, 72U, 0.0003},
    {1U, 1, 1, 6U, 0.0},
    {2U, 1, 1, 48U, 0.0}
};
UmiAiTrainingRotaryAcceptanceReport report;
UmiStatus status = UmiAiTrainingRotaryAcceptanceEvaluate(
    example, 3U, 0.0008, &report);
/* report.accepted describes ONLY the supplied example evidence. */

The function never executes the real tests. They must already have run through CTest or the Framework's test service. Passing its fixture regression proves only that the interpreter accepts valid records and rejects bad ones.

5. Practice

Which outcome should be recorded if the gradients test never executed but the memory and rewind tests passed? Why is “two out of three passed” not sufficient to approve an optimisation?

Show answer

The evidence is incomplete; the acceptance gate must not approve the release. A missing gradient test leaves numerical correctness unverified.
