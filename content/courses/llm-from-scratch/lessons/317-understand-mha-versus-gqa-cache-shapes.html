Learning objective

Distinguish Q heads from K/V heads.

Technical foundation

A model with 16 query heads and 4 K/V heads has a grouping ratio of 4. At identical layer count, sequence length, head width and precision, its raw K/V footprint is one quarter of a 16-KV-head model. This arithmetic does not automatically prove model compatibility or quality.

A capacity estimate is not the same as an allocation or a runtime measurement. Numerical correctness requires independent evidence against the canonical Transformer implementation.

Worked investigation

Identify each dimension, unit and assumption in the example. Change exactly one quantity and recalculate. State which result is measured and which is estimated.

Native C23 connection

UmiAiTrainingInferenceMemoryPlan estimates raw cache payload with checked arithmetic. It does not execute inference or allocate K/V tensors. Model evaluation continues through the canonical Framework decoder and qualification components.

Exercise

What structural requirement is commonly enforced by a simple uniform GQA grouping?

Reveal the worked answer

The query-head count is divisible by the KV-head count.

Further exploration

Construct another configuration and document any unmeasured memory overhead, numerical deviation or scheduling effects separately.
