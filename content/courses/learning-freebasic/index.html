Learning FreeBASIC

Begin with a source file and a compiler, then learn values, control flow, records and a reviewed C boundary.

Read without tools. Practical work needs a supported FreeBASIC compiler, a text editor and terminal; the C boundary additionally needs a compatible C toolchain.

  1. From typed text to a running FreeBASIC program
  2. Names, values and number types
  3. Text input, strings and validation
  4. Expressions, comparisons and decisions
  5. Loops, arrays and bounds
  6. Procedures, ByVal and ByRef
  7. Records, reusable modules and files
  8. Call a small C service from FreeBASIC

Study one step at a time

Read the explanation, predict the result, perform the exercise in a separate practice folder, then compare the result and recover from errors before continuing. A compiler check, a mathematical example and a full product qualification are different kinds of evidence.
