Finance, Bitcoin and systems learning routes

Choose one subject and follow its numbered route. These are separate courses: you do not need to learn blockchain to write a web server or study treasury software to learn Linux.

If computers, files and programs are new, begin with Introduction to Computers and then Learning C. Source-reading and construction courses build on these foundations.

A useful study routine

  1. Open the course contents and check its prerequisites.
  2. Read the next lesson rather than selecting unrelated advanced topics.
  3. Trace the diagram or small program on paper.
  4. Answer the exercise, then compare the explanation.
  5. Follow the related Umicom source link and identify the same idea in real code.
  6. Continue only when you can explain the result in your own words.

The new courses currently contain their opening three-lesson modules. The existing web-server course has seven lessons. Later modules are described on each course page. Source files and browser editions remain available together; an introductory exercise does not certify a production system.
