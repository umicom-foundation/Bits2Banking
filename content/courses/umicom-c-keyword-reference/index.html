Umicom C checked integer keywords and syntax

Learning pathways

Read every dedicated word used by the current checked integer entry and its counted statements. Trace complete original programs before compiling them with Umicom C.

Start with paper. For the optional practical run, use an Umicom C build that implements the counted-loop and input-profile commands. Type umicom-c --help before copying any example.

Lessons in order

  • Enter the program and return a whole number
  • Choose with if, else, true, and false
  • Repeat, skip and stop a counted loop
  • Read the checked input entry and its limits
  • Guard calculations with AND and OR
  • Choose an action and classify source
  • Compare negative division and remainder
