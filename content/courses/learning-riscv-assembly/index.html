Learning RISC-V Assembly

Read the small Assembly bridge used by a real Umicom Kernel program. Learn each instruction's job before changing anything.

Read on screen or trace values on paper. No installation is needed to read. Optional commands need the prepared environment described in the Kernel guide. This is an introductory section, not a complete language or hardware reference.

  1. Follow a system call from C into Assembly
  2. Understand entry, return and program exit
  3. Preserve register values when execution is interrupted
