Choose your learning subject

Start with files, folders and simple programs. Then choose a subject that helps you build something you understand. You do not need to study every language before making a first application. Each course names its prerequisites and distinguishes available lessons from later topics.

How to use a lesson

  1. Read what the lesson assumes and revisit a prerequisite when needed.
  2. Read the worked example before running a command. Choose your own practice folder.
  3. Predict the result, try the exercise and compare it with the explained answer.
  4. Follow the source link to see how the idea relates to Umicom.
  5. Continue using Previous and Next; filenames are stable addresses, not always the reading order.

Reading formats and practical limits

New lessons have matching HTML and Markdown. HTML is for browser reading; Markdown is an editable manuscript for later publishing. Downloading a source file does not install a course plugin or a language runtime. Future books, documents and video scripts need editorial review; they are not produced automatically by these pages. The examples describe expected results, not a claim that every machine and toolchain has been tested.

Mobile and native-language starter courses

Each course explains its own setup, expected results and troubleshooting steps.

  • Learning Kotlin — Write and check a small lesson-progress program. Start with installing a JDK and the Kotlin compiler, then create a file, compile it and explain its values and functions. Two introductory lessons; later topics are listed separately.
  • Learning D Language — Create a native program with the D compiler. Learn how source becomes an executable, then check a function with input validation and unit tests. Two introductory lessons; later topics are listed separately.
  • Android Development — Build a small lesson counter for an Android device or emulator. Begin with the development tools, run the generated application, then connect a button to visible screen state. Two introductory lessons; later topics are listed separately.
  • Learning Flutter — Create a small lesson counter using Dart and Flutter. Begin by running the generated project, then learn widgets, state, callbacks and automated interaction checks. Two introductory lessons; later topics are listed separately.
