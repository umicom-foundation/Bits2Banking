Choose and repeat with Go

Course contents Previous lesson: Write a first Go program Next lesson: Describe data and behaviour

Carry a loop through a short list, then choose one way to respond to its total.

Follow one position at a time

The three-part for in Go covers the same basic pattern as the C loop. range makes it easier to walk a slice, which is a sequence of values in this example. _, cents uses the blank identifier to ignore the position. Unlike a C switch, an ordinary Go switch does not fall through by default.

Keep the filter readable

The next program uses a toy rule to ignore negative values. That rule is only for demonstrating control flow. A real statement would often retain a negative transaction and use a separate posted flag.

Keywords and examples

Each row shows a separate example. Some belong inside a function, and some use a name introduced earlier. The full program below is the first one to copy.

Words in this lesson
WordExampleMeaning
ifif total > 0 { report() }Run the block when the condition is true. Go requires braces for this body.
elseif total > 0 { report() } else { reset() }Take the other branch when the condition is false. Write else on the same line as the closing brace of the first block.
forfor i := 0; i < 3; i++ { total += i }Use setup, a condition and an update. Go does not surround them with parentheses.
rangefor i, cents := range amounts { use(i, cents) }Walk a slice and receive the index and value. The meaning of the variables depends on the thing ranged over.
breakif total > 100 { break }Leave the closest surrounding for, switch or select, unless a label selects another permitted target.
continueif cents < 0 { continue }Skip to the next iteration of the surrounding loop.
switchswitch code { case 1: report(); default: reset() }Choose a matching clause. The chosen clause normally ends without executing the next one.
casecase 1: report()Mark one matching clause of a switch, or a communication clause of a select.
defaultdefault: reset()Use a fallback in a switch. A default in select instead lets the statement proceed when no communication can proceed.
fallthroughcase 1: report(); fallthroughIn an expression switch, explicitly enter the next clause. This belongs at the end of a non-final clause.
gotoif bad { goto done }; report(); done: returnJump to a permitted label in the same function. Use normal branches for straightforward decisions.

Trace the steps on paper

Pseudocode uses ordinary words to show the order of steps. Read the plan one line at a time before reading the program.

START total at 0
FOR each amount
    IF amount is negative, skip this turn
    ADD amount to total
IF the total equals the practice result, label it as practice
OTHERWISE label it as unexpected

Run the complete example

Save the whole program as practice.go. Open a terminal in that folder, then enter the command shown for your language.

package main

import "fmt"

func main() {
    amounts := []int{425, -25, 100}
    total := 0
    for _, cents := range amounts {
        if cents < 0 {
            continue
        }
        total += cents
    }
    switch total {
    case 525:
        fmt.Println("practice total", total)
    default:
        fmt.Println("unexpected", total)
    }
}
go run practice.go

Expected line

practice total 525

If the terminal cannot find go, complete the setup for your operating system before running the command. If Go reports a missing package or main function, check that the whole program was copied and saved as practice.go. The paper trace still works without a toolchain.
