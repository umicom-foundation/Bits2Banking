Go Keywords for Beginners

Read all reserved Go words through short programs about names, decisions, data and workers.

This reference covers all 25 reserved words in the Go language specification. The example programs use forms available in Go 1.22 and later. The course also distinguishes the built-in names and punctuation learners see beside these words.

A keyword is a word that the language grammar reserves for a specific job. A value name such as cents is a name you choose. Syntax describes where the pieces can go. Meaning describes what happens when the program runs.

No earlier coding class is needed. Start with pencil and paper. To run a program, save it as a plain text file with the .go ending. The Go command builds and runs the current example as one operation.

Follow the lessons

  1. Write a first Go program Find the package, the entry function and two ways to give a value a name.
  2. Choose and repeat with Go Carry a loop through a short list, then choose one way to respond to its total.
  3. Describe data and behaviour Group named fields, find values by a key and describe what an object can do.
  4. Pass a result between workers Send one value through a channel, know when cleanup runs and avoid depending on timing.
