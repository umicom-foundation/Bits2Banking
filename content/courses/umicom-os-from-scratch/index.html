Umicom OS from Scratch

Understand the existing OS foundation through source reading, a real parser lab, startup policy and evidence that identifies what was tested.

Initial course section: original hosted labs and source-reading lessons. A complete bootable system, installer and hardware course are not yet provided.

Prerequisites

Basic C arrays, functions and return values; a C23-capable compiler, CMake and Ninja; the corresponding Umicom source checkouts. You do not need administrator rights for these hosted labs.

Lessons

  1. A system has several layers
  2. Build one real OS component
  3. Plan startup before executing it
  4. Keep rejected state separate from recovery
  5. Know which bytes you booted
  6. Separate a check from a release claim
  7. Make recovery decisions testable
  8. Verify the guest environment

Work with the source

The lab lives at labs/native/os-boot-plan in Bits2Banking. It links source from the named OS or Kernel checkout. It does not carry a diverging copy of the implementation. Use a new build directory and keep logs from your own runs.

Expected results in lessons describe what to check; they are not evidence that a compiler, guest or hardware run has already succeeded.
