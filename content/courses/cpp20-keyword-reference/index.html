C++20 Keyword and Token Reference

Read C++20's 81 reserved keyword spellings, 11 reserved alternative operator words and four identifiers with special meaning. Each has an original example.

Before you start

Begin after Learning C++ or keep that course open beside this reference. Start with paper and read each snippet as an individual example. A keyword is a reserved spelling with a language meaning. A contextual identifier has a special meaning in certain positions and can be an ordinary name elsewhere. The C++20 mode and module setup of your chosen compiler matter when compiling examples.

Lessons

  1. Name the kind of value

    Read C++20 type and literal keywords and predict which values they represent.

  2. Choose what happens next

    Recognise branches, repeated steps and ways to leave them, and trace a short repeated calculation.

  3. Declare names, storage and size

    Distinguish declarations that infer a type, qualify access, control storage, or inspect an object's size.

  4. Organise data and actions into objects

    Read class, member-access, dispatch and naming keywords, and distinguish two contextual class identifiers.

  5. Read ownership, errors and conversions

    Recognise allocation, exception handling and named conversions, and predict the result of a checked conversion.

  6. Ask the compiler to compute and check

    Distinguish constant evaluation, static checks, reusable type templates and constraints.

  7. Read modules, coroutines and reserved words

    Recognise module and coroutine syntax and tell when an example requires a configured toolchain or intentionally fails.

  8. Read word forms of operators

    Match all eleven reserved alternative operator spellings to their symbol forms and distinguish logical from bitwise operations.
