Declare names, storage and size

Course contents Previous lesson — Choose what happens next Next lesson — Organise data and actions into objects

What you will learn

Distinguish declarations that infer a type, qualify access, control storage, or inspect an object's size.

Read the words in context

A declaration introduces a name and gives the compiler information about it. Storage duration is how long storage exists. Linkage determines whether declarations can refer to the same entity across scopes or source files. Alignment places an object at an address that meets a boundary requirement.

Reserved keywords in this lesson

SpellingMeaningRead this example
autoLets the compiler infer a type from an initializer in this example.auto movement = 25;
decltypeNames the type determined from an expression or entity. The form can preserve references.int planned = 25; decltype(planned) actual = 24;
constPrevents modification through that const view.const int posted_cents = 1750;
volatileMarks accesses that must follow volatile rules. It provides neither atomic operations nor inter-thread synchronisation by itself.volatile int simulation_input = 0;
staticInside a function, gives a local variable static storage duration. Other uses include class members and file-level names.int next_id() { static int id = 0; return ++id; }
externCan declare a variable defined elsewhere, allowing another file to use it.extern int saved_receipt_count;
inlineAllows suitable identical definitions in multiple source-file translation units when the rules are met. The compiler chooses whether to inline calls.inline int one_cent() { return 1; }
thread_localProvides separate storage for each thread, an independently scheduled path of execution.thread_local int thread_receipt_count = 0;
mutableAllows an eligible member to change even through a const instance of its class.struct CacheCount { mutable int reads = 0; };
typedefIntroduces another name for an existing type without creating a new type.typedef int CentCount;
usingCan introduce a type alias, or bring a name into a scope in other forms.using CentCount = int;
alignasRequests an alignment for an object or type. The requested alignment must meet language and implementation constraints.alignas(int) unsigned char sample = 0;
alignofReports a type's alignment requirement in bytes.auto boundary = alignof(int);
sizeofReports a type or object's size in bytes. Different platforms can report different results.auto cents_bytes = sizeof(int);

Try it and check

After calling next_id twice from the same thread in this simple program, what are the two results? What changes if the local variable stops using static?

Check: The results are 1 then 2. With a fresh automatic local variable initialised to zero on each call, both results are 1.
