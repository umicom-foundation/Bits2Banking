Introduction to Version Control

Where this course fits: 1. Computers and first programs. After editing and saving files, learn how to record and review changes.

Before you begin: No previous computing or programming knowledge.

Beginner sequence · Return to this subject

Learn how Git records work, how to inspect a change before sharing it, and why an Umicom application records exact Framework revisions. The first practical exercise uses a separate practice repository.

Read on screen or trace values on paper. No installation is needed to read. Optional practical work needs Git, a text editor and a separate practice folder. This is an introductory section, not a complete language or hardware reference.

  1. Files, snapshots and history
  2. Review and record a change
  3. Remotes and safe updates
  4. Submodules and application dependencies
