# Umicom website branding

The Umicom logo, symbol and Windows favicon are maintained in [Umicom Framework](https://github.com/umicom-foundation/umicom-framework/tree/main/resources/brand). The website uses unchanged copies of the original assets. To update them, copy the approved Framework artwork into this directory with the repository's preparation command.

- `umicom-icon-on-dark.svg` is used in the website header.
- `umicom.ico` is the browser favicon.
- `umicom-logo.png` is used for the home page wordmark.
- The remaining source SVG and PNG variants support light and dark displays.

The website uses the operating system's text fonts; no font redistribution is required.
