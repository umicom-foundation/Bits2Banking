# Working examples

These are the complete files shown in the chapters. Start with the chapter that introduces the language, then open its matching folder here. Run code in a practice directory, not against real financial or customer data.

The Python exercises use only the standard library. The C and C++ examples require suitable compilers. The Java example requires a JDK. The browser task board contains its HTML, CSS and JavaScript files together; the PHP example requires PHP for its local development server. The CMake example shows a small build and test project.
