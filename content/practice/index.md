# Practise a small example

![Umicom Foundation](../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Choose one example. Read the expected result, change one input, then run it again and compare what happened. Use the linked lesson when you want to understand the code behind the result.

| First exercise | What can I change? | Where does it run? |
| --- | --- | --- |
| [Bash and PowerShell practice](shell/index.md) | Change a practice folder, filename or command. | In this browser tab with a fixed lesson workspace. |
| [Run a compiled Umicom C program in the browser](../lessons/06-umicom/running-a-cvm-program.md) | Change the integer inputs or build a different bytecode artifact locally. | The browser worker runs the selected artifact after you complete the setup. |
| [Redraw a web graphic](../labs/web/web-graphics/monthly-deposits.html) | Change a table value and redraw the chart. | In this browser using the chart and its reading table. |
| [Native reserve statement lab](../umicom/native-statement-web-lab.md) | Change the adjustment in cents and read the calculated movement. | The [exercise form](../labs/statement-cvm-web/index.html) calls your configured local Umicom Framework host. |
