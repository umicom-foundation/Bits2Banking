# Original books and downloadable editions

Bits to Banking includes the original book manuscripts alongside its newer lessons. The learning website provides chapter-by-chapter navigation. The **book catalogue** brings together complete editions generated by the existing BookForge publishing tools.

Open the [original book catalogue](https://umicom-foundation.github.io/Bits2Banking/archive/books/) to browse published book websites. Available PDF, DOCX and EPUB editions are listed on the [downloadable books page](https://umicom-foundation.github.io/Bits2Banking/archive/books/downloads/).

If an edition is not listed, it may not have been generated in the current publication. The source manuscripts remain in the repository under [`dropzone/`](https://github.com/umicom-foundation/Bits2Banking/tree/main/dropzone). To inspect the original *Islam: Blueprint for Life* chapters, use the [volume's reading page](../v001_islam_blueprint_for_life/index.md).

The educational website links to the relevant Umicom repositories where practical code examples and current API contracts are maintained.
