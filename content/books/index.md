# Books and longer reading

The website chapters are available for reading in sequence or individually. A longer book can collect related chapters into a single edition with an introduction, exercises and references.

The existing [Bits2Banking repository](https://github.com/umicom-foundation/Bits2Banking) also contains the BookForge and dropzone publishing tools. Existing manuscripts and publication outputs remain separate from these new lessons while the book catalogue is organised.

## Islam: Blueprint for Life

Read [Volume 1 — Islam: Blueprint for Life](../v001_islam_blueprint_for_life/index.md), including its existing ten chapters. Topics include purpose, worship, honesty in trade, money, banking, financial systems, Islamic finance and governance. The [illustrations](../v001_islam_blueprint_for_life/illustrations.md) accompany the reading.

The original book files remain under [`dropzone/documents/islam_blueprint_for_life`](https://github.com/umicom-foundation/Bits2Banking/tree/main/dropzone/documents/islam_blueprint_for_life), with existing BookForge publication tools unchanged.
