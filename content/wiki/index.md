# Umicom contributor wiki

![Umicom Foundation](../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Start with one thing you want to change. Open its source guide, make one small edit, and check the result before moving to the next item.

| I want to work on | Start here |
| --- | --- |
| A tool that runs or compiles Umicom C | [Compiler and toolchain](toolchain.md) |
| A native application using the shared framework | [Framework SDK](framework-sdk.md) |
| A Studio command that refuses to build a project | [Studio build command](studio-build.md) |
| A bootable image or the Setup Centre wizard | [OS and Kernel boot media](boot-media.md) |
| A student guide or a help answer | [Course maintenance](course-maintenance.md) |

A source file is what the contributor edits. A generated file is what a tool produces from that source. In a contribution, show which source changed and give a command that reproduces the generated result.

If you are setting up a new Windows workstation, start with [PowerShell setup](../simple-steps/powershell-setup.md), then [check your system](../simple-steps/system-checks.md). When you can open a terminal, choose one route above.
