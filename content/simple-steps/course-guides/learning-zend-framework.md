# Learning Zend Framework

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open the isolated component exercise. Write down which package and namespace it uses. [Frameworks, packages and Laminas](../../courses/learning-zend-framework/lessons/01-frameworks-packages-and-laminas.html)
2. Put a title with angle brackets into the local template example. Apply its HTML text-escaping operation before displaying it. [Output context and readable text](../../courses/learning-zend-framework/lessons/02-output-context-and-readable-text.html)
3. View the page and preserve the package name alongside the test result. [Output context and readable text](../../courses/learning-zend-framework/lessons/02-output-context-and-readable-text.html)

**Check your result.** The page still shows the angle brackets as text, and the old and new package names are recorded separately.
