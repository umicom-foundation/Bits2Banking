# LLM from Scratch

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write down an expected next token and trace the numerical prediction example by hand. [Lesson 01 — From Source Text to Learned Predictions](../../courses/llm-from-scratch/lessons/01-from-source-text-to-learning.html)
2. Assign sample sentences to separate training and evaluation lists and record where each came from. [Lesson 02 — Training Data, Provenance and Evaluation Splits](../../courses/llm-from-scratch/lessons/02-training-data-and-evaluation.html)
3. Encode the same short sentence twice with one vocabulary. Compare the IDs, then use the loss lesson to check a prediction. [Lesson 03 — Tokens, Vocabulary and Text Encoding](../../courses/llm-from-scratch/lessons/03-tokens-vocabulary-and-encoding.html)

**Check your result.** The token IDs stay stable for both runs, and the examples reserved for evaluation stay out of training.
