# Build a weight-management companion with Umicom Framework

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. List the fields the learner enters, then list the identity and revision fields supplied by the application. [Define the observation before the screen](../../courses/weight-management-framework/lessons/01-define-the-observation-contract.html)
2. Use the supplied parser to check the example and one refused input. Keep the unit next to the output. [Convert kilogram text into exact grams](../../courses/weight-management-framework/lessons/02-convert-kilograms-without-rounding.html)
3. Follow the client’s save exercise and record which reviewed revision is kept when an edit fails. [Save a reviewed revision without losing a newer draft](../../courses/weight-management-framework/lessons/04-save-revisions-with-the-existing-record-service.html)

**Check your result.** The sample text 80.250 becomes 80,250 grams. A rejected edit preserves the last reviewed value.
