# Learning React

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open the prepared React editor linked in the lesson. Add the `LessonCard` example and identify its title and minutes inputs. [Components and their inputs](../../courses/learning-react/lessons/01-components-and-inputs.html)
2. Run the stateful example. Click Record one exercise and watch the count change. [Clicks and visible state](../../courses/learning-react/lessons/02-clicks-and-visible-state.html)
3. Add a Reset button that calls `setCompleted(0)`. Try click, reset, click. [Clicks and visible state](../../courses/learning-react/lessons/02-clicks-and-visible-state.html)

**Check your result.** The displayed count starts at 0 and moves to 1, back to 0, and up to 1 again.
