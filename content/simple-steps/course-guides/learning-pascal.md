# Learning Pascal

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Build the Pascal progress lab and run its `progress` program with argument `2`. [Values, functions and input validation](../../courses/learning-pascal/lessons/02-values-functions-and-validation.html)
2. Run it again with `0` and `5`. Compare each remaining count with the five-item total. [Values, functions and input validation](../../courses/learning-pascal/lessons/02-values-functions-and-validation.html)
3. Run it with `6`, then with `abc`. In PowerShell, check `$LASTEXITCODE` immediately after each run. [Values, functions and input validation](../../courses/learning-pascal/lessons/02-values-functions-and-validation.html)

**Check your result.** The valid calls report 3, 5 and 0 remaining. The bad calls report range and conversion errors, respectively, with exit status 1.
