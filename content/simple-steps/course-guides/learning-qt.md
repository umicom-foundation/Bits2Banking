# Learning Qt

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Select a compatible Qt 6 kit and installed Framework SDK. Configure and build the `qt-profile` lab with its documented prefixes. [Build a small Qt consumer of the Framework SDK](../../courses/learning-qt/lessons/02-build-a-small-qt-consumer.html)
2. Launch the example and find the name field, Check name button and result line. [A window, a program and an event loop](../../courses/learning-qt/lessons/01-window-program-and-event-loop.html)
3. Resize the window and see how the controls move. Close it from the window controls. [A window, a program and an event loop](../../courses/learning-qt/lessons/01-window-program-and-event-loop.html)

**Check your result.** One window opens with the three controls. When you close it, the program returns control to the terminal.
