# AngularJS and Legacy Statement Screens

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Record the amount and state of fictional statement entries 101, 102 and 103. [Read a legacy statement component](../../courses/angularjs-legacy-statements/lessons/01-read-a-legacy-component.html)
2. Find `track by row.id` in the archived template. Follow the ID that ties each row to its data. [Follow entry identities and empty states](../../courses/angularjs-legacy-statements/lessons/02-follow-entry-identities-and-empty-states.html)
3. Trace the template with an empty entry list. Find which message would appear when there are no rows. [Follow entry identities and empty states](../../courses/angularjs-legacy-statements/lessons/02-follow-entry-identities-and-empty-states.html)

**Check your result.** Entries 101 and 102 account for 1,750 posted cents. Entry 103 is pending and the empty report has its own message.
