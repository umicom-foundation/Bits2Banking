# Introduction to Programming

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Copy the small greeting example to `greeting.c` in a practice folder. Find the quoted text sent to `puts`. [Instructions, source files and results](../../lessons/02-programming/introduction-to-programming/01-instructions-source-and-results.md)
2. In PowerShell with GCC ready, type `gcc -std=c23 -Wall -Wextra greeting.c -o greeting.exe`. If it succeeds, type `.\greeting.exe`. [Instructions, source files and results](../../lessons/02-programming/introduction-to-programming/01-instructions-source-and-results.md)
3. Change the greeting to `My first Umicom learning project.` Save, compile and run the program again. [Instructions, source files and results](../../lessons/02-programming/introduction-to-programming/01-instructions-source-and-results.md)

**Check your result.** Each successful run prints one line. The second run prints only your new greeting.
