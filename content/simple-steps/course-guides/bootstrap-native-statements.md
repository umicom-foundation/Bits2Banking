# Bootstrap and Native Statement Reports

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open the worked statement markup. Locate its caption, column headings and the reference shown for each row. [Lay out a readable statement table](../../courses/bootstrap-native-statements/lessons/01-lay-out-a-readable-statement-table.html)
2. Follow the C reporter from validation to its HTML output. Compare the approved rows with the visible labels. [Export the page from C23](../../courses/bootstrap-native-statements/lessons/02-export-the-page-from-c.html)
3. Use `250.50` in the lesson’s whole-cent correction example. Write a message that tells the reader what to enter instead. [Display native validation feedback](../../courses/bootstrap-native-statements/lessons/03-display-native-validation-feedback.html)

**Check your result.** The posted amount is still 1,750 cents. The correction feedback identifies the field and asks for a whole number of cents.
