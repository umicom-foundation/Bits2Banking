# Oracle Database Ledger Practice in C23

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Record the exact amount and its scale in the lesson’s small numeric projection. [Read an exact numeric projection in Oracle](../../courses/oracle-database-c23-ledger/lessons/01-read-an-oracle-number.html)
2. Draw the input parameter and output fields. Use the example to mark which indicator says a value is absent. [Follow a named OCI bind and a result indicator](../../courses/oracle-database-c23-ledger/lessons/02-follow-a-named-bind-and-indicator.html)
3. Compare the report for a present zero and a missing adjustment, using the local practice cases. [Keep optional values distinct in a financial report](../../courses/oracle-database-c23-ledger/lessons/03-keep-optional-values-in-a-report.html)

**Check your result.** The report represents an absent adjustment separately from an exact present value of zero.
