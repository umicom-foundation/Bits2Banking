# MINIX OS Foundations

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Choose the release named in the lesson. Record the release and media identity and use a separate guest directory. [Choose a release and an isolated guest](../../courses/minix-os-foundations/lessons/01-choose-a-release-and-isolated-guest.html)
2. Draw the kernel and two server boxes. Put each responsibility in the box that owns it. [Draw the kernel and server boundaries](../../courses/minix-os-foundations/lessons/02-draw-the-kernel-and-server-boundaries.html)
3. Trace one request to a server and the reply back. Label the point at which the caller can continue. [Follow a message and its reply](../../courses/minix-os-foundations/lessons/03-follow-a-message-and-a-reply.html)

**Check your result.** The guest uses its own virtual disk. Your message diagram identifies the sender, reply and component that owns the operation.
