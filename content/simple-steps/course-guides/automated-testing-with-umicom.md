# Automated Testing with Umicom Framework

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write an expected result row for 42 pennies and a refusal row for −1 penny. [Write the expected result](../../courses/automated-testing-with-umicom/lessons/01-write-the-expected-result.html)
2. For the refusal row, start the output at 77. Follow the rule and record the status and output separately. [Write the expected result](../../courses/automated-testing-with-umicom/lessons/01-write-the-expected-result.html)
3. Add a case at zero and record the expected status before using the native practice fixture. [Write the expected result](../../courses/automated-testing-with-umicom/lessons/01-write-the-expected-result.html)

**Check your result.** A refused input leaves the output at 77. A test that only checks the refusal cannot confirm that value.
