# Learning Data and Messaging Services

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write the transfer’s two account updates together. Sketch where the operation commits or rolls back. [Keep related changes together](../../courses/framework-and-finance/data-and-messaging/lessons/transactions.html)
2. In the retry exercise, record a successful outcome for message P7 with amount 250. Trace a second P7 with the same amount. [Recognise the same message twice](../../courses/framework-and-finance/data-and-messaging/lessons/retries-and-envelopes.html)
3. Submit P7 with 300 in the paper trace and keep both message arrivals in the record. [Recognise the same message twice](../../courses/framework-and-finance/data-and-messaging/lessons/retries-and-envelopes.html)

**Check your result.** The repeated P7/250 returns the saved result. P7/300 is a conflict and leaves the original record intact.
