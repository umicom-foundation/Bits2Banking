# Learning Laravel

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Set up the Laravel 12 practice project from the lesson. Confirm `php artisan --version` works. [A route and a response](../../courses/learning-laravel/lessons/01-a-route-and-a-response.html)
2. Add the `GET /learning` route in `routes/web.php`. Start the development server and open `/learning`. [A route and a response](../../courses/learning-laravel/lessons/01-a-route-and-a-response.html)
3. Replace the route's text response with the supplied `lesson` view, passing `Learning C & GTK4` as the title. [A view with data](../../courses/learning-laravel/lessons/02-a-view-with-data.html)

**Check your result.** The route first displays the welcome sentence, then the page displays `Learning C & GTK4`.
