# Introduction to Computers

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write one instruction for a calculator. Name the inputs, the operation and the result you expect. [What does a computer do?](../../courses/learning-computer-architecture/lessons/02-input-instructions-and-results.html)
2. Type a short fictional meeting note in a plain-text editor. Save it as `meeting-note.txt` in your practice folder. [Keep something you can find again](../../courses/learning-computer-architecture/lessons/03-files-folders-and-saving.html)
3. Close the practice note and reopen it from that folder. Compare its text with what you saved. [Keep something you can find again](../../courses/learning-computer-architecture/lessons/03-files-folders-and-saving.html)

**Check your result.** The saved note opens at the path you recorded. You can name the input, instruction and output separately.
