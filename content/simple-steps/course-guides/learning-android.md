# Android Development

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. In Android Studio, create the lesson’s Empty Activity Compose project. Run the template on the emulator and check that it opens. [Set up Android development and launch a small app](../../lessons/15-mobile-development/learning-android/01-install-and-launch.md)
2. Keep a copy of the generated activity outside `app/src`. Use the linked training `MainActivity.kt` and check its package matches your project. [Connect a button to visible Android screen state](../../lessons/15-mobile-development/learning-android/02-state-events-and-checks.md)
3. Run the app again. Tap the completion button three times, then try another tap and press Reset. [Connect a button to visible Android screen state](../../lessons/15-mobile-development/learning-android/02-state-events-and-checks.md)

**Check your result.** The count starts at 0 of 3, stops at 3 of 3 and returns to 0 of 3 when you press Reset.
