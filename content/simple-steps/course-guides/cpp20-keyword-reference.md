# C++20 Keyword and Token Reference

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. List the fields of a fictional receipt. Give each a type, a unit where appropriate and two possible values. [Name the kind of value](../../courses/cpp20-keyword-reference/lessons/01-values-and-types.html)
2. Trace the `continue` example row by row. Mark when the loop adds the current index to the total. [Choose what happens next](../../courses/cpp20-keyword-reference/lessons/02-decisions-and-loops.html)
3. In your local example, remove the `continue` and trace the same three indices again. [Choose what happens next](../../courses/cpp20-keyword-reference/lessons/02-decisions-and-loops.html)

**Check your result.** With `continue`, indices 0 and 2 contribute a total of 2. Without it, index 1 also contributes and the total is 3.
