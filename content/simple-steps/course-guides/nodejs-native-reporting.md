# Node.js and Native Statement Reports

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save the sample snapshot, shape check and reader from the lesson in the same practice folder. Run the reader on the snapshot. [Check a local report](../../courses/nodejs-native-reporting/lessons/01-check-a-local-report.html)
2. Follow the adapter’s call to the native producer. Record the expected units and which process owns the calculation. [Connect a known native producer](../../courses/nodejs-native-reporting/lessons/02-connect-a-known-native-producer.html)
3. Compare the valid, empty and refused fixtures. Write the message and visible report you expect for each. [Diagnose a refused or empty result](../../courses/nodejs-native-reporting/lessons/03-diagnose-a-refused-or-empty-result.html)

**Check your result.** The valid producer result changes the displayed report. A refused result keeps the report’s earlier value.
