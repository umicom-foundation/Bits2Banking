# Rust 2024 Keywords for Beginners

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save and run the names and functions example with a compiler that supports the Rust 2024 edition. [Name values and functions](../../courses/rust-keyword-reference/lessons/01-name-values-and-functions.html)
2. Trace the loop example. Cross out the rows the program skips and count the remaining ones. [Make a decision and repeat](../../courses/rust-keyword-reference/lessons/02-make-a-decision-and-repeat.html)
3. Run the loop exercise after changing one row’s state and compare the new count with your marks. [Make a decision and repeat](../../courses/rust-keyword-reference/lessons/02-make-a-decision-and-repeat.html)

**Check your result.** The example builds for Rust 2024, and the count matches the rows your paper trace kept.
