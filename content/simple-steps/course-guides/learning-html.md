# Learning HTML

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save the example as an HTML file with a page title, a main heading, a paragraph and a numbered list. [A page with meaning](../../courses/learning-html/lessons/01-a-page-with-meaning.html)
2. Open the file in your browser. Check the tab title and look for the visible heading and list. [A page with meaning](../../courses/learning-html/lessons/01-a-page-with-meaning.html)
3. Give `main` the ID `main` and add the lesson’s `Skip to content` link to `#main`. Reload and activate the link with the keyboard. [Links, illustrations and access](../../courses/learning-html/lessons/02-links-images-and-access.html)

**Check your result.** The heading and numbered list render as page content, and the keyboard link moves you to the main content.
