# Learning GTK4

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Build and open the GTK4 activity example using the lab's setup. Find the count label and the Record one exercise button. [Widgets and the event loop](../../courses/learning-gtk4/lessons/01-widgets-and-the-event-loop.html)
2. Click the button once and note the new count. [Connect a button to a shared rule](../../courses/learning-gtk4/lessons/02-connect-a-button-to-a-shared-rule.html)
3. In `window.c`, follow `clicked` into `Completed` and trace the call to `BtbActivityAdvance`. [Connect a button to a shared rule](../../courses/learning-gtk4/lessons/02-connect-a-button-to-a-shared-rule.html)

**Check your result.** The label moves from zero to one after the click, and you can identify the callback that updates it.
