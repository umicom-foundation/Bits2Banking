# Learning Kotlin

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Run `java -version` and `kotlinc -version` in a new terminal. Compile and run the greeting using the course's commands. [Install Kotlin and run a first program](../../courses/learning-kotlin/lessons/01-tools-and-first-program.html)
2. In the progress example, predict `remainingLessons(0, 0)` and `remainingLessons(4, 5)`. [Calculate progress and check the result](../../courses/learning-kotlin/lessons/02-values-functions-and-checks.html)
3. Compile and run the progress checks. Trace the range guard before the subtraction. [Calculate progress and check the result](../../courses/learning-kotlin/lessons/02-values-functions-and-checks.html)

**Check your result.** The greeting prints once. The progress checks accept zero remaining and reject five completed out of four.
