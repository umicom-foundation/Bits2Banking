# D Keywords for Beginners

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write a type for an unsigned count of 300 and a signed refund of −25. Check the range of each selected type. [Name values and choose D types](../../courses/d-keyword-reference/lessons/01-name-values-and-choose-types.html)
2. Use `foreach` to trace the three statement entries in the example. Mark the row skipped by `continue`. [Choose, repeat and stop in D](../../courses/d-keyword-reference/lessons/02-choose-repeat-and-stop.html)
3. Add the values from the admitted rows and compare your arithmetic with the program’s result. [Choose, repeat and stop in D](../../courses/d-keyword-reference/lessons/02-choose-repeat-and-stop.html)

**Check your result.** `ushort` fits 300 and `byte` fits −25. The two admitted amounts, 425 and −25, give 400.
