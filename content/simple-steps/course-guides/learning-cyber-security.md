# Learning Cyber Security

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Choose a fictional notes app. Make a table with four columns for asset, entry point, unwanted result and protective control. [Identify what an application must protect](../../lessons/05-engineering/learning-cyber-security/01-assets-and-trust-boundaries.md)
2. Add a row for a saved note opened from an import screen. List an explicit destination and confirmation before any overwrite as controls. [Identify what an application must protect](../../lessons/05-engineering/learning-cyber-security/01-assets-and-trust-boundaries.md)
3. Draw the normal import route from input through validation to the saved record. Label where the app will display status. [Identify what an application must protect](../../lessons/05-engineering/learning-cyber-security/01-assets-and-trust-boundaries.md)

**Check your result.** Your table names the file to protect and the controls around saving. Your drawing shows validation before the write.
