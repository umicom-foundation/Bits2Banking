# Practical Web and Data Foundations

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Read one statement entry in the supplied JSON and write its amount and state on paper. [Read a statement as JSON](../../courses/practical-web-and-data-foundations/lessons/01-read-a-statement-as-json.html)
2. Build the small page in the lesson. Put that entry in a row and check it in your browser. [Put the entries on a web page](../../courses/practical-web-and-data-foundations/lessons/02-put-rows-on-a-web-page.html)
3. Try the typed-data check with a changed field. Compare the unchanged sample’s posted total with the spreadsheet exercise. [Check a record with TypeScript](../../courses/practical-web-and-data-foundations/lessons/03-check-a-record-with-typescript.html)

**Check your result.** The same entry amount and state appear in the JSON, the browser row and the manual total.
