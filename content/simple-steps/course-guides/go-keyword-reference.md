# Go Keywords for Beginners

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Copy the complete first program into `practice.go` after setting up Go. Find `package main`, `func main` and `fmt.Println`. [Write a first Go program](../../lessons/03-native-code/go-keyword-reference/01-write-a-first-go-program.md)
2. Type `go run practice.go`. Write down the number you see. [Write a first Go program](../../lessons/03-native-code/go-keyword-reference/01-write-a-first-go-program.md)
3. Change the adjustment from `-25` to `75`, save and run the same command again. [Write a first Go program](../../lessons/03-native-code/go-keyword-reference/01-write-a-first-go-program.md)

**Check your result.** The first run prints 400. The changed version prints 500.
