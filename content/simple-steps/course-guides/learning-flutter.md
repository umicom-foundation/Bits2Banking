# Learning Flutter

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Run `flutter doctor` and `flutter devices`. Confirm Chrome appears, then create and run the `lesson_counter` project. [Install Flutter and run a first application](../../courses/learning-flutter/lessons/01-install-and-run.html)
2. Add the lesson's screen and test files. Run `flutter test test/counter_test.dart`. [Build a counter and test its buttons](../../courses/learning-flutter/lessons/02-widgets-state-and-tests.html)
3. Run `flutter run -d chrome`. Complete three exercises and press Reset. [Build a counter and test its buttons](../../courses/learning-flutter/lessons/02-widgets-state-and-tests.html)

**Check your result.** The counter starts at 0, disables the completion button at 3, and enables it again after Reset.
