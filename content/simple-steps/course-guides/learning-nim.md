# Learning Nim

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open `labs/languages/nim-activity/hello.nim`. Locate the count and its `echo` line. [Run your first Nim program](../../courses/learning-nim/lessons/01-run-your-first-program.html)
2. Compile it with `nim c` using the source, C compiler and output options in the lesson. [Run your first Nim program](../../courses/learning-nim/lessons/01-run-your-first-program.html)
3. Run the compiled file. Change the count to 42, recompile and run again. [Run your first Nim program](../../courses/learning-nim/lessons/01-run-your-first-program.html)

**Check your result.** The first run prints `Completed: 41`, and the second prints `Completed: 42`.
