# Learning Data Structures

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write 7, 2 and 9 into slots 0, 1 and 2. Mark the count as 3. [Arrays, length and capacity](../../courses/learning-data-structures/lessons/01-arrays-length-and-capacity.html)
2. Trace one append of 2. Identify the first free slot before changing the count. [Arrays, length and capacity](../../courses/learning-data-structures/lessons/01-arrays-length-and-capacity.html)
3. Build and run the supplied collections lab. Compare its sorted output with your four values. [Arrays, length and capacity](../../courses/learning-data-structures/lessons/01-arrays-length-and-capacity.html)

**Check your result.** The fourth value uses slot 3, the count becomes 4, and the lab prints 2 2 7 9.
