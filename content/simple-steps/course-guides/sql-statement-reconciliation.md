# SQL Statement Reconciliation

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Set up the practice database using the supplied statement tables and mark which movements are posted. [Summarise posted movements](../../courses/sql-statement-reconciliation/lessons/01-summarise-posted-movements.html)
2. Run the lesson’s summary query. Check one account’s signed total by hand. [Summarise posted movements](../../courses/sql-statement-reconciliation/lessons/01-summarise-posted-movements.html)
3. Run the comparison with a missing account and a mismatched total. Compare the two reported states. [Distinguish mismatches and missing totals](../../courses/sql-statement-reconciliation/lessons/02-distinguish-mismatches-and-missing-totals.html)

**Check your result.** Your report can tell an account with a genuine zero total from an account with no matching total.
