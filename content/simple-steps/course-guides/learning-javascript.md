1. Start with an empty task array. Trace what happens when the form receives `Read Kernel entry Assembly`. [Events and visible state](../../courses/learning-javascript/lessons/01-events-and-visible-state.html)
2. Trace a second submission containing only spaces. Follow the `trim` check before adding a title. [Events and visible state](../../courses/learning-javascript/lessons/01-events-and-visible-state.html)
3. Run through `renderTasks` twice on paper. Count how many visible list items remain. [Events and visible state](../../courses/learning-javascript/lessons/01-events-and-visible-state.html)

**Check your result.** The array has one title and the page has one list item after both renders.
