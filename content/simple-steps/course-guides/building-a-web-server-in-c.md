# Building a Web Server in C

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Follow the local example’s request for `/api/health`. Mark the method, path and blank line ending the headers. [Follow a browser request into C](../../courses/building-a-web-server-in-c/lessons/01-follow-a-request.html)
2. Find the matching route and follow it into the C handler that builds the JSON response. [Connect routes to ordinary C functions](../../courses/building-a-web-server-in-c/lessons/02-routes-and-handlers.html)
3. Use the documented loopback address in the course to compare the response with the handler output, or trace that output from source. [Follow a browser request into C](../../courses/building-a-web-server-in-c/lessons/01-follow-a-request.html)

**Check your result.** You can point to the GET route and the two JSON fields `service` and `status`.
