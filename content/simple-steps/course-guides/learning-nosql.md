# Learning NoSQL and MongoDB

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Connect `mongosh` to the local training server and select `bits2banking_learning`. [Create and read a training document](../../courses/learning-nosql/lessons/02-create-and-read-a-document.html)
2. Run the lesson's `updateOne` for `c-hello`. Run `findOne` for that same ID and find its `minutes` field. [Create and read a training document](../../courses/learning-nosql/lessons/02-create-and-read-a-document.html)
3. Set `minutes` to the number 20 and run the update and lookup again. [Create and read a training document](../../courses/learning-nosql/lessons/02-create-and-read-a-document.html)

**Check your result.** The same document ID returns with `minutes` changed from 15 to 20.
