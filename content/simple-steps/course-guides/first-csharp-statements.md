# First C# Statements

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. With the .NET SDK already available, create a fresh project with `dotnet new console --name ReceiptLab --output ReceiptLab`. [Name values in a receipt](../../courses/first-csharp-statements/lessons/01-name-values-in-a-receipt.html)
2. Save the receipt sample in `ReceiptLab/Program.cs` and type `dotnet run --project ReceiptLab` from the practice folder. [Name values in a receipt](../../courses/first-csharp-statements/lessons/01-name-values-in-a-receipt.html)
3. Trace the checking example with a pending-only list and again with status `waiting`. Record each outcome. [Check the posted total](../../courses/first-csharp-statements/lessons/04-check-the-total.html)

**Check your result.** The sample prints `1 posted 2600`. A pending-only list gives zero posted cents and the `waiting` status is refused.
