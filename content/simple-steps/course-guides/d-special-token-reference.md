# D Special Tokens for Beginners

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Locate `__DATE__`, `__TIME__` and `__TIMESTAMP__` in the first sample. Match each token to its printed line. [Read the date and time of a build](../../courses/d-special-token-reference/lessons/01-read-build-time.html)
2. With a D compiler available, build and run the sample using the lesson’s instructions. Record the actual build values. [Read the date and time of a build](../../courses/d-special-token-reference/lessons/01-read-build-time.html)
3. Use the second sample to record the compiler’s vendor and version alongside the source filename. [Record which compiler read a program](../../courses/d-special-token-reference/lessons/02-record-compiler-identity.html)

**Check your result.** Your record has three labelled build-time lines and a compiler version reported as an integer.
