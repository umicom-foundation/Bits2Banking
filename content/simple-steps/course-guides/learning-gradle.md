# Learning Gradle

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open the Gradle jvm-identity example. Find its Java toolchain setting and check that Java 17 is available. [Read projects plugins and tasks](../../courses/learning-gradle/lessons/01-projects-plugins-and-tasks.html)
2. Run `gradle test` and open `build/reports/tests/test/index.html`. [Run and inspect Gradle tests](../../courses/learning-gradle/lessons/02-run-and-inspect-tests.html)
3. Run `gradle build` and find the archive under `build/libs`. [Run and inspect Gradle tests](../../courses/learning-gradle/lessons/02-run-and-inspect-tests.html)

**Check your result.** The test report lists three passing methods, and the build places a library archive in `build/libs`.
