# Learning Studio Documents and Visual Design

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Make a scratch text file containing `total = 10;`. Open it in an editor and change the draft to `total = 12;`. [A file, a draft and a saved document](../../lessons/06-umicom/framework-studies/studio-workflows/documents-and-saving.md)
2. Before saving, check the stored file from a second window. Then save the draft and reopen the file. [A file, a draft and a saved document](../../lessons/06-umicom/framework-studies/studio-workflows/documents-and-saving.md)
3. Sketch a notes form with a title field and a Save button. Give each control a stable name in a second list. [Build a form from a shared document model](../../lessons/06-umicom/framework-studies/studio-workflows/designer-model.md)

**Check your result.** The stored value is 10 before saving and 12 after reopening. Your sketch has a name for each control.
