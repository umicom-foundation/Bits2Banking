# React and Native Statement Data

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save the lesson’s snapshot beside its page component. Pass the snapshot into React as props and check the heading and summary. [Pass the native result as props](../../courses/react-native-statements/lessons/01-pass-the-native-result-as-props.html)
2. Add the row component and apply the supplied filter. Count the visible entries and compare the posted total before and after. [Filter rows without changing the posted total](../../courses/react-native-statements/lessons/02-filter-without-changing-the-posted-total.html)
3. Use the loading, empty and error examples. Check the text shown for each state. [Show loading, empty and error states](../../courses/react-native-statements/lessons/03-show-loading-empty-and-error-states.html)

**Check your result.** The displayed row count changes with the filter, and the posted total stays the same.
