# Accessible Statement Review

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save the statement table as `statement.html` in a practice folder and open it in your browser. [Build a readable statement table](../../courses/accessible-statement-review/lessons/01-build-a-readable-statement-table.html)
2. Add the lesson’s checkbox, status line and script. Reload the page. [Filter posted rows with a status message](../../courses/accessible-statement-review/lessons/02-filter-posted-rows-with-a-status-message.html)
3. Press Tab to reach the checkbox. Press Space once to filter the rows and again to restore them. [Filter posted rows with a status message](../../courses/accessible-statement-review/lessons/02-filter-posted-rows-with-a-status-message.html)

**Check your result.** The status reads `3 rows shown`, then `2 rows shown`, then `3 rows shown`. Focus stays on the checkbox.
