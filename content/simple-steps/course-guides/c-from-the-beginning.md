# Learning C: For beginners

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open `hello.c` from the first lesson. Find `main`, the call to `puts` and the return value. [Read a C program before running it](../../courses/learning-c/lessons/01-read-your-first-program.html)
2. Use the build lesson to compile the file from its practice folder, then run the executable. [Prepare, build and run without mixing the steps](../../courses/learning-c/lessons/02-build-and-run-one-step.html)
3. Change the text inside the quotes. Save, build again and run the new executable. [Prepare, build and run without mixing the steps](../../courses/learning-c/lessons/02-build-and-run-one-step.html)

**Check your result.** The first run prints `Hello from Bits2Banking.` and the next run displays the exact message you saved.
