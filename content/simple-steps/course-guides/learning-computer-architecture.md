# Introduction to Computers

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write a line naming the information you will enter, the action you will take and what you expect to see. [What does a computer do?](../../lessons/00-getting-started/02-input-instructions-and-results.md)
2. In a plain-text editor, type `Review the practice schedule.` and save it as `practice-note.txt` in your practice folder. [Keep something you can find again](../../lessons/00-getting-started/03-files-folders-and-saving.md)
3. Close the editor, find the file in the folder and reopen it. Name the input, action and result you observed. [Keep something you can find again](../../lessons/00-getting-started/03-files-folders-and-saving.md)

**Check your result.** The note opens from the saved folder and contains the same sentence. You can point to its name and location.
