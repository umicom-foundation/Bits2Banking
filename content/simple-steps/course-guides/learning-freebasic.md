# Learning FreeBASIC

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save the lesson's `values.bas` example. Find `items`, `centsEach` and `totalCents`. [Names, values and number types](../../courses/learning-freebasic/lessons/02-names-values-and-number-types.html)
2. Run `fbc -lang fb -w all values.bas -x values.exe`. In PowerShell, run `.\values.exe`. [Names, values and number types](../../courses/learning-freebasic/lessons/02-names-values-and-number-types.html)
3. Set `items` to 7 and `centsEach` to 250. Rebuild and run again. [Names, values and number types](../../courses/learning-freebasic/lessons/02-names-values-and-number-types.html)

**Check your result.** The first run shows 375 and 100. After the change, the first value is 1750 cents.
