# Learning HDL and VHDL

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open `select_bit.vhd` and write down which data input the selector chooses for each binary control value. [Describe a circuit with signals](../../courses/learning-hdl-vhdl/lessons/01-signals-bits-and-circuits.html)
2. In the VHDL lab folder, analyse `select_bit.vhd` and `select_bit_tb.vhd` with GHDL using the lesson's commands. [Run a self-checking VHDL simulation](../../courses/learning-hdl-vhdl/lessons/02-first-simulation.html)
3. Prepare and run the `select_bit_tb` simulation. Compare its checks with the choices you wrote down. [Run a self-checking VHDL simulation](../../courses/learning-hdl-vhdl/lessons/02-first-simulation.html)

**Check your result.** The testbench reports `selector checks passed` after checking the binary choices and an unknown control.
