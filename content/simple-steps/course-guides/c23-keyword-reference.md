# C23 Keywords for Beginners

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Give the posted amount 425 and the refund −25 a signed integer type. [Name values and choose their types](../../courses/c23-keyword-reference/lessons/01-name-values-and-types.html)
2. Trace the loop in the second lesson. Write down the positions it visits and mark the entries it counts. [Choose an action and repeat it](../../courses/c23-keyword-reference/lessons/02-choose-and-repeat.html)
3. Use the `struct` example to locate the amount and posted flag together. Trace the result for an unposted entry. [Group data and return results](../../courses/c23-keyword-reference/lessons/03-group-data-and-results.html)

**Check your result.** The posted amounts 425 and −25 total 400. The filter returns zero when the posted flag is clear.
