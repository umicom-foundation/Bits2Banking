# Native Statement Calculations

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open the training statement. Mark the posted rows and add their cents by hand. [Calculate posted cents in Umicom C](../../courses/native-statement-calculations/lessons/01-calculate-posted-cents-in-umicom-c.html)
2. Run the Umicom C exercise with that statement and compare the result to your calculation. [Calculate posted cents in Umicom C](../../courses/native-statement-calculations/lessons/01-calculate-posted-cents-in-umicom-c.html)
3. Pass the supplied invalid case to the C23 check after a valid case. Record the status and the last valid total. [Keep the last valid total in C23](../../courses/native-statement-calculations/lessons/02-keep-the-last-valid-total-in-c23.html)

**Check your result.** Pending rows leave the posted total alone. A rejected update leaves the last valid total available.
