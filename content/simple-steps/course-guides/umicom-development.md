# Learning Umicom Framework

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Run the first C example and make the small change described in the lesson. [Introduction to C programming](../../courses/umicom-development/lessons/01-introduction-to-c.html)
2. Open the Framework introduction and mark which part of the small application calls a shared tool. [Introduction to Umicom Framework](../../courses/umicom-development/lessons/02-introduction-to-framework.html)
3. Use the installed SDK exercise to build the client. Keep its build output and compare the console result after one edit. [Use an installed Framework SDK](../../courses/umicom-development/lessons/06-use-an-installed-sdk.html)

Try the [installed Framework SDK project](../framework-sdk-venue-report/index.md) for a full sequence from validating input through publishing a checked result.

**Check your result.** The installed-SDK client builds and reports the result you expect after a single source edit.
