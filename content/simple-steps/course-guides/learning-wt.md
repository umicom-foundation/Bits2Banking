# Learning Wt

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Build the `wt-profile` lab and launch it on the local address with the lesson's public-assets setup. [Build and launch the Wt server](../../courses/learning-wt/lessons/02-build-and-launch-the-server.html)
2. Open two separate browser contexts. Submit `Alice_7` in the first and `Bob` in the second. [Observe independent browser sessions](../../courses/learning-wt/lessons/12-observe-independent-browser-sessions.html)
3. Clear the name in the first context and submit it again. Keep both pages visible to compare the feedback. [Observe independent browser sessions](../../courses/learning-wt/lessons/12-observe-independent-browser-sessions.html)

**Check your result.** The accepted names appear as `alice_7` and `bob`. The refusal in the first session leaves the second result in place.
