# Java SE 25 keyword reference

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. With the course’s JDK ready, create `ReceiptPractice.java` and put `byte ticketCount = 12;` inside its `main` method. [Numbers, characters, and result types](../../lessons/03-native-code/java-keyword-reference/01-numbers-and-values.md)
2. Add `System.out.println(ticketCount);`. Type `javac ReceiptPractice.java`, then `java ReceiptPractice`. [Numbers, characters, and result types](../../lessons/03-native-code/java-keyword-reference/01-numbers-and-values.md)
3. Change `byte ticketCount = 12;` to `short ticketCount = 150;`. Save, recompile and run. [Numbers, characters, and result types](../../lessons/03-native-code/java-keyword-reference/01-numbers-and-values.md)

**Check your result.** The first run prints 12. The second prints 150, which fits the wider `short` type.
