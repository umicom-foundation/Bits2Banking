# Learning Fortran

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open `labs/languages/fortran-activity/hello.f90` and find the assignment that sets `completed` to 41. [Run your first Fortran program](../../courses/learning-fortran/lessons/01-run-your-first-program.html)
2. Compile and run the example using the lesson's commands. [Run your first Fortran program](../../courses/learning-fortran/lessons/01-run-your-first-program.html)
3. Change 41 to 42 in your practice copy. Compile and run it again. [Run your first Fortran program](../../courses/learning-fortran/lessons/01-run-your-first-program.html)

**Check your result.** The first run prints `Completed: 41`. The second prints `Completed: 42`.
