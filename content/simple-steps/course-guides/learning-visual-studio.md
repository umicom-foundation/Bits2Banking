# Learning Visual Studio for Umicom development

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. In Visual Studio, choose File > Open > Folder and open your `umicom-c` checkout. [Learning Visual Studio for Umicom development](../../lessons/05-engineering/learning-visual-studio.md)
2. Open `tools/main.c` and find `main`. Follow the `run` and `execute` variables to `umc_execute`. [Learning Visual Studio for Umicom development](../../lessons/05-engineering/learning-visual-studio.md)
3. Open the declaration in `include/umicom_c/umicom_c.h` and the implementation in `src/vm.c`. Compare the argument and result types. [Learning Visual Studio for Umicom development](../../lessons/05-engineering/learning-visual-studio.md)

**Check your result.** You can point to where the command enters the program, where the function is declared and where it executes.
