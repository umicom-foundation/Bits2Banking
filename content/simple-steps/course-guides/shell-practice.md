# Learn a shell in three steps

Choose Bash or PowerShell 7. Use the same one for the whole exercise. Each command turns the same short checklist into a result you can check by hand.

1. [Create and open the practice file](../../lessons/02-programming/shell-practice/01-navigate-and-quote.md). Read the working directory and find `closing notes.txt`. Confirm that it contains `Approved`, `Pending` and `Approved`.
2. [Count the approved lines](../../lessons/02-programming/shell-practice/02-compare-pipelines.md). Say how many matches you expect, then run your shell's commands. The result should be `2`.
3. [Check whether a command succeeded](../../lessons/02-programming/shell-practice/03-check-command-status.md). Compare an empty search or missing-file check with the successful case. Read the status before you type the next command.

If you cannot open a terminal yet, start with the [browser shell practice](../../practice/shell/index.md). It shows the commands supported in its sample workspace. If PowerShell 7 is missing on Windows, follow the [installation steps](../powershell-setup.md) before running the local course.
