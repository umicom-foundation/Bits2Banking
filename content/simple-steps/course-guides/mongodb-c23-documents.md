# MongoDB Receipt Documents in C23

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Copy the sample receipt document and underline its required fields. Remove one field in a separate copy. [Read a receipt document and its required fields](../../courses/mongodb-c23-documents/lessons/01-read-required-document-fields.html)
2. Follow the BSON inspection exercise and write down the expected type beside the value you look up. [Inspect a BSON field from the C driver boundary](../../courses/mongodb-c23-documents/lessons/02-build-and-inspect-bson-from-c.html)
3. Run the local cursor rehearsal or trace it on paper. Give an empty lookup and a failed lookup their own rows. [Distinguish an empty cursor from a failed lookup](../../courses/mongodb-c23-documents/lessons/03-distinguish-empty-cursors-from-errors.html)

**Check your result.** A missing field, an empty query result and a failed query are recorded as three different outcomes.
