# Learning Zig

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save the short typed example and run its check with your installed Zig compiler. [Types and a small check](../../courses/learning-zig/lessons/01-types-and-a-small-check.html)
2. Run the explicit-error example with a value it accepts, then use the refused input from the exercise. [Return an explicit error](../../courses/learning-zig/lessons/02-return-an-explicit-error.html)
3. Open the shared C declaration beside the Zig caller. Mark which layer owns the output and where Zig interprets the returned status. [Call the shared C model](../../courses/learning-zig/lessons/03-call-the-shared-c-model.html)

**Check your result.** A valid value reaches the calculation. A refused value follows the error branch and leaves the output unchanged.
