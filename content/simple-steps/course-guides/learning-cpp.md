# Learning C++

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open the note journal example and find the part that keeps notes in memory. Write two practice notes on paper. [Objects and a note journal](../../lessons/03-native-code/learning-cpp/01-objects-and-a-note-journal.md)
2. Trace `Save` on those two notes. In a second column, record which lines the stream appends to a new practice file. [Streams and file lifetime](../../lessons/03-native-code/learning-cpp/02-streams-and-file-lifetime.md)
3. Trace `Save` a second time without changing the journal. Record where the stream is released. [Streams and file lifetime](../../lessons/03-native-code/learning-cpp/02-streams-and-file-lifetime.md)

**Check your result.** Your paper trace shows two lines after the first save and four after the second. The stored list still holds two notes.
