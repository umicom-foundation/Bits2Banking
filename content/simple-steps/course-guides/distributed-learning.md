# Introduction to Distributed Learning, Blockchain and Verifiable AI

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Record the starting checkpoint value of 1.000. Check that every worker’s update uses that same starting point. [Distributed Learning 01 — What a distributed training worker actually computes](../../courses/distributed-learning/lessons/001-what-a-distributed-training-worker-computes.html)
2. Use the three sample counts to weight the three updates. Add the weighted values and divide by the total sample count. [Distributed Learning 03 — Average three workers by hand](../../courses/distributed-learning/lessons/003-average-three-workers-by-hand.html)
3. Add that average to the starting value. Draw a separate record for the proposed next checkpoint. [Distributed Learning 03 — Average three workers by hand](../../courses/distributed-learning/lessons/003-average-three-workers-by-hand.html)

**Check your result.** The weighted update is 0.029. The proposed value is 1.029 and the starting checkpoint remains 1.000.
