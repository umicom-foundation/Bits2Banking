# Programming across languages

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write one plain instruction per action and execute the instructions on paper once. [Follow instructions on paper](../../courses/programming-across-languages/lessons/01-follow-instructions-on-paper.html)
2. Name a value and write its unit. Copy the same value into two language examples. [Give values names and units](../../courses/programming-across-languages/lessons/02-give-values-names-and-units.html)
3. Trace the decision at its boundary value and one value immediately beside it. Compare the branch in both languages. [Make a decision with if](../../courses/programming-across-languages/lessons/03-decide-with-an-if.html)

**Check your result.** Both versions take the same branch on each boundary input and display the same checked result.
