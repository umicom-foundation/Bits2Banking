# Learning CSS

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Put a heading, paragraph and link in a practice HTML file. Link a local stylesheet named `notes.css`. [Rules, colour and spacing](../../lessons/04-web/learning-css/01-rules-colour-and-spacing.md)
2. Use the lesson’s `p` rule to add paragraph colour and line spacing. Save and refresh the page. [Rules, colour and spacing](../../lessons/04-web/learning-css/01-rules-colour-and-spacing.md)
3. Add the `:focus-visible` rule from the next lesson. Press Tab until the link receives focus. [Responsive and keyboard-friendly pages](../../lessons/04-web/learning-css/02-responsive-and-keyboard-friendly-pages.md)

**Check your result.** The paragraph styling changes while the heading remains readable. A visible outline appears at the focused link.
