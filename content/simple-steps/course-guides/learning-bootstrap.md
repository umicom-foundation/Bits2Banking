# Learning Bootstrap

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. In a practice folder, place `bootstrap.min.css` beside `index.html`. Copy the lesson’s first card and open the page in a browser. [Classes and reusable components](../../lessons/04-web/learning-bootstrap/01-classes-and-components.md)
2. Add the sample row with two `col-12 col-md-6` columns to the page. Save and refresh. [Responsive columns and reading order](../../lessons/04-web/learning-bootstrap/02-responsive-columns.md)
3. Narrow and widen the browser, then use Tab to reach the links. [Responsive columns and reading order](../../lessons/04-web/learning-bootstrap/02-responsive-columns.md)

**Check your result.** The cards stack at a narrow width and sit side by side at a wider width. Keyboard focus reaches the links.
