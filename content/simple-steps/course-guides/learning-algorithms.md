# Learning Algorithms

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write `7, 2, 9, 2` in boxes numbered 0 to 3. Search from left to right for 2 and count your comparisons. [Linear search and counting work](../../lessons/02-programming/learning-algorithms/01-linear-search-and-cost.md)
2. Use the insertion-sort trace to put the four values in ascending order. Check each new value goes into the sorted part. [Insertion sort and a promise kept at every step](../../lessons/02-programming/learning-algorithms/02-insertion-sort-and-invariants.md)
3. Search the sorted result for 9 with the course’s binary-search steps. Mark the range you keep after each comparison. [Binary search and its sorted-input promise](../../lessons/02-programming/learning-algorithms/03-binary-search-and-preconditions.md)

**Check your result.** The first search finds index 1 after two comparisons. The sorted list is `2, 2, 7, 9`, and the second search finds 9.
