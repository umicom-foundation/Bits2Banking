# Learning C

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Save the lesson’s first program as `hello.c` in a practice folder and find the line that displays the greeting. [Your first C program](../../lessons/learning-c/01-read-your-first-program.md)
2. With the C23 tools ready, type `gcc -std=c23 -Wall -Wextra hello.c -o hello.exe`. If compilation succeeds, type `.\hello.exe`. [Build and run your first C program](../../lessons/learning-c/02-build-and-run-one-step.md)
3. Change the quoted greeting, save `hello.c`, build again and run the new executable. [Build and run your first C program](../../lessons/learning-c/02-build-and-run-one-step.md)

**Check your result.** The first run prints `Hello from Bits2Banking.` and the new build prints your revised greeting.
