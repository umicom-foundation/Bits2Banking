# Spring Boot with a Native C23 Service

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Open the local Boot example and trace from application startup to the native adapter. Check its no-listener setup. [Start a Boot application with no web listener](../../courses/spring-boot-native-service/lessons/01-start-without-a-web-listener.html)
2. Write down the setting that locates the library and the line that owns the native decision. [Configure the lab library outside the native rule](../../courses/spring-boot-native-service/lessons/02-keep-config-outside-the-rule.html)
3. Replay the same accepted and refused examples through the Boot test and compare them with the native evidence table. [Replay the same native case from a Boot test](../../courses/spring-boot-native-service/lessons/03-replay-the-native-decision.html)

**Check your result.** The same practice input gives the same native status in the direct run and the Boot test.
