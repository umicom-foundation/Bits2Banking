# Spring Framework with a Native C23 Receipt Rule

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Trace the three supplied receipts through the C rule. Write the input amount and expected status beside each. [Put a receipt rule behind one native function](../../courses/spring-framework-with-c23/lessons/01-find-the-native-rule.html)
2. Follow one value through JNI. Compare the amount and units on the Java and C sides. [Pass the same units through JNI](../../courses/spring-framework-with-c23/lessons/02-bridge-the-exact-values-with-jni.html)
3. Run or trace the bean exercise with the same rows and compare its results to the original table. [Supply the native rule through a Spring bean](../../courses/spring-framework-with-c23/lessons/03-wire-the-native-rule-as-a-bean.html)

**Check your result.** An accepted and a refused synthetic receipt have matching outcomes in C and through the Spring bean.
