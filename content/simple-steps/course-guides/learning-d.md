# Learning D Language

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Set up DMD using the course directions, then type `dmd --version`. Save the first example as `hello.d`. [Install D and compile a first program](../../lessons/03-native-code/learning-d/01-install-and-run.md)
2. On Windows, type `dmd -g hello.d -of=hello.exe`. If it succeeds, type `.\hello.exe`. [Install D and compile a first program](../../lessons/03-native-code/learning-d/01-install-and-run.md)
3. Change the words inside `writeln` to `My first D program.` Save, compile and run again. [Install D and compile a first program](../../lessons/03-native-code/learning-d/01-install-and-run.md)

**Check your result.** The first run says `Welcome to Umicom learning.` and the second says `My first D program.`.
