# Building Linux from Scratch Using C Code

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Sort the lesson’s kernel image, compiler, shell and executable by the role each plays in a Linux system. [What makes a Linux system](../../courses/building-linux-from-scratch/lessons/01-what-makes-a-linux-system.html)
2. Save the lesson’s short `hello.c` in a practice folder on an existing Linux system. Use its build and run commands separately. [A C program meets the host](../../courses/building-linux-from-scratch/lessons/02-a-c-program-meets-the-host.html)
3. Choose the book edition you would use for a later isolated build. Record the host requirements and intended target. [Plan the toolchain and root filesystem](../../courses/building-linux-from-scratch/lessons/03-plan-the-toolchain-and-root-filesystem.html)

**Check your result.** The example prints `Hello from a user-space C program.` and the plan identifies which machine builds and which runs it.
