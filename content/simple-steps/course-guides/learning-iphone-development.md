# Learning iPhone Development

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. On a Mac with Xcode, create `ActivityLab` as an iOS App using Swift and SwiftUI. [Create and run your first iPhone screen](../../courses/learning-iphone-development/lessons/01-create-and-run-a-screen.html)
2. Choose an installed iPhone simulator. Run the untouched template, then stop it from Xcode. [Create and run your first iPhone screen](../../courses/learning-iphone-development/lessons/01-create-and-run-a-screen.html)
3. Change the greeting to `My learning activity` and run again on the same simulator. [Create and run your first iPhone screen](../../courses/learning-iphone-development/lessons/01-create-and-run-a-screen.html)

**Check your result.** The simulator shows `My learning activity` after the second run.
