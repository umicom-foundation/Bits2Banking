# Build a Banking Application in C

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Write the opening balances of 3,000 and 1,000 cents and the transfer request with reference 71. [Write the smallest ledger contract](../../courses/build-a-bank-application-in-c/lessons/01-write-the-smallest-ledger-contract.html)
2. Apply the lesson’s checks to the 600-cent transfer. Track the two balance changes and the accepted record. [Build one checked posting](../../courses/build-a-bank-application-in-c/lessons/02-build-a-checked-posting.html)
3. Repeat reference 71 once with the same fields and once with a changed amount. Record the replay and conflict separately. [Compare a retry with a changed request](../../courses/build-a-bank-application-in-c/lessons/03-compare-a-retry-and-a-conflict.html)

**Check your result.** The balances remain 2,400 and 1,600 cents after both attempts. There is only one accepted transfer record.
