# Learning Spring Framework

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Prepare and start the Java web example from the lesson. Confirm the first learning route responds. [A Java web request](../../courses/learning-spring-framework/lessons/01-a-java-web-request.html)
2. Add `CourseAdvice` and `AdviceController`. Restart and visit `/learning/advice`. [Supply a service through a constructor](../../courses/learning-spring-framework/lessons/02-supply-a-service-through-a-constructor.html)
3. Change the sentence only in `CourseAdvice`, restart the app and request the same path again. [Supply a service through a constructor](../../courses/learning-spring-framework/lessons/02-supply-a-service-through-a-constructor.html)

**Check your result.** The route first returns `Read, predict, practise, compare`. It then returns the new sentence without a route change.
