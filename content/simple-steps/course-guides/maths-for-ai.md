# Maths for AI — From the Beginning

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

1. Work one counting or ratio example by hand. Use it to check how many entries belong in a table with two rows and three columns. [Numbers, fractions and percentages](../../courses/maths-for-ai/lessons/01-counting-ratios-and-percentages.html)
2. Draw the table and label the dimensions before filling in the numbers. Trace two index pairs to their values. [Tensor shapes, rows and attention heads](../../courses/maths-for-ai/lessons/16-tensor-shapes-and-indexing.html)
3. Use the backpropagation exercise to mark which values are calculated on the way forward and which change during the update. [Backpropagation with one understandable example](../../courses/maths-for-ai/lessons/17-backpropagation-from-a-small-example.html)
4. Use the memory budget exercise to write the limit beside your estimate and mark where the operation stops if it exceeds the limit. [Memory budgets, peak allocation and safe rollback](../../courses/maths-for-ai/lessons/18-memory-budgets-and-rollback.html)

**Check your result.** A 2-by-3 tensor has six values, and your written rows show which value each index selects.
