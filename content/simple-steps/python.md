# Show the total in Python

![Umicom Foundation](../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Picture two apples sitting on a table. Put one more beside them.

```python
print(2 + 1)
```

1. Python adds `2 + 1`.
2. `print` shows the answer on the screen.

You should see **3**. Change `2` to `4`. Guess the new answer before you run the program.

## Run it if you have Python 3

Save the line as `apples.py`. Open a terminal in that folder and run the command for your computer.

On Windows, the Python launcher uses this command.

```powershell
py -3 apples.py
```

If PowerShell can't find `py` and you already have Python 3, try `python apples.py`.

On macOS or Linux, use this command.

```sh
python3 apples.py
```

After you change a number, save the file and run the command again. The answer with `4 + 1` is **5**.
