# Summarise exact amounts by reference

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional journal has amounts 2.35 and 3.45 under reference A and another amount 1.20 under reference B.

1. Model each journal line using the record lesson. Construct every amount from its text with BigDecimal.
2. Use a small method to total only the matching reference. Call it for A and B and keep their labels next to the output.

**Check your result.** The report displays A 5.80 and B 1.20.
