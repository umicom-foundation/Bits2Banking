# Join rooms to their inspection results

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Fictional room IDs 4 and 5 are named Gallery and Studio. An inspection row contains room ID 5 and result Ready.

1. Use the join lesson to connect the room ID in the inspection row to the matching room table key.
2. Select the room name and result from that inner join. Check each source row against the selected result.

**Check your result.** The query returns one row containing Studio and Ready. Gallery has no matching inspection in this fixture.
