# Build a two-line group report with a Go map

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice collection gives one note the tag tools and gives two notes the tag transport.

1. Use a map from a tag string to an integer count, and increment the matching count for each note.
2. Print the two keys in a fixed tools-then-transport order with the value beside each one.

**Check your result.** The report shows tools 1 on the first line and transport 2 on the second.
