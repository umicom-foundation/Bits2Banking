# Make a tiny weighted prediction

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use an input vector `[2, 5]`, weights `[3, 2]` and a bias of 4.

1. Multiply matching entries, add them and add the bias. Keep the input and weight order visible.
2. Make a small report for this prediction and a second input of `[3, 5]`. Calculate the actual change.

**Check your result.** The two outputs are 20 and 23. Increasing the first input by one changes the result by 3.
