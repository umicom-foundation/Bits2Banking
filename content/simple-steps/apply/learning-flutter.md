# Publish a validated room name

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local name editor begins with the confirmed name Elm. A scratch C policy fixture accepts Cedar and refuses an empty input.

1. Use the native-call lesson to mark where Dart sends the text and where it first checks the returned status. Wire or draw those steps for the editor.
2. Trace an empty submission followed by Cedar. Read the confirmed label after each submission and record the status beside it.

**Check your result.** The refused submission leaves Elm visible. The next accepted submission displays Cedar.
