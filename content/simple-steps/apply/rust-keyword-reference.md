# Prepare a small inventory decision

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice inventory value represents 0, 2 or 11 stored objects. The case labels are empty, ready and high.

1. Use the course pattern matching or `if` forms to give zero and values over ten different outputs. Keep the default for the other input.
2. Run or trace all three inputs and record which condition supplies each label.

**Check your result.** 0 is empty, 2 is ready and 11 is high under the practice rules.
