# Build a small checked counter

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training report counts three accepted readings with values of 4, 5 and 6.

1. Use supported checked-integer declarations and a loop to add one for each input. Draw the expected loop state.
2. Run or trace the accepted case, then change your loop boundary once and compare the counted result.

**Check your result.** The original loop counts three records. The chosen strict limit controls how many visits are counted.
