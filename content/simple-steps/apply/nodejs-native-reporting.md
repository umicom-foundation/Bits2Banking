# Assemble a small local report reader

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Your practice report file stores a heading and an exact amount of 220 cents.

1. Write it in the course’s report structure and run or trace the Node adapter’s local shape check.
2. Add one displayed line that includes the amount and unit, then compare it with the native sample report.

**Check your result.** The displayed report labels 220 as cents and identifies the accepted input source.
