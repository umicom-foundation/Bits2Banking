# Separate a small balance calculator into a module

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A D practice program needs one function that adds two integer-cent amounts and returns the sum.

1. Place the function in a calculation module and import that module from the console entry file.
2. Give the entry function amounts of 24 and negative 9 cents and print the returned amount.

**Check your result.** The console reports 15 cents from the imported calculation function.
