# Build a three-line native activity report

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local Odin command needs to report native results for input counts 0, 8, and 999.

1. Use the foreign declaration from the C lesson for BtbActivityNext. Store the fixture with the C-compatible argument type.
2. Read each supplied input once, call the declared function, and print the corresponding result beside the input.

**Check your result.** The report pairs 0 with 1, 8 with 9, and 999 with 1000 in the original order.
