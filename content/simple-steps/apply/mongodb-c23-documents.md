# Prepare two downloadable practice receipts

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A synthetic receipt has ID M4 and amount 1250 cents. Another has ID M5 and amount 260 cents.

1. Write both using the course’s document shape. Use the field inspection example to check the numeric type.
2. Build or trace a small report of their IDs and cents. Compare the reported sum to the input rows.

**Check your result.** The two rows keep their original identities and total 1,510 cents.
