# Show a safe result from a disconnected local service

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice service has a readable cached notice with the ID Guide-04. Its connection is unavailable when the user opens the notice.

1. Read the cached notice through the local service and capture the connection state as a separate field.
2. Display the notice and a visible cached-result label. Leave the queued write count at its initial value of zero.

**Check your result.** Guide-04 appears with the cached-result label and the write queue contains zero entries.
