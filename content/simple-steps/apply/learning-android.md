# Give an updated count a clear accessibility label

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training Android screen has one control for adding a cup to a counter. The visual count starts at 2.

1. Label the control Add one cup and make the count available as text in the focused practice view.
2. Activate Add one cup once and read both the visible count and the accessibility text for the result.

**Check your result.** The visible count is 3. The result text identifies it as three cups.
