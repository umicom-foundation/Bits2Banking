# Prepare a review table for two classroom payments

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One fictional instruction has a later accepted report. The other has a matching settlement observation.

1. Write each ID and instruction amount on separate lines. Match the later evidence against its own ID.
2. Create a short report showing the earlier instruction status and any later observation in distinct columns.

**Check your result.** Acceptance and settlement appear with the correct IDs, and the source evidence remains identifiable for each.
