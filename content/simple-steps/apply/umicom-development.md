# Publish one verified local report result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A venue practice report uses a fixed data file and should produce a checked result through an installed SDK client.

1. Use the SDK workshop to set up the isolated project and identify the accepted input. Record how it is validated.
2. Produce the report in its local output folder and compare the written result with the check before handing over the file.

**Check your result.** The approved input produces a complete report that matches the workshop’s verification and stated file location.
