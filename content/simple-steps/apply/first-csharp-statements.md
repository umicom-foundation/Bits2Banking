# Build a posted amount list for a read-only view

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice receipt list contains posted 900 cents, pending 125 and posted -75 in that order.

1. Use the Receipt class and `List<int>` pattern in Keep only the posted receipts to construct the two collections.
2. Trace foreach and write a two-column handoff with the original entries and the filtered amount list.

**Check your result.** The input list still contains three receipts in order. The filtered list contains 900 and -75 only, in that order.
