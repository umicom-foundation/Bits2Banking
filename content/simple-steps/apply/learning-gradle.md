# Record the test task in a build review

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice Gradle project named venue-tools has a Java plugin and a named test RoomCapacityTest.

1. Use the project and plugin lesson to mark which plugin supplies the test task and which test class the fixture expects.
2. Add the matching project name, task name, and class name to a one-page build review based on a fixture marked as executed.

**Check your result.** The review identifies venue-tools, the test task, and RoomCapacityTest as part of the same fixture run.
