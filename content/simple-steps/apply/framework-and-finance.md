# Make a handoff for an edit with a saved copy

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A trainee opens an existing form document, changes its label to Office hours and wants to record whether that change was saved.

1. Follow the Studio document route. Write three evidence fields showing the original file, the current draft and the save result.
2. Draft two history rows, one after the edit and one after a confirmed save. Record the draft's label in both rows.

**Check your result.** The edit row shows Office hours in the draft with a save still required. The confirmed row records Office hours in the saved document.
