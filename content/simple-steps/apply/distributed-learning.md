# Write a bounded native job ticket

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A virtual classroom worker W3 may process fixture shard S2 from base C20. It may perform at most six local training steps using the classroom's fixed numeric recipe.

1. Write a job ticket with worker, authorized shard, checkpoint, step limit and a version label for the numerical recipe.
2. Add a returned-result row for a report of five steps. Record the checkpoint that the delta must name and what further evaluation is needed.

**Check your result.** The ticket has W3, S2, C20 and a six-step limit. The five-step candidate passes the budget check and still needs model-result evaluation.
