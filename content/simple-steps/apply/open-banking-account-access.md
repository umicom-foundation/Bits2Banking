# Build a paper permissions worksheet

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training account consent permits two fields until cancellation. It has its own fictional ID C20.

1. Make one column for each request, consent state and chosen fields. Trace the allowed active request before marking consent cancelled.
2. Repeat that same request after cancellation in the paper exercise and retain both observations.

**Check your result.** The first request can read its allowed fields. The second is refused after cancellation, even with unchanged input fields.
