# Create a checklist counter for a coffee station

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A startup checklist has four items. The first, second and fourth items have been completed.

1. Represent completion with four yes-or-no values. Write a function that visits them in order and counts yes values.
2. Use the result to print completed and remaining counts for the checklist.

**Check your result.** The result reports three completed items and one remaining item.
