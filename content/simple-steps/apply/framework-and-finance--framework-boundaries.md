# Return a small learning pack through a service boundary

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training pack lists a welcome card and a command card. The console consumer needs the cards in that order.

1. Define one service result with a card count and an ordered collection. Give the result an explicit success status.
2. Have a separate consumer read that result and number the cards as it displays them.

**Check your result.** The consumer displays 1 Welcome and 2 Command from a successful two-card result.
