# Pass a calculated result to the display step

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice coffee station uses a C helper to split 18 filters equally across three operating stations.

1. Put the division in a helper function with filter and station arguments. Give the zero-station case an explicit failure result before dividing.
2. Call the function with 18 and 3 from main and print the returned share for the success case.

**Check your result.** The practice run prints 6 filters per station.
