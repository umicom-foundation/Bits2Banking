# Assemble a source-bound exercise catalogue

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

You have four original sentences describing booking rooms. Two refer to the same source memo.

1. Assign a source ID and content record ID to each line. Keep the related pair in one original source group.
2. Build two practice partitions and document the two source lists before proceeding to any training exercise.

**Check your result.** The record is traceable to named sources; both related examples stay in the same partition.
