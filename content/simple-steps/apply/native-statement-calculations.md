# Produce a checked one-day report

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional day contains posted cents 700 and −155 and pending cents 411.

1. Put those three rows in the documented sample format. Find the posted total and separately count the pending rows.
2. Run the practice operation and record which rows contributed to the accepted total.

**Check your result.** The report shows 545 posted cents and one pending row whose amount does not alter the posted sum.
