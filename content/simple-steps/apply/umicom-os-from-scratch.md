# Build a review note for two boot reports

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

In the course boot-report exercise you have one recorded report and a second sample with its lines in a different order.

1. Record the parsed service count and state from the original report. Copy the sample and reorder two independent fields.
2. Run the same parsing check on the second file and compute both SHA-256 digests. Put the parsed fields and raw digests in separate columns.

**Check your result.** The parsed counts and state agree. The digest column distinguishes the two files.
