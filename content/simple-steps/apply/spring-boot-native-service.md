# Prepare one local service review record

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A configured practice service calls a tested native rule with one accepted receipt.

1. Note the active local configuration and the exact native input. Run or trace the course’s integration check for it.
2. Keep the C reference status and the application status in the same result sheet.

**Check your result.** A matching input produces a matching status in both the configured application route and direct C check.
