# Assemble one file-only optical evidence report

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the documented private diagnostic build to produce an EFI-stage artifact and optical image in a disposable directory.

1. Record the compiler, input artifact and resulting ISO identity. Run only the existing workshop’s image inspection check.
2. Write one sentence explaining the boot evidence still needed after confirming the file layout.

**Check your result.** The report names the exact image and inspection result, and reserves the boot claim for a matching observed run.
