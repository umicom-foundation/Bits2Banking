# Prepare a signed-cents correction card

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice statement page needs a small correction form. One visible example uses 80, and a second enters the invalid decimal -1.25.

1. Use the lesson's labelled input and linked error text. In a separate practice copy show the invalid decimal state with aria-invalid and its error description.
2. Create a short handoff listing the accepted whole-cent input and the correction required for the invalid example. Read both examples with styles disabled.

**Check your result.** The visible field label specifies whole cents. 80 is the valid teaching input. -1.25 shows the linked instruction to enter a whole number of cents.
