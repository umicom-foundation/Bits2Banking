# Write a two-client acceptance note

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Assume the course’s reference C service accepts a typed input and exposes a stable return status.

1. Run or trace one fixture in the C client with the input and output types copied from its public header.
2. Follow the equivalent value in a second supported binding. Make a table with source language, status and value.

**Check your result.** The table gives matching values and statuses for the same valid input, and records the independent call paths.
