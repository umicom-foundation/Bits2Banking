# Assemble an experiment review sheet from fixed captions

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom experiment uses four approved photos with captions. Four outputs are provided from a fixed prompt run and one misses the requested desk lamp.

1. Record the four input IDs, the test prompt, and the run identifier on a review sheet.
2. Give each sampled output a lamp present or lamp absent label and tally the four labels.

**Check your result.** The sheet identifies the fixed input and prompt. Three outputs are labelled lamp present and one is labelled lamp absent.
