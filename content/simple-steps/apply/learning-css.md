# Build a two-part catalogue header using the box model

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice catalogue header needs a text label and a search button separated by a 12-pixel gap. Its inside spacing must be 16 pixels.

1. Place the label and button in a flexible parent with a 12-pixel gap. Give that parent 16 pixels of padding.
2. Inspect the parent and its children in browser developer tools and record both dimensions.

**Check your result.** The computed gap between the items is 12 pixels. The parent padding measures 16 pixels on each side.
