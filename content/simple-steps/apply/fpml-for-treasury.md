# Write an import admission sheet

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

An offline FpML teaching fixture proposes trade TRAIL-24 with USD 20,000 notional. A local adapter requires the pinned confirmation view and schema defined in its practice setup.

1. Write the source-reference, namespace, pinned version and view columns of a review sheet. Mark the expected structure check before mapping.
2. Add a business-rule checklist for parties, reversed legs and USD. Calculate the integer cents that maps from the stated notional.

**Check your result.** The notional is 2,000,000 cents. Admission requires both the expected structure and the listed business checks. The source reference TRAIL-24 remains visible.
