# Prepare a tiny reproducible token experiment

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the three words `open`, `the` and `window` with stable identifiers 10, 11 and 12.

1. Encode `open the window` and write down the vocabulary mapping. Reserve a separate test phrase with the same words in another order.
2. Make a short report with the two token sequences and the vocabulary identity used to decode both.

**Check your result.** The first sequence is 10, 11, 12. For `window the open`, it is 12, 11, 10. Both use the recorded vocabulary.
