# Build a small trade status card from a fake response

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local fake repository supplies two items with identifiers F7 and F8 and product labels Swap and Deposit. The view only requires identifier and product.

1. Map both in-memory rows into a display record with just those two fields.
2. Render the list in fixture order and compare it with the original values.

**Check your result.** The display shows F7 Swap above F8 Deposit, with both identifiers preserved.
