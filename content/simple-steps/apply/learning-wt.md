# Keep a rejected form result out of the summary

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch web session has accepted the name Cedar. The next submission is empty and the local policy fixture refuses it.

1. Use the event and validation lessons to draw the browser action, session callback, and result from the shared C rule.
2. Give the response a plain-text error while the summary continues reading the accepted value. List the visible texts after refusal.

**Check your result.** The summary still shows Cedar and the status reads Name required for the same session.
