# Report bad input from a small Java reader

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A command exercise takes two text inputs in sequence, 12 and red. Each is meant to be an integer count.

1. Use Integer.parseInt inside a try block and catch NumberFormatException for each individual item.
2. Keep a list of successful values and a separate result describing which text was refused.

**Check your result.** The accepted list contains 12 only. The error report identifies red as invalid.
