# Prepare a revised record without losing its extension field

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional note contains id 7, title Elm, and an unfamiliar field colour with value blue.

1. Use the unknown-field lesson to prepare a candidate record that changes the title to Elm room while keeping all other fields.
2. Validate the candidate before replacing the accepted note in the scratch exercise. Compare both versions field by field.

**Check your result.** The candidate contains id 7, title Elm room, and colour blue. The original title remains Elm until acceptance.
