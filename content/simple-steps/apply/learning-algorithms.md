# Find and report one practice stock item

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice stock sheet contains unsorted reference numbers 14, 8, 21 and 10, each with a label.

1. Sort a copy by reference while keeping the label attached to its row.
2. Search the sorted copy for reference 14 and record its zero-based sorted index. Keep the source sheet as the input record.

**Check your result.** The sorted references are 8, 10, 14 and 21, and reference 14 is at sorted index 2 with its original label.
