# Make a bounded practice inventory summary

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A storeroom counts four boxes with 2, 4, 1 and 3 notebooks. It needs the number of boxes and notebooks.

1. In a practice copy of arrays.c replace the initialized activities array with those four counts and compute its element count using the lesson pattern.
2. Trace the sum loop from index zero to count minus one. Use its console example to display the two totals.

**Check your result.** The array count is four, the inspected indexes are 0 through 3 and the sum is 10 notebooks.
