# Prepare a small invoice table

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional repair workshop charges £8 for the visit and £4 per item.

1. Write a row for 1, 3 and 5 items. Use the same named fixed charge in each calculation.
2. Add a fourth row for a total of £24 with its item count to check that you can work back from a result.

**Check your result.** The first three amounts are £12, £20 and £28. A total of £24 corresponds to four items.
