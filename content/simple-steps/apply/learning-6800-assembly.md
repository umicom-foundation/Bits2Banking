# Produce a stored total from two memory cells

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice 6800 memory trace has hexadecimal 06 at address 0022 and 04 at address 0023.

1. Load the first byte into A and add the byte from the next address using the course instruction notation.
2. Store A at address 0024 and record all three memory bytes after the store.

**Check your result.** Addresses hexadecimal 0022, 0023 and 0024 contain 06, 04 and 0A respectively.
