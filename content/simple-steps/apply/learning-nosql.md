# Design a document for an actual question

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local receipt view asks for the review status and three item quantities from one fictional record with ID R14.

1. Use the documents lesson to make one document that keeps the ID, review status Pending, and the item quantities 1, 2, and 4 together.
2. Trace a read by ID R14. Display its status and find the sum of the quantities in that one document.

**Check your result.** The view reads Pending and shows total quantity 7 using only the matching record.
