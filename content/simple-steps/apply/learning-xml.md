# Record a test case with its suite identity

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional room report check is named total_empty and belongs to the suite VenueReport.

1. Using the test report lesson, make a local XML fragment with a suite, one case, and a failure child inside that case.
2. Trace the suite name and case name from their attributes to the failure child. Write them together on one result line.

**Check your result.** The result identifies VenueReport, total_empty, and one failure associated with that case.
