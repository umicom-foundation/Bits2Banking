# Give terminal inputs separate outcomes

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local guide needs a status line for its percentage example with inputs 3 and 4, plus a readable error if the total argument is missing.

1. Use the argument-count and progress lessons to sketch a handler that checks there are two arguments before reading them.
2. Trace the complete pair through conversion and the shared progress helper. Trace the single argument 3 through the earlier count check.

**Check your result.** The complete pair prints 75 percent. The single argument prints Expected two values and makes no progress call.
