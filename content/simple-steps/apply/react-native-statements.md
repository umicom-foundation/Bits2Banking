# Build a three-state local report view

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training statement page can receive a loading input, an empty accepted snapshot and a report with two rows.

1. Use the course component to feed all three states separately. Keep visible labels and row counts in a table.
2. Make a short result note showing which state contains a real posted total and where it came from.

**Check your result.** The three case renders are visually distinguishable. Only the populated accepted data supplies the two displayed rows.
