# Keep a small notebook inside fixed storage

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch Pascal notebook can hold three names. It starts empty and receives Cedar, Elm, and Ash.

1. Use the notebook and occupied entries lessons to keep capacity 3 separate from the number of stored records. Insert Cedar then Elm.
2. Display only occupied slots, then add Ash and list the names again using the occupied count.

**Check your result.** The first list is Cedar and Elm with count 2. The second is Cedar, Elm, and Ash with count 3.
