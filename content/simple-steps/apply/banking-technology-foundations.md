# Create a payment evidence sheet

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

An offline payment P19 requests 700 USD cents. The practice gateway accepts it, and a later independent statement records P19 for 700 USD cents.

1. Make a one-page sheet with request, local acknowledgement and statement observations. Write the owner, identity, amount and currency for each.
2. Compare the request and statement using reference and currency, then mark the point when there is enough evidence to reconcile the exercise.

**Check your result.** There are three labelled observations and one reconciled P19 movement for 700 USD cents. Reconciliation uses the later independent row.
