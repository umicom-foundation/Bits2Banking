# Run a small program and attach its result to a record

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch directory holds one C source file for a user-space summary. Its successful result should be Room report ready.

1. Use the course’s first build procedure to make the program in the scratch directory. Record the source and resulting executable paths separately.
2. Launch that executable, or trace the launch on paper. Pair the visible text with the process result for the same launch.

**Check your result.** The run record shows the newly built executable, Room report ready, and exit status 0.
