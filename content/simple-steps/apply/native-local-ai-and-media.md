# Make a small local output contract

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom media request expects an image no larger than 800 by 600 using a provider fixture.

1. Write the capability, maximum dimensions and provider name before following the lesson’s admission step.
2. Record an accepted result of 640 by 480. Use a second row for an 800-by-601 refusal.

**Check your result.** The first result fits both limits. The second exceeds the height limit by one and stays separate from the accepted image.
