# Make a backup plan for a fictional wallet

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom wallet worksheet lists a public receiving identifier and a sealed envelope representing recovery information.

1. Assign one storage location to the public identifier and a controlled offline location to the sealed envelope.
2. Give a second learner the public receiving identifier and ask them to identify which item stays in the controlled location.

**Check your result.** The second learner can name the public receiving identifier. The recovery information stays in the sealed envelope.
