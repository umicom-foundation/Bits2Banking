# Build a four-stage startup worksheet

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A simulated boot log contains four course markers for firmware, bootloader, kernel and the initial console.

1. Copy the four lines into a worksheet in time order and put the relevant startup stage beside each line.
2. Mark the line where the kernel begins and the line where the console first accepts practice input.

**Check your result.** The stages are firmware, bootloader, kernel and console in that order. The two marked lines occupy positions three and four.
