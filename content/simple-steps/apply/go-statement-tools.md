# Report the row count and signed total

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom statement update supplies two valid rows with identifiers A19 and A20. One amount is zero and one is a negative 70 cents.

1. Keep both accepted integer-cent rows and create a summary with accepted count and net amount.
2. Print the accepted IDs in input order below the summary.

**Check your result.** The summary has accepted count 2 and net negative 70 cents. Its details show A19 followed by A20.
