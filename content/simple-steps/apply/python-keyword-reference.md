# Prepare a small totals report with a skip

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A group practice record stores attendance counts `[5, 0, 9, 6]`. Zero is included as an empty session.

1. Use the course’s loop and skip pattern to add nonzero values and count contributing visits.
2. Return or print a two-value report containing the count and total. Compare it to a handwritten result.

**Check your result.** Three nonzero sessions contribute to a total of 20 attendees.
