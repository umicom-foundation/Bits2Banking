# Put a source location into a navigation result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A sample project has a declaration for report_open on line 3 of report.h and a definition on line 14 of report.c.

1. Create distinct navigation entries for the declaration and definition, with file and line included in each entry.
2. Choose the definition entry and confirm where the source navigation lands.

**Check your result.** The definition opens report.c at line 14, and a separate declaration entry still points to report.h line 3.
