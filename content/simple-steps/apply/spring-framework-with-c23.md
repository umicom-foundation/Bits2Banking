# Produce a small Java-to-C comparison report

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A toy caller sends a valid receipt of 1,600 cents and a second record that the lesson marks invalid.

1. Use the published C declarations to identify accepted field types. Record expected outcomes from the direct native test.
2. Use the Java example on the same two local fixtures. Make a two-row table comparing both status codes.

**Check your result.** The accepted and refused cases retain their respective native outcomes through the Java path.
