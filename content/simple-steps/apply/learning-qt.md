# Map a C registry record into a view

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice registry returns ID R07 and title Elm for a single row. The view needs both values in different roles.

1. Use the registry model lesson to list the fields needed by the title column and the stable identity role.
2. Draw the row adapter and trace the returned values to their roles. Change the page’s displayed column caption without changing the model’s identity.

**Check your result.** The row displays Elm and its identity role remains R07 before and after the caption changes.
