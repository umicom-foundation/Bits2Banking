# Make a short summary card for a course catalogue

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A starter page needs a summary of the 20-minute Coffee practice course, with a Continue action inside the card.

1. Use the lesson's card, card-body and card-title classes for the card. Place a visible length of 20 minutes below the title.
2. Add a Continue action with the lesson's button classes and open the local page.

**Check your result.** A single card displays Coffee practice, 20 minutes and Continue. The action can receive keyboard focus.
