# Create a blank report with known defaults

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice C23 report has int total and bool retry fields. It should start with zero and false before recording a delivery count of four.

1. Use the structure examples to write the two fields, then initialize the structure variable with = {} as shown in Initialize a value before reading it.
2. Record the values just after initialization. Assign 4 only to the total field and record both values again.

**Check your result.** The initial fields are 0 and false. After recording the delivery they are 4 and false.
