# Make a before-and-after record for a bounded write

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Your previous accepted text is `draft` in a buffer with seven bytes available.

1. Trace replacing it with `review` and mark the space required for the terminator. Keep the saved state beside the new one.
2. Trace replacing it with `reviews` and write a local evidence report for both cases.

**Check your result.** `review` fits its seven bytes including the terminator. `reviews` requires eight, so the accepted text remains `review` after that refusal.
