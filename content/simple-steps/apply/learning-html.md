# Make a results table usable

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local report must show Gallery with 7 visits and Studio with 4 visits.

1. Write a table with a caption Room visits, column headers Room and Visits, and a body row for each result. Use the table lesson’s header markup.
2. Open the local file or inspect its structure. Match both numbers to the room name and Visits header.

**Check your result.** The table has one caption, two column headers and two data rows. Gallery is paired with 7 and Studio with 4.
