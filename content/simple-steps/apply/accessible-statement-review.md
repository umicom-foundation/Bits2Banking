# Make a readable receipt register

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A small workshop needs an offline page with two fictional receipt rows, R42 for 900 cents marked Posted and R55 for -120 cents marked Pending.

1. Adapt the course table into a practice file with a heading, a caption and Reference, Cents and State column headings. Keep the two states visible as words.
2. Make the scroll region keyboard-focusable using the lesson markup. Open the local file, narrow the window and use Tab to find the region.

**Check your result.** The table contains R42, 900, Posted and R55, -120, Pending. Its scroll region receives focus, and both state labels remain readable.
