# Make a marker for a confirmed low

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A synthetic chart has three closed values, 8, 4, and 6. A paper indicator should mark closed values below 5.

1. Use the price-series lesson to write the marker rule for one closed value. Draw the series and number the three bars.
2. Evaluate the rule at each closed bar and apply a marker only when the comparison is true.

**Check your result.** Only bar 2, with value 4, is marked. Bars 1 and 3 remain unmarked.
