# Print single-call results from an existing C rule

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local Nim exercise receives the two independent activity counts 3 and 25 for a summary.

1. Store the two numbers as cint values and connect to the declaration used by the Nim interop lesson.
2. Call activityNext for each input. Display both the source and returned value, retaining the input values if the summary is used again.

**Check your result.** The summary shows 3 becoming 4 and 25 becoming 26. Neither input value is changed.
