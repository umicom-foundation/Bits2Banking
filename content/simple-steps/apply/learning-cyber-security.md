# Produce an acceptance note for a safer import

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local file import lesson uses public test records with fields for label and amount. One valid sample contains label Lamp and amount 7.

1. Validate the sample fields before passing an owned copy of the record to local storage.
2. Write an acceptance note recording validation, ownership and the new stored record count, starting from an empty fixture.

**Check your result.** The note records a successful check, one caller-owned stored copy and exactly one imported record.
