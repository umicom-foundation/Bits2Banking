# Give a small note journal an owned record type

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice journal receives one note with reference 14 and title Coffee checklist.

1. Define a small C++ record with an integer reference and an owned string title. Put the supplied note into a collection of those records.
2. Pass the collection to a report function that prints the stored reference and title together.

**Check your result.** The report contains one row pairing reference 14 with Coffee checklist.
