# Make a compact equipment inventory record

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice machine lists a four-core CPU, 16 GB RAM and a 512 GB SSD.

1. Put CPU, working memory and storage into separate fields in an inventory sheet.
2. Add one example operation to each field, using a calculation, current application data and a saved document respectively.

**Check your result.** The sheet records four cores for CPU work, 16 GB for working memory and 512 GB for stored files.
