# Name and package the intended practice project

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional Maven library has group org.example.training, artifact room-report, and version 1.0.0. It uses default JAR packaging.

1. Identify those three values in the POM using the project model lesson. Keep the group name separate from the artifact name.
2. Use the package-phase lesson to predict the artifact path under target for default naming. Record the full project coordinates beside it.

**Check your result.** The expected artifact is target/room-report-1.0.0.jar. The project identity retains all three supplied values.
