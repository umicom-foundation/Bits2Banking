# Write and compare an opening-hours rule

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional venue accepts a reservation when the hour is at least 9 and before 17.

1. Write the rule in plain steps and trace three inputs, 8, 9 and 17.
2. Build or trace two course language versions and produce a result table with one row per input.

**Check your result.** Only 9 meets the interval of the three examples. The versions give the same decisions.
