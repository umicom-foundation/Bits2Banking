# Show angle brackets as part of a label

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local practice form accepts the fictional label `Cold <brew>`. The label should appear exactly as text in its results page.

1. Pass the label as a view value and escape it at the output using the view helper taught in the course.
2. Read the displayed text and inspect the corresponding element's HTML.

**Check your result.** The page displays `Cold <brew>` visibly. The HTML contains escaped angle brackets in the text.
