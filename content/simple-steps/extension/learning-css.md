# Reuse one spacing value in two page sections

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice header and results list both need an 8-pixel space between their direct items. The exercise asks for an easy way to adjust both later.

1. Define one custom property for the shared gap and apply it to both sections with var().
2. Inspect the computed gaps, change the shared value to 12 pixels, and inspect again.

**Check your result.** Each section has an 8-pixel gap initially and a 12-pixel gap after the shared value changes.
