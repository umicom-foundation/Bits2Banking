# Send a validated deal through three operations roles

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional desk books deal FX7 in portfolio Training. The middle-office check approves the booking for processing.

1. Record the deal ID and portfolio as the front-office capture, then mark the middle-office validation result.
2. Write a separate back-office settlement instruction that references the same deal ID.

**Check your result.** The three worksheet stages all refer to FX7. The final instruction can be traced to the approved booking in portfolio Training.
