# Check that a test report’s totals agree

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A sample XML test report declares zero failures. It has three case elements and the second contains a failure element.

1. Use the test report lesson to count case elements. Count failure elements within those cases separately.
2. Correct the summary failure count in the scratch document and check it against the unchanged cases.

**Check your result.** The summary agrees with the three cases and one failure shown in the body.
