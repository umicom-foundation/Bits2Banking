# Show the returned value in two views

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A single practice Wt session displays the free seat count beside a form and again in a review panel.

1. Using the Wt and C boundary lesson, have both views read one accepted result from the session. Use 5 as the initial result.
2. Trace a new accepted result of 3 and refresh each view from that stored value. Keep the shared calculation inside the C service.

**Check your result.** Both views first display 5 and then display 3. One service result supplies both updated labels.
