# Check that equal keys keep their original order

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice insertion sort takes rows B with key 4, A with key 2, and C with key 4 in that order.

1. Insert each row into an ascending run while keeping an existing equal key before a newly inserted one.
2. Read back the letters and check the relative order of the two rows with key 4.

**Check your result.** The final order is A, B, C. B stays before C.
