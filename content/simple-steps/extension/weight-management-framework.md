# Keep a review separate from a new edit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional application stores an accepted revision at 71,000 grams. A newer draft contains 71,500 grams.

1. Draw a row for the reviewed revision and a row for the new draft. Identify what the report reads before review is complete.
2. Use the course’s acceptance trace to mark when 71,500 grams becomes available as the reviewed result.

**Check your result.** The reviewed report initially stays at 71,000 grams. The new value appears there only after its own acceptance.
