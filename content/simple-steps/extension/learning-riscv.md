# Compare one bit pattern two ways

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch RV64 register contains 64 one bits. Another register contains the value 1.

1. Use the signed comparison lesson to interpret the first register as a signed integer and record whether it is less than 1.
2. Interpret the same bits as an unsigned integer and record the comparison against 1 again.

**Check your result.** The signed value is -1 and is less than 1. The unsigned value is 18446744073709551615 and is greater than 1.
