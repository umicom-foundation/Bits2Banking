# Trace the project’s Gradle version

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two sample logs show Wrapper 8.7 and PATH Gradle 9.0. A teammate needs to know which one ran the project task.

1. Find the Wrapper properties in the build lesson and match the pinned distribution version to the first log.
2. Label the command using gradlew as the project Wrapper and label the separate gradle command as a PATH executable.

**Check your result.** The record identifies 8.7 as the project task launcher and lists 9.0 separately as the other installation.
