# Describe an action and its limit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice iPhone screen has a plus button and displays a room count of 3. The room limit is also 3.

1. Use the accessibility lesson to write the button’s spoken label as Add one visitor. Write down why a symbol by itself would be ambiguous.
2. Draw the activation result when the room is already full. Keep the count visible and provide a separate status that can be read aloud.

**Check your result.** The action label reads Add one visitor. Activating it at the limit leaves the count at 3 and reports The limit is 3.
