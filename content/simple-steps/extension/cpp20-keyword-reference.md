# Reuse a type from an earlier declaration

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A short C++20 training function declares auto opening = 25. It needs an adjustment of the same type with value -5.

1. Declare decltype(opening) adjustment = -5 in the same function. Write the inferred type of both variables.
2. Use the expression opening + adjustment in the course's console output pattern and calculate the expected line.

**Check your result.** Both names have type int and the expression prints 20.
