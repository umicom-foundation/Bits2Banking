# Assign a new identifier after a deletion

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local notes exercise has IDs 4 and 10. A user removed the first note, leaving only ID 10.

1. Use the note identifiers lesson to compute the next ID from the largest currently present ID instead of the list length.
2. Try the same function against the original two-note fixture and the smaller one-note fixture before storing a new note.

**Check your result.** The next ID is 11 for both fixtures, and neither fixture has an existing note with that ID.
