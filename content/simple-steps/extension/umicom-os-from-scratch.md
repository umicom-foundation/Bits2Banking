# Distinguish layout evidence from boot evidence

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One training record shows that an image contains an expected partition. A second record shows a completion marker in its matching emulator profile.

1. Write the claim each record supports and check that their image digests match.
2. Add a third line for physical testing. Leave it open until a real authorized run supplies its own record.

**Check your result.** The partition record supports layout. The guest record supports only the named virtual boot. Physical qualification remains a separate result.
