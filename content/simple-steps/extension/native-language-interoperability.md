# Carry a result through two bindings

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice C service returns a status and writes an output through a provided result object.

1. Use an accepted input from the lab in the C reference run. Write the type, representation and expected output.
2. Use another supported language binding from the course. Compare the status and value under the same input.

**Check your result.** The bindings agree on the C contract’s accepted status and result for that input.
