# Render a useful empty list

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice React component first receives no rooms and then receives one room named Gallery.

1. Add an empty branch that shows No rooms available, with the room list in the other branch.
2. Trace the component with both sets of props. Check which text and list items each render contains.

**Check your result.** The empty case shows No rooms available with zero room items. The second shows one item named Gallery and no empty message.
