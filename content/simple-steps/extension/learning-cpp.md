# Read back two consecutive journal entries

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

An empty temporary journal receives the practice notes First check and Second check in separate saves.

1. Append both notes through the course journal interface and close the stream after each save.
2. Read the file back as lines and compare the order with the saves.

**Check your result.** The journal has exactly two lines. First check is followed by Second check.
