# Group two fields before adding amounts

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice entry type has a cents field and a posted flag. Four entries represent posted 200, pending 900, posted -40 and pending -60.

1. Use the structure in Group data and return results to write the four entries as paired values. Mark each true posted flag.
2. Add cents only for entries with a true flag. Count the full array with sizeof entries divided by sizeof entries[0].

**Check your result.** The array has four entries. Two are posted. Their total is 160 cents.
