# Recheck a saved snapshot after an edit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice artifact record holds the SHA-256 of a file containing exactly 12 as UTF-8 text with no line ending. A second copy contains exactly 15.

1. Compare the recorded hash with a fresh hash of the original bytes. Compute the hash of the second copy with the same tool.
2. Mark each file as matching or changed. Keep the original record beside both observations.

**Check your result.** The original matches its recorded hash. The 15 copy produces a different hash and is labelled changed.
