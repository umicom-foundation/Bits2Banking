# Convert a measurement with an explicit unit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A room inspection ends after 45 seconds, but its exported record needs milliseconds.

1. In a copy of the first Fortran program, store seconds in an integer and use a named parameter for 1000 milliseconds per second.
2. Multiply the two values and print the result with the text ms. Repeat with zero seconds before adding any other operations.

**Check your result.** The two outputs report 45000 ms and 0 ms.
