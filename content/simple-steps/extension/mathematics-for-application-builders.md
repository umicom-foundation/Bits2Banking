# Make and check a rate table

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A hypothetical copy shop charges £2 setup and 50 pence per sheet.

1. Make a table for 0, 2, 4 and 6 sheets using the same unit in every row. Check the difference between adjacent two-sheet rows.
2. Use the table to predict the cost for 8 sheets. Compare it to the original rule.

**Check your result.** The four initial charges are £2, £3, £4 and £5. Eight sheets cost £6.
