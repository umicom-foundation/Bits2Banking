# Plan one comparison with the same input images

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom experiment compares output widths of 128 and 256 pixels for the same three approved training images.

1. List the original image IDs in one order and give each image the same caption in both run plans.
2. Write the only intentional difference, the output width, and add a row for each expected prepared image.

**Check your result.** Each plan lists the same three image IDs and captions. One lists width 128 for all outputs and the other lists width 256.
