# Give unknown status values their own result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch payment display receives the invented state strings pending, paid and unexpected.

1. Use the course’s payment-state exercise to map pending to Awaiting payment and paid to Payment recorded.
2. Add an explicit fallback message Unknown payment state. Try all three inputs without making any payment calls.

**Check your result.** The three inputs display Awaiting payment, Payment recorded, and Unknown payment state in that order.
