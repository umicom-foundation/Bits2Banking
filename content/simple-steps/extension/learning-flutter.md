# Check what a rebuild keeps

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A room counter shows 7. A designer changes a heading without opening a new counter screen.

1. Use the state lesson to write a widget test sequence that changes the heading while keeping the counter widget’s identity.
2. Write a second sequence that closes the counter and opens a fresh one with an initial count of zero.

**Check your result.** The first sequence shows the new heading and count 7. The fresh screen shows count 0.
