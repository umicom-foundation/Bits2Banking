# Check how a local result fits a fixed limit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A toy local client receives images with 7, 11 and 16 units of decoded data. Its practice limit is 12 units.

1. Write each input size and its expected admission result. Trace the client check before any display step.
2. Test or trace a new image with exactly 12 units. Explain what “at most” means in the input policy.

**Check your result.** 7, 11 and 12 are within the typed practice limit. 16 exceeds it.
