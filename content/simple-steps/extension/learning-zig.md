# Add a boundary to a small local count

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice function must accept a report count from 1 through 5. Use 1, 5 and 6 for the exercise.

1. Write the expected result for each value before adapting the lesson’s explicit-error example.
2. Run or trace the new cases. Keep the numeric result under the accepted path and show the refused case separately.

**Check your result.** 1 and 5 are accepted. 6 returns the chosen range failure and supplies no replacement count.
