# Compare two configurations for one test input

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local example can find the same installed native library through two documented practice prefixes.

1. Run or trace the accepted input with each valid prefix. Keep the package or binary identity visible.
2. Compare the native status and units under both settings. Record what would prevent treating them as equivalent.

**Check your result.** With the same library identity and input, the rule gives the same status in both runs.
