# Check a counter at wraparound

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A three-bit practice counter is at 110 before an incoming rising clock edge.

1. Use the configurable counter lesson to write the value immediately after each of two rising edges.
2. Add a sample between the two rising edges and record the counter value there as well.

**Check your result.** The samples read 111 after the first edge, 111 between edges, and 000 after the second edge.
