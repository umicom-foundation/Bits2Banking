# Compute one row of a matrix product

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A toy row is `[1, 3]`. The two columns are `[2, 4]` and `[5, 0]`.

1. Calculate one dot product per column. Write the output values in their order.
2. Swap the columns and repeat. Compare what changes in the output.

**Check your result.** The row is `[14, 5]`. Swapping columns produces `[5, 14]`.
