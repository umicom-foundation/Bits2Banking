# Follow four instructions through a register

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice machine has a saved value of 14 and a register initially set to 0.

1. Load 14, add 3, subtract 2, and store the result to a new memory location. Write down the state after each operation.
2. Compare the original memory location with the destination after the store.

**Check your result.** The register holds 14, then 17, then 15. The destination contains 15, and the original memory location remains 14.
