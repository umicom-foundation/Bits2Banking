# Compare a pending row in two views

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training table contains posted cents of 160 and 240 and a pending row of 300.

1. Enter the rows into the documented JSON and spreadsheet formats. Calculate only the posted total.
2. Change the second posted amount to 245 in both source copies. Compare the new totals and the pending row display.

**Check your result.** The posted total changes from 400 to 405 cents. The pending amount stays 300.
