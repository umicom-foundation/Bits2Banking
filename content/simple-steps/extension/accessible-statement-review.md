# Announce a single visible row

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

In a scratch copy of the lesson statement, only row 101 should remain posted. The display currently uses rows for every count.

1. Mark row 102 pending in both its data-state and its visible label. Replace the status assignment with text that uses row for a count of one and rows otherwise.
2. Reload. Select and clear Show only posted rows using the keyboard.

**Check your result.** The checked view displays only reference 101 and says 1 row shown. Clearing it displays all three and says 3 rows shown.
