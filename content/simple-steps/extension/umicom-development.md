# Connect a console result to a second client

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A small Framework laboratory already exposes a checked core result and text output.

1. Record one accepted input and status from the local C lab. Sketch a second thin client that calls the same operation.
2. Compare the status and expected value in both client traces. List one display detail that may differ.

**Check your result.** Both clients use the same core result. Their presentation can differ while preserving the checked content.
