# Work with a pair of room records

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice report has Gallery with 2 visitors and Studio with 9 visitors.

1. Define a FreeBASIC record with a room name and a whole-number visitor count. Populate two records with the sample values.
2. Read the count from each record and add them. Use the stored names as the labels when you show the individual counts.

**Check your result.** The report shows Gallery 2, Studio 9, and Total 11.
