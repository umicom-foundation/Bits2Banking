# Keep two versions in one practice folder

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

You want to preserve a short reading list while trying edits to a copy.

1. In your editor save training-list.txt with one line that reads Read chapter 1. Save a second file named training-list-draft.txt in the same practice folder.
2. Replace the line in the draft with Read chapters 1 and 2, save it, and reopen both filenames.

**Check your result.** training-list.txt contains Read chapter 1. training-list-draft.txt contains Read chapters 1 and 2. The two names identify separate saved files.
