# Put two spoken rules into one condition

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A workshop seat is ready when there is space and the request is confirmed.

1. Build a four-row truth table for the two yes-or-no inputs. Circle the row that qualifies.
2. Translate that same rule into two supported languages and use the table to check both.

**Check your result.** Only the row with both conditions true qualifies in either language.
