# Compare each close with the preceding bar

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Three fictional bars close at 6, 9, and 12 in that order.

1. Use the course’s history reference to place the preceding close beside each current close. Leave the first preceding value unavailable.
2. Subtract the preceding close from the current one where both exist. Keep the missing first result separate from a numeric zero.

**Check your result.** The differences in order are unavailable, 3, and 3.
