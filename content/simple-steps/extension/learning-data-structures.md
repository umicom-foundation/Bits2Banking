# Reuse the first slot in a circular queue

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice ring queue has three slots numbered zero through two. It starts empty.

1. Enqueue A and B, dequeue A, then enqueue C and D while recording each write position.
2. Read the queue from its oldest value until it is empty.

**Check your result.** D reuses slot zero. The remaining records come out as B, C and D.
