# Map two pages to separate routes

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local project needs a rooms page and a sessions page, each displaying a different heading.

1. In a scratch route table, use the course’s route pattern to give the GET paths /rooms and /sessions separate handlers.
2. Return Rooms from the first handler and Sessions from the second. Follow both path-to-handler mappings in a local exercise or on paper.

**Check your result.** GET /rooms displays Rooms and GET /sessions displays Sessions.
