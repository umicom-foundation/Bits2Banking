# Show the same value in two contexts

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local page reuses `Room & garden` as a heading and as an approved form value.

1. Use the full lesson to find the escaping operation for each display context. Make a separate note about why the context matters.
2. Open the local example and check the text and the inspected field value. Preserve the unescaped value in the sample data.

**Check your result.** Both destinations represent `Room & garden`. Their output operations belong beside the context they serve.
