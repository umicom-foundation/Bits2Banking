# Record enough context to review a local decision

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice review begins with a request ID, an allow or refuse outcome, and the requester’s full postal address. The review only needs to match an outcome to a request.

1. Write a review record containing request ID R18, the action label read-report and the outcome allow.
2. Use R18 to match the record to the worksheet and check the fields exposed in the review.

**Check your result.** The review identifies R18, read-report and allow. No address is included.
