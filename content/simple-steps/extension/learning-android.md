# Return a small C model result through the app boundary

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training Android view calls a local C function that adds two pack counts. The fixture inputs are 4 and 3.

1. Confirm the Java native declaration and the registered C entry use the same two integer arguments and integer return.
2. Pass 4 and 3 from the practice view and display the returned count beside its label.

**Check your result.** The view displays Packs 7.
