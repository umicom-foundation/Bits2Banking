# Read a field through a record accessor

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A Java exercise represents a delivery of three boxes using a record.

1. Declare record Delivery(int boxes) and create a Delivery value with 3.
2. Pass the value to a method that prints what boxes() returns.

**Check your result.** The method prints 3.
