# Give each currency its own subtotal

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice statement contains posted entries of EUR 240 cents, USD 300 cents and EUR negative 40 cents.

1. Add accepted rows by currency using signed integer amounts.
2. Print the subtotals with currency keys in ascending order.

**Check your result.** The first subtotal is EUR 200 cents and the second is USD 300 cents.
