# Compare posted totals across two valid snapshots

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The first synthetic statement has posted cents of 400 and −150. The next adds a posted 75 and a pending 500.

1. Total only the posted inputs in each snapshot on paper. Keep both snapshot identifiers visible.
2. Run the course’s calculation exercise after changing the input to the second snapshot. Compare both accepted results.

**Check your result.** The first total is 250 cents. The second is 325 cents. The pending 500 stays outside the posted sum.
