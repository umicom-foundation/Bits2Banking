# Check one bean with two explicit inputs

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the course’s native practice rule with one valid receipt and one that it refuses.

1. Write the expected status from the C reference for each input. Trace the Spring provider call for the same values.
2. Repeat the two cases in the service test and compare the results to the C check.

**Check your result.** The service preserves the two different native decisions for the two input cases.
