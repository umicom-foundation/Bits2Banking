# Write one function to count the supplies needed

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training kitchen uses two filters per coffee station. The practice setup has four stations.

1. Write a function named filters_needed that takes the station count and returns twice that count.
2. Call it with four stations and then with zero stations. Write down the two returned values.

**Check your result.** The function returns 8 for four stations and 0 for zero stations.
