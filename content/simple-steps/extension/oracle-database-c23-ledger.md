# Represent a negative fractional amount

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The practice report must retain the exact value −46.75 and marks the adjustment as present.

1. Write the original amount and its scale. Convert to cents while preserving the sign.
2. Compare the result with a second row with no adjustment using the course’s optional-value pattern.

**Check your result.** The exact reported amount is −4,675 cents. The absent row has no selected amount.
