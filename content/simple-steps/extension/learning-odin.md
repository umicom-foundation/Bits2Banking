# Keep shared calculations behind one call

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch Odin command and a scratch on-screen view both show the number of free seats in a room.

1. Draw the language boundary from each caller to one provided C function. For this fixture, give the function capacity 12 and occupied count 7.
2. Mark where each caller checks the returned status, then trace how it shows the returned seat count.

**Check your result.** Both callers display 5 free seats from the same result and the diagram contains one implementation of the subtraction.
