# Make a limited result repeatable

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Three fictional documents have IDs R3, R2, and R1. R3 is dated 2026-01-02. R2 and R1 are both dated 2026-01-01.

1. Use the ordering lesson to sort by date ascending, then by ID ascending where two dates match.
2. Apply a limit of two after sorting. Reverse the input order and check the same selection again.

**Check your result.** Both input orders yield R1 followed by R2. R3 is outside the limit.
