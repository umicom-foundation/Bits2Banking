# Check a condition on a signed value

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use inputs −2, 0 and 3 in a supported checked-integer source lesson.

1. Write a condition that selects negative inputs and record the three expected paths.
2. Use the signed-comparison program from the course. Run or trace all three, keeping the zero case separate in your notes.

**Check your result.** Only −2 takes the negative branch. Zero and 3 follow the remaining path.
