# Report a third screen state

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local course view can show a loading view, an accepted empty report and an error.

1. Prepare one small input for each state. Write the expected visible message for the examples.
2. Use the course example to display the three states one at a time. Check that the empty report uses its own message.

**Check your result.** The three states are distinguishable before the user sees any rows.
