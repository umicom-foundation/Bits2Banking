# Compare two fictional scopes side by side

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Training consent A allows currency. Training consent B allows currency and a masked account name.

1. Write one paper request for currency and one for both fields. Match each requested field to what each consent includes.
2. Make a four-cell table for the two requests under the two consents. Mark the allowed combinations.

**Check your result.** The currency-only request fits both. The two-field request fits B only under this exercise’s rules.
