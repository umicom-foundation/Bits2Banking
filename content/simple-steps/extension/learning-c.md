# Sum a complete array with a counted loop

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A C worksheet lists three brewing times of 2, 3 and 5 minutes.

1. Give a sum function the array and its three-element length, then visit one element per loop iteration.
2. Print the returned sum and, on a separate line in the exercise, the number of elements visited.

**Check your result.** The sum is 10 minutes and the visit count is 3.
