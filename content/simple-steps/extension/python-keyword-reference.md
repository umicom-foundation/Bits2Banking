# Give one function two return paths

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice container limit is four items. Use the tested counts 4 and 5.

1. Write a small function that returns the permitted value or a chosen refusal result. Use the course’s `def` and `return` reading.
2. Run both cases. Add a count of zero and compare the outcomes by tracing the condition.

**Check your result.** 4 and zero are within the maximum. The count of 5 uses the refusal path.
