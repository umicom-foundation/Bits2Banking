# Read a small part of a sequence without changing it

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A D exercise has the sequence 4, 9, 12 and 18. A read-only view needs the two middle values.

1. Create the read-only slice covering index 1 up to but excluding index 3.
2. Pass the slice to a function that sums its values, then read the original sequence again.

**Check your result.** The slice contains 9 and 12 and returns the sum 21. The source still contains 4, 9, 12 and 18.
