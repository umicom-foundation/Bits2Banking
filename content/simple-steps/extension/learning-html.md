# Make a failed load understandable

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local mock-up opens a room report and cannot read its data file.

1. Use the loading and failure lesson to make two HTML drafts. In the first, show Loading report in the page’s status area.
2. In the second, replace the status with Could not read report and keep the export button disabled. Open each draft locally or review its source.

**Check your result.** The first draft displays Loading report. The second displays Could not read report and offers no enabled export button.
