# Check two local report sources

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local fixture emits a report total of 970 cents. The native course producer is configured for the same practice data.

1. Record the field and units expected by the JavaScript adapter. Feed the two outputs into the same validation path.
2. Compare the reports by value and keep the source identity beside each result.

**Check your result.** Both accepted results show 970 cents for the same practice inputs. Their producer identities remain distinguishable.
