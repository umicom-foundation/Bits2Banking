# Check the first and last valid values

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training plan contains six lessons. The practice condition rejects a completed count below zero or above the total.

1. Use the decision lesson to trace the completed counts -1, 0 and 6. Label each comparison true or false.
2. Add 7 as a final case. For each accepted case calculate how many lessons remain.

**Check your result.** The values -1 and 7 are refused. Zero completed leaves six to do, and six completed leaves zero.
