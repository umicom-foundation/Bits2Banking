# Trace a process that waits for input

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scheduling worksheet starts with a report process and a notes process both ready. The report process runs first and requests input that is not ready.

1. Mark the report process waiting and let the notes process run.
2. Signal that the input has arrived and mark the report process ready again.

**Check your result.** The report process changes from running to waiting and then to ready. The notes process can run while the report waits.
