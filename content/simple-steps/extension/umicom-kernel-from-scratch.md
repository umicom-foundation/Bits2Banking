# Compare two isolated boot identities

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

You have two diagnostic image files in separate disposable workspaces.

1. Calculate a digest for each using the workshop’s file-only instructions. Keep filenames, boot profiles and output locations together.
2. Load each image only in its appropriate guest if your lab has that path. Keep each observed marker beside the correct digest.

**Check your result.** The two records remain separate and identify the boot mode and bytes actually used for each observation.
