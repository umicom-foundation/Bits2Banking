# Compare skipping a visit with stopping the loop

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom loop reads `[3, 0, 8]` and adds visited nonzero items.

1. Trace a version that continues after reading zero. Trace a second version that stops at zero.
2. Compare the visited entries and final totals. Identify the word that changes the action.

**Check your result.** Continue reaches 8 and totals 11. Break stops before 8 and leaves 3.
