# Compare two paper update sizes on one link

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom link transfers 8 megabits each second. Fixed latency is 0.1 seconds per message. Compare one update of 8 megabits with a compressed update of 2 megabits, ignoring all other overhead.

1. Divide each payload size by the transfer rate to find pure transmission time.
2. Add the same message latency to both totals. Keep latency and transmission time in separate columns.

**Check your result.** The two transmission times are 1.0 and 0.25 seconds. Estimated totals are 1.10 and 0.35 seconds under the stated model.
