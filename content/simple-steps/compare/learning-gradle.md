# Distinguish cached work from a task with no inputs

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two teaching logs mention the same Java test task. One shows FROM-CACHE and the other shows NO-SOURCE.

1. Use the task-outcomes lesson to annotate whether each result restores outputs or skips because the task has no source inputs.
2. Write an evidence sentence for each run. Check whether either log shows the test bodies executed during that invocation.

**Check your result.** FROM-CACHE reports restored outputs. NO-SOURCE reports no source input. Neither shows test execution during the recorded run.
