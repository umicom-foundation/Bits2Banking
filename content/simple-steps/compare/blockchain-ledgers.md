# Choose the right evidence for two document exchanges

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One offline classroom file is compared against a trusted reference digest. A second file carries a signed statement and you have its trusted verification key.

1. Use the course's lesson on hashes and signatures to label the inputs for each verification.
2. Write the conclusion supported by a successful check in each case. Add the separate evidence needed to grant a business permission.

**Check your result.** The digest check compares byte integrity against the trusted reference. Signature verification ties a signed message to the trusted key. A business permission also needs authorization rules.
