# Compare a direct validation and a report check

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A native SDK workshop validates a venue record before creating its report.

1. Find a valid record in the lab and trace its validator result. Then inspect the report check for the same record.
2. Describe what a valid record alone proves and what extra evidence the finished report provides.

**Check your result.** Validation admits the input. The report check also confirms that output was produced as expected for that input.
