# Compare familiar and unknown snapshot versions

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two fictional snapshots both contain row 30 with 500 posted cents. The first declares version 1 and the second version 2.

1. Use knownReportVersion in Plan a host migration to trace each version value before any rendering.
2. Write the result and mark which snapshot may proceed to the subsequent row checks.

**Check your result.** Version 1 gives 1 and may proceed to row checks. Version 2 gives 0 and is refused at the version boundary.
