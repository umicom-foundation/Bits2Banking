# Compare two relative link origins

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch site has both courses/start.html and courses/room/start.html. Each file links to next.html using the same relative address.

1. Use the relative resources lesson to resolve the address from the first document’s folder. Repeat from the second folder.
2. Compare both completed paths and decide where a same-folder next page would have to be placed for each link.

**Check your result.** The paths are courses/next.html and courses/room/next.html respectively.
