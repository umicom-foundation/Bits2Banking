# Compare a toy latent's size with the rendered image

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A hypothetical image codec turns a 64 by 64 pixel grid into an 8 by 8 latent grid. Use one number per grid position in this exercise.

1. Count the positions in each grid and put the counts beside the stage that owns them.
2. Divide the rendered position count by the latent position count.

**Check your result.** The rendered grid has 4,096 positions and the toy latent has 64. The position-count ratio is 64 to 1.
