# Compare a full group and a filtered group

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A synthetic ledger contains posted cents of 175 and −25 and a pending 60.

1. Write the full signed total. Then use the prepared filter exercise to compute only posted values.
2. Compare the row counts and state which total the report calls posted.

**Check your result.** The full sum is 210 cents over three rows. The posted sum is 150 cents over two rows.
