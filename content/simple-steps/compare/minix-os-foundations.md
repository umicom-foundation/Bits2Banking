# Compare an immediate and delayed reply

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two local guest traces send the same fictional file request. One receives its matching reply immediately and the other receives it one observation later.

1. Place each event on a labelled timeline. Record when the caller can use the reply.
2. Compare the last observed state at the same intermediate point in both traces.

**Check your result.** The first trace has a usable reply at that point. The second is still waiting until its matching reply arrives.
