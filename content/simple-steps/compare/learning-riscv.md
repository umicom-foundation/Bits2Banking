# Compare a wrapped shift and a rotation

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The input bits in an eight-bit classroom register are 10000001.

1. Trace a one-bit left shift within the fixed width. Note the old top bit that leaves the register.
2. Trace a one-bit left rotation using the rotation lesson. Place the old top bit in the new lowest position.

**Check your result.** The shift produces 00000010. The rotation produces 00000011.
