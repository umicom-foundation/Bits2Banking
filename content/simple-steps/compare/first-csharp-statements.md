# Compare two zero totals with different status

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One C# call receives a pending row worth 300 cents. A second receives a waiting row worth the same amount.

1. Trace the branches in TryPostedTotal separately and write the Boolean returned before recording the amount.
2. Write a display label that distinguishes a valid total from a rejected attempt, using both return values.

**Check your result.** The pending case returns true with total 0. The waiting case returns false with total 0 and should be labelled rejected.
