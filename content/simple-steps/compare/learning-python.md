# Compare a Boolean with a note identifier

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two synthetic records have id values True and 1. Note IDs must be positive integers and Boolean values are refused.

1. Use the Boolean and identifiers lesson to trace a generic isinstance check for both values. Mark their outcomes without accepting either yet.
2. Trace the course’s explicit Boolean exclusion before the positive integer check.

**Check your result.** The generic isinstance check matches both values. The explicit rule refuses True and accepts the integer 1.
