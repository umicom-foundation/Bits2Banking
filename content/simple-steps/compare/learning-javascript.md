# Compare a saved count with the current draft

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A browser practice screen has five saved notes and a sixth note in an unsaved editor.

1. Use the lesson about visible and saved state to count persistent records and records shown in a preview that includes the draft.
2. Trace a local reload before saving, then repeat with a successful save of the exact draft before reload.

**Check your result.** Before save the preview count is 6, but reload shows 5. After an accepted save, reload shows 6.
