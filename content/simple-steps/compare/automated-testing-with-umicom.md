# Compare a skipped fixture and a missing command

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local practice report marks an optional equipment check as Skipped. A second check names a program that is absent and is marked Not Run.

1. Use Separate a skip from a test that could not start. Copy the two result words and their recorded reasons.
2. Write a coverage statement and a next investigation for each row. Keep the summary count for passed cases separate.

**Check your result.** There are zero passing checks among these rows. One was skipped for optional equipment and one could not start because its command was missing.
