# Compare a native print exercise and a foreign call

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two paper builds use the same folder. The first contains only the course’s Odin hello program. The second refers to BtbActivityNext.

1. Mark which build declares a foreign library and name the contract used by the foreign procedure.
2. Remove the supplied C object or archive from the paper build inputs and trace where each build gets its needed implementation.

**Check your result.** The hello program does not need the C archive. The exercise that refers to BtbActivityNext needs a linked definition of that symbol.
