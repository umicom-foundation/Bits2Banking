# Compare the first item returned by a stack and a queue

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A paper stack and a paper queue each receive K, L and M in that order.

1. Remove one item from the stack and write down its returned entry.
2. Remove one item from the queue and write down its returned entry.

**Check your result.** The stack returns M first. The queue returns K first.
