# Compare a returned message with a confirmed publication

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom exercise records an accepted broker confirmation for one event. Another event has a return observation.

1. Use the speech of the full lesson to label event identity, publication observation and destination evidence.
2. Compare what each observation allows you to record in the durable outbox state.

**Check your result.** They remain distinct observations. A return cannot be recorded as proof of a delivered destination effect.
