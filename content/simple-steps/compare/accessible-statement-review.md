# Compare two table captions in a narrow window

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two offline copies use the same training rows. Copy A keeps the course's native caption, and copy B uses only a paragraph above an otherwise identical table.

1. Open both copies at a narrow width. Confirm that the visible row order and state labels match.
2. Inspect the table markup and note which copy has a name attached directly to the table element.

**Check your result.** Both copies show the same three training rows. Copy A exposes Reserve account movements as its native table caption. Copy B has a separate paragraph and no caption element.
