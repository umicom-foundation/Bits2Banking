# Compare a typed field read with a display label

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice row stores status `posted` and amount 775 cents.

1. Write the field types used by the validator. Inspect the same row in the HTML table or spreadsheet example.
2. Compare the labels with the validated source fields. State which belongs in code and which belongs in the user’s view.

**Check your result.** The source includes a string status and signed integer amount. The visible label explains that 775 is in cents.
