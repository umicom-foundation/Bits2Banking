# Compare two bracing spellings

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One C23 copy starts main with ordinary braces. Another uses the <% and %> spellings from Read alternative C punctuators. Both set checks to 4, add 3 if it is less than 5 and return it.

1. Mark the opening and closing tokens in each copy for both the function and the if block.
2. Trace the condition and the return using the equivalent block structure in both copies.

**Check your result.** 4 is below 5. Both token spellings select the same block and the return value is 7.
