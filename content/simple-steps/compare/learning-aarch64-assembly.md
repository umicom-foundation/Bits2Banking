# Compare two object formats for the same instruction

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The course provides object examples for the same AArch64 return function in ELF64 and Windows ARM64 COFF.

1. Read each object's file header using the course's inspection workflow and record the object format.
2. Find the target architecture for each object and compare the two results.

**Check your result.** The formats are ELF64 and COFF respectively. Both objects target AArch64.
