# Compare a file inspection and a guest boot

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A disposable practice image has a verified digest and structure. An emulator transcript shows a named startup marker for the same bytes.

1. Record the digest and tool action for the file inspection. Record the named emulator profile for the transcript.
2. Write the separate observation proven by each tool and keep the link between them through the common digest.

**Check your result.** The first record identifies the image layout. The second establishes the named marker in that specific guest run.
