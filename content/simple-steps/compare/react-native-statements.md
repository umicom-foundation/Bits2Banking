# Compare a loading state with an empty state

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A hypothetical page has no visible rows during loading and no rows in a successful empty report.

1. Feed both state objects to the course’s component in its local setup. Record the displayed messages.
2. Compare which state has an accepted response and which waits for one.

**Check your result.** The early view says it is loading. The accepted empty input shows its own empty result.
