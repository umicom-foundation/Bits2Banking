# Compare an empty span with an invalid one

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A paper review traces BtbSumCounts with values set to NULL. The first call supplies count zero and the second supplies count one.

1. Read Let a function read memory you still own. Mark the case with an empty collection.
2. Write which call can be processed under the contract and whether either call may read an element.

**Check your result.** NULL with zero represents an empty collection and reads zero elements. NULL with one is invalid and is refused before any element read.
