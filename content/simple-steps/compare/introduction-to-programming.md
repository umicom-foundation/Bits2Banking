# Compare repeated statement lines with a counted loop

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two plain-language scripts each print Setup complete four times. One repeats the full print line four times and one uses a repeat count of four.

1. Count the output lines in each trace.
2. Change each script to print twice and count how many statement lines or count values must change.

**Check your result.** Both original traces print four lines. The explicit script needs two print lines removed, and the loop needs one count changed to two.
