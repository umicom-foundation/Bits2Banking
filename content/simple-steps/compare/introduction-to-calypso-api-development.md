# Compare two SDK references before choosing a guide

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom adapter identifies its licensed SDK as Practice Release B. The local reading pack has separate examples for Practice Release A and Practice Release B.

1. Read the release marker registered with the adapter and compare it with the heading on each example.
2. Record the matching example in the design notes and keep the other under version-specific references.

**Check your result.** The design note selects the Practice Release B example and keeps the Practice Release A example as a separate reference.
