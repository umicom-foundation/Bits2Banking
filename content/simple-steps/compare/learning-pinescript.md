# Compare the current bar series with a fixed reference

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A paper chart has closed values 3, 7, and 5 and a fixed reference of 5 on every bar.

1. Write each closed series value and repeat the same reference in the line below it. Compare values within each bar only.
2. Mark values strictly greater than the reference, and then mark values equal to it using a different symbol.

**Check your result.** Only bar 2 is greater than the reference. Only bar 3 equals it.
