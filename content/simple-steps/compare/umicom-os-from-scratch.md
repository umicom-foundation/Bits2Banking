# Compare two file formats by their intended use

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The workshop has an optical ISO and a GPT disk image for distinct guest workflows.

1. Write the file name, digest, intended firmware path and expected observation for each.
2. Check the workshop’s command and identify which artifact belongs in its optical or disk slot.

**Check your result.** Each file stays tied to its own media type and guest configuration. Neither record claims the other format was tested.
