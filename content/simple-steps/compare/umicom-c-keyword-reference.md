# Compare inclusive and strict comparisons

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A checked example asks about values 4, 5 and 6 relative to a limit of 5.

1. Trace a strictly-less test and an at-most test using the built-in comparison constructs in the course.
2. Run the supported examples when ready or compare the two paper traces. Find the input that changes path.

**Check your result.** Both accept 4. Only the inclusive test accepts 5. Both decline 6.
