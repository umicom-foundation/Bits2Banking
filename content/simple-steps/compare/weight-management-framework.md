# Compare equal values written with different precision

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional form accepts `70.5` and `70.500` kilograms in the lesson’s format.

1. Trace both strings through the scale-to-grams parser. Record the normalized stored values.
2. Compare the values with a formatted report that consistently shows three decimal digits.

**Check your result.** Both become 70,500 grams. A three-digit display can show both as 70.500 kilograms.
