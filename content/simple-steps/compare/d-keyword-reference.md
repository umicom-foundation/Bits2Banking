# Compare a template alias with two types

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two D practice declarations use CountType!int and CountType!long from Ask the compiler about a type.

1. Substitute each supplied type into the CountType template alias. Write the new alias in full.
2. Draft one static assert with is for each resulting type. Check both claims before compiling.

**Check your result.** The first substitution gives int and the second gives long. Both assertions of those respective types are true.
