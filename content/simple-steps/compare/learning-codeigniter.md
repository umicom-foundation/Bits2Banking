# Compare request methods for the same path

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local CodeIgniter route table maps GET /label to a preview handler and POST /label to a practice submit handler.

1. Request /label using GET and check the returned fixture response label.
2. Request /label using POST with the same harmless sample field and check its fixture label.

**Check your result.** The GET response says Preview. The POST response says Submitted.
