# Compare spacing inside and outside a border

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The default content-box model gives a practice panel a 100-pixel content width. It has 10 pixels of padding and a 2-pixel border on each horizontal side, plus 5-pixel horizontal margins.

1. Calculate the width from the outer edge of one border to the other.
2. Then add the margins and compare the width of the border box with its total horizontal space.

**Check your result.** The border box is 124 pixels wide. With both margins it takes 134 pixels.
