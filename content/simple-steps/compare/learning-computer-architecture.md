# Compare sequential and independent work on two cores

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two practice workers each take four ticks to finish one independent task. The worksheet excludes startup overhead.

1. Schedule both tasks one after the other on one core and count when the second finishes.
2. Place one task on each of two cores at time zero and count when both tasks finish.

**Check your result.** Sequential work finishes at tick 8. With two cores the independent tasks finish at tick 4 in this model.
