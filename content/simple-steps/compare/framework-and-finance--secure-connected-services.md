# Compare a verified identifier with a display name

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two fictional profiles display Pat Lee. Their verified subject identifiers are U31 and U58. The local report belongs to U31.

1. Look up the report owner using the display name and count the matching profiles.
2. Repeat the lookup using the verified subject identifier already attached to the report.

**Check your result.** The name lookup has two possible matches. The owner identifier selects U31 alone.
