# Tell the prompt from a read command

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A worksheet shows PS C:\Learning> followed by Get-Content -LiteralPath .\status.txt, and the file contains ready.

1. Mark the part the shell displays and the part you would type. Circle the argument that selects the file.
2. Run only the command in a practice folder containing status.txt, or trace its action on paper using the same filename.

**Check your result.** The typed portion starts with Get-Content. It reads status.txt from the current directory, whose one line is ready.
