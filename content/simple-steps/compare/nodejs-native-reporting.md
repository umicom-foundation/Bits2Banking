# Compare direct local data and producer output

A source snapshot carries total 810 cents and the native sample can report the same fixture.

1. Run or trace the JS validator with the source snapshot first, then the producer output. Record origin and validated field values.
2. Compare the displayed text and preserve which input route supplied it in each observation.

**Check your result.** Both accepted observations represent 810 cents, with distinct source routes.
