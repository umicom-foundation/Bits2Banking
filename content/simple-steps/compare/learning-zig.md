# Compare a valid empty result with refusal

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local practice function can yield an accepted count of zero or a conversion error.

1. Make one course-style input for each outcome. Trace its return type and the branch that examines it.
2. Write what each caller can display, then compare the two status values separately from the count.

**Check your result.** An accepted zero has a result. A refusal has its error and supplies no new numeric result.
