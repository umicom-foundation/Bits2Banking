# Compare two ways the same number enters a screen

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One fictional screen calculates summary totals independently. A second consumes the validated total from a shared Framework service and only formats it for display.

1. Open Introduction to Umicom Framework Architecture and label each component that owns calculation and rendering under each proposal.
2. Add a second application to each diagram and count how many copies of the calculation still need maintenance.

**Check your result.** The independent proposal has two places that calculate the number. The shared proposal has one calculation service and two display clients.
