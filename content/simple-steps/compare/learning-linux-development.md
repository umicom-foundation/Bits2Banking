# Compare launching by a relative path and a bare name

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A disposable Linux folder has an executable program called check_room. No directory on the stated PATH contains that name.

1. Trace the location used when the command names ./check_room from that folder. Compare with a lookup using only check_room.
2. Keep the working folder and PATH fixed. Record whether each launch resolves a file under these stated conditions.

**Check your result.** The relative path resolves the local file. The bare name is not resolved by the supplied PATH.
