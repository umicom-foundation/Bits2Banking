# Compare a pulse and a sustained high signal

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Four sampled values in a practice simulation are 0, 1, 1, 0.

1. Mark every high sample using the level rule. Use the rising-edge lesson to mark where the same signal moves from 0 to 1.
2. Place the level and edge marks on the same four positions. Count marked samples in each row.

**Check your result.** The high level occurs at samples 2 and 3. The rising edge is marked only at sample 2.
