# Compare a presentation problem and a rejected report

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

In one local practice case the CSS file is missing. In another, two native input rows have the same ID, so the reporter refuses to generate a new document.

1. Use Export the page from C23 to list what remains visible in the missing-CSS case.
2. Trace both equal IDs through Summarise. Record the process output and when a preview file can be replaced.

**Check your result.** Missing CSS leaves the statement text readable. A duplicate ID yields Statement rows were rejected. on standard error and status 1, with no new HTML from that run.
