# Compare two methods for finding the first repeated label

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A sample sequence contains A, B, C and then B. Both methods examine entries from first to last.

1. For each position, use the first method to compare it with earlier entries until a match appears.
2. With the second method, keep a set of earlier labels and check membership before adding each new label.

**Check your result.** Both methods first detect a repeated label at index 3. The repeated label is B.
