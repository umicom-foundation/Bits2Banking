# Compare record numbers with array indexes

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch record chooser displays public numbers 1, 2, and 3. Its backing Pascal array is declared with indexes 0 through 2.

1. Draw the direct use of public number 3 as an index. Compare it with the subtraction step in the translation lesson.
2. Trace both index choices to the declared bounds and mark the record chosen by the translated value.

**Check your result.** Direct index 3 is outside the array. Translating 3 to index 2 selects the third record.
