# Compare a cancelled and active synthetic consent

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two practice consents allow the same read-only field list. One is currently active and the other is cancelled.

1. Write the field and consent-state checks in the order the course demonstrates. Apply them to both records.
2. Compare the access outcomes while keeping the identical request visible.

**Check your result.** Matching field scope is necessary in both cases. Only the active consent meets both checks.
