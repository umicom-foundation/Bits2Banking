# Separate the editor from the toolchain

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fixture screenshot shows a source file open in Visual Studio. A second fixture contains the UCRT64 debug preset output from the guide’s terminal.

1. Label the first item with the editor fact it shows. In the second, identify which command invoked the build and where it ran.
2. Compare the known compiler evidence in both records before assigning a build status.

**Check your result.** The open editor accounts for editing only. The terminal record identifies a build started with the UCRT64 debug preset.
