# Compare a service list with a client's requirements

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice console lists Reader and Export as requirements. The test host registers Reader and Search.

1. Write the desired service names on one side of a worksheet and the registered names on the other.
2. Mark exactly which service matches and which requirement is still missing.

**Check your result.** Reader is both required and registered. Export is missing, and Search is registered without being a requirement of this client.
