# Compare fixed-breakpoint and fluid containers

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local Bootstrap example gives one panel the container class and a second otherwise identical panel the container-fluid class.

1. Set the viewport to 900 CSS pixels and inspect the two parent widths.
2. Compare which width stays capped and which fills the available width at this viewport.

**Check your result.** The container is narrower at 900 pixels. The container-fluid panel fills the available width.
