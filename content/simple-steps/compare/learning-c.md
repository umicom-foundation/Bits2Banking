# Compare an input argument with a returned value

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A C exercise has a local integer count of 7. A helper takes an integer by value, adds 2 and returns the result.

1. Call the helper once and display the original count without assigning the return value.
2. Call it again and assign its result to a different local variable named adjusted.

**Check your result.** The original count is still 7. The separate adjusted calculation holds 9.
