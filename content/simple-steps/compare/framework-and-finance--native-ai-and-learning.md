# Compare bytes with supplied token counts

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom tokenizer fixture treats Café as one token. A second text tool reports five UTF-8 bytes for that same text.

1. List the length reported by each tool with its unit.
2. Apply a three-byte limit to the byte count and a three-token limit to the token count.

**Check your result.** Café exceeds the three-byte limit and fits the three-token limit.
