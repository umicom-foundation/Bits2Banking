# Compare two defensive session records

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A test session fixture assigns an expiry time of 10:15. Another session is explicitly signed out at 10:05.

1. At 10:16, ask the local policy check to classify the first fixture.
2. At 10:06, classify the signed-out fixture with the same check and compare the recorded reasons.

**Check your result.** Both sessions are refused. The first reason is expired and the second is signed out.
