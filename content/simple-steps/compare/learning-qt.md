# Compare formatter work and the shared C rule

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice desktop view and mobile view both ask a C policy whether Elm is accepted. The supplied fixture returns accepted in both calls.

1. Label the returned policy status in each trace. Give desktop feedback the text Saved and mobile feedback the text Name accepted.
2. Find the single authoritative validation step and compare the two view-specific labels.

**Check your result.** Both clients record one accepted policy result. The desktop and mobile labels differ without changing that decision.
