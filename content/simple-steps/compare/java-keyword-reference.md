# Compare an interface promise with a class result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A Java worksheet defines a Counter interface with a count method and a FixedCounter class that implements it and returns 6.

1. Read the interface and list the method name, parameters and return type it requires.
2. Read the implementation and call count through a Counter reference that holds a FixedCounter.

**Check your result.** The contract requires count with no parameters and an int result. The call returns 6.
