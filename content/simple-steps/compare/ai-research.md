# Compare familiar and withheld evaluations

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Model A passes 9 of 10 familiar coding tasks and 5 of 10 withheld tasks. Model B passes 8 familiar tasks and 7 withheld tasks. Both runs use the same test budget.

1. Write one row per model with separate columns for familiar and withheld results.
2. Calculate the percentage for each of the four cells. Circle the leading model independently within each column.

**Check your result.** Model A leads the familiar set 90% to 80%. Model B leads the withheld set 70% to 50%.
