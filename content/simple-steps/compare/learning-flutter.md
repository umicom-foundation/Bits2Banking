# Distinguish desktop native and browser builds

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training ledger shows one Windows Flutter run loading a C asset. The second row is a browser UI mock-up with a displayed Room ready label.

1. Use the native and browser integration lesson to label which row has an observed native symbol call. Record the browser asset type as unqualified until evidence identifies it.
2. Find the same label in both displays and compare what it demonstrates for each row’s platform.

**Check your result.** Both rows show Room ready. Only the Windows row records the observed host C asset call.
