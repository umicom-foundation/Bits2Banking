# Compare a fixed source revision with a changing branch label

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two reviews describe the same Bitcoin source function. The first gives a complete commit ID from its local checkout. The second gives only the branch label main.

1. Use the supplied source mirror's history to identify the exact revision for the first note.
2. Advance only the separate paper model of the branch by one commit and check which note still identifies its original code.

**Check your result.** The complete commit ID continues to identify the original revision. The branch label now points to the next revision in the paper model.
