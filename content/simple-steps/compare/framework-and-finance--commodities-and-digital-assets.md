# Compare two deliveries of the same mass

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two teaching tickets each report 600 kilograms. The order calls for grade X at Gate B on Monday. Ticket A matches all terms. Ticket B lists grade Y and Gate C on the same day.

1. Use the delivery-context checklist to compare mass, grade, location and date for each ticket.
2. Write a status with one line for each unmatched term.

**Check your result.** Ticket A matches all four terms. Ticket B matches mass and date, with mismatches in both grade and delivery location.
