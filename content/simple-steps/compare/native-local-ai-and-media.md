# Compare two offline mock providers

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local classroom fixture includes a text-only provider and one marked as supporting both text and images.

1. Construct a small table of capabilities. Put a text request and an image request in separate rows.
2. Apply the course’s capability check to each input under both descriptors. Check that provider selection remains explicit.

**Check your result.** Text appears in both allowed sets. Image admission fits only the provider that advertises that capability.
