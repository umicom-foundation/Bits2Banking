# Compare an inner join and a review join

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A synthetic database has account A in both inputs and account B on one side only.

1. Run or trace the matching-only query and list its account IDs. Trace the review shape from the course keeping unmatched rows.
2. Compare which list can report a missing counterpart for B.

**Check your result.** The matching-only list shows A. The review list can show both A and the missing counterpart for B.
