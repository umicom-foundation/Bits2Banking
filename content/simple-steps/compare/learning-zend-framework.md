# Compare two local title renderings

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two local templates receive the same title `Workshop “July” & guests`.

1. Inspect the value supplied to each template and then its visible heading. Write the two raw inputs side by side.
2. Keep a note of where each template turns the data into text for its own context.

**Check your result.** Both visible headings represent the same supplied title. The rendering operation belongs at each display boundary.
