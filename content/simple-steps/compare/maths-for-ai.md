# Compare an integer count and a normalized value

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A toy vector records counts `[2, 3, 5]`.

1. Write the sum of the counts. Divide each component by that same sum to form the normalized vector.
2. Compare the total and normalized values as separate quantities. Add the new components to check the representation.

**Check your result.** The count sum is 10. The normalized vector is `[0.2, 0.3, 0.5]` and sums to 1.
