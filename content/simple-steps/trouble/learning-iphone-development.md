# Identify what a simulator run proves

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A test note says the venue screen passed on hardware. Its evidence names only an iPhone simulator and one successful tap.

1. Open the target and release evidence lesson and copy the target name into an explicit field on the note.
2. Create a separate blank result field for a real device. Keep the same tap and expected change in that test plan.

**Check your result.** The note records one simulator pass and a device check still awaiting evidence. Each has its own target field.
