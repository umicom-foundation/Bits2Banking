# Read an empty snapshot

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

An AngularJS training component receives an admitted version 1 snapshot with rows: []. Its table does not appear.

1. Read the two ng-if conditions in Follow entry identities and empty states. Write the value of rows.length.
2. Evaluate the conditions using the existing report object. Check which branch carries role="status".

**Check your result.** rows.length is zero. The table is hidden and the status text reads No entries in this statement.
