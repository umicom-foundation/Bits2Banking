# Find an out-of-order service

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

In a practice plan display requires storage, and storage also requires display. Both declarations are present.

1. Draw both “requires” arrows and trace the cycle. Predict why neither service can begin.
2. Run or trace the hosted plan check. Remove the unintended requirement from storage to display, then check again.

**Check your result.** The cycle is refused. The repaired plan starts storage before display even if the source lists display first.
