# Check a teaching payment that is still pending

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A paper example shows a payment receipt with transaction ID T4. The latest classroom block lists T1 and T2.

1. Look for T4 in the classroom block list and give the receipt a status based on what you find.
2. Add a printed next block that includes T4 and update the status from the new evidence.

**Check your result.** T4 changes from pending with zero confirmations to included with one confirmation.
