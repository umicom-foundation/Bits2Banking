# Recover a fraction lost to integer division

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A Java temperature worksheet expects 2.5 from dividing 5 by 2. The recorded result is 2.

1. Inspect the types of the two values before evaluating the expression.
2. Cast one operand to double before dividing and compare the two results.

**Check your result.** The integer expression gives 2. The expression with a double operand gives 2.5.
