# Find why a blank adjustment became zero

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A simulated result indicator reports an absent adjustment. The report previously displayed it as 0.

1. Trace the indicator branch before reading the numeric value. Write which data may be used in each branch.
2. Repeat the trace with a present zero adjustment, then compare both displays.

**Check your result.** The absent case leaves its value missing. The present case displays a genuine zero.
