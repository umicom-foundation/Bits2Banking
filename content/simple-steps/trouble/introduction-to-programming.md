# Find why a repeat stops one step early

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A robot-maze worksheet asks for three one-square moves. The counter starts at one and repeats only while it is less than three.

1. Trace the counter values that actually produce a move and compare the result with three squares.
2. Change the start to zero, run the trace again, and count the moves.

**Check your result.** The first trace moves twice. The corrected trace moves at counts zero, one and two and finishes three squares ahead.
