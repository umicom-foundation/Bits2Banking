# Find a confirmation linked to a different payment

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Instruction P14 is recorded. A settlement observation comes in for P15.

1. Copy both IDs next to their message types. Check the relationship before changing P14’s status.
2. Repeat the review using a separate fictional observation with the exact P14 ID.

**Check your result.** The original observation cannot settle P14. The matching observation can be checked as separate settlement evidence.
