# Select a name by namespace URI

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local XML sample uses prefix a for urn:venue. A second copy uses prefix b for the same URI, and both name the room element.

1. Compare the lesson’s prefix and URI fields and record each element’s expanded name, the URI plus its local name.
2. Match the room by its expanded name in both copies. Include a third room element whose URI is urn:other.

**Check your result.** Both urn:venue room elements match. The urn:other room element does not match.
