# Recognise a request without a result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A simulator note shows request 17 sent to a service, followed by reply 18 from another request.

1. Write both request and reply identifiers down. Match each reply only to its corresponding request.
2. Add a received reply for request 17 in a separate trace and identify when its result becomes available.

**Check your result.** Reply 18 cannot complete request 17. The matching reply provides the result for 17.
