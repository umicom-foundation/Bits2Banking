# Check the scope on a fictional request

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice consent allows a masked account view. The request asks for the full account number.

1. Write the exact field names in two columns. Mark the requested field that does not belong to the permitted set.
2. Make a second request limited to the allowed fields in the local exercise or a paper trace. Compare the outcomes.

**Check your result.** The full-number request exceeds the practice scope. The narrowed request matches the permitted fields.
