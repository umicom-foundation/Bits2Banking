# Find a row with no amount

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

TryPostedTotal receives states posted and pending, but the amounts array contains only 700 cents.

1. Read Check the posted total and count each array's entries before the loop.
2. Predict the Boolean return and the out total. Add a test case for these exact arrays using the existing Check helper.

**Check your result.** The unequal lengths return false and total is 0. The helper prints Pass: missing amount when that is the case name.
