# Follow a change made to a copy

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A D practice variable cents begins at 20. The learner removes ref from add_five's parameter and the value printed by the caller stays at 20.

1. Read Pass values and describe function promises. Write the caller's value and the parameter value before and after cents += 5.
2. Restore ref to the int parameter and repeat the trace using the same caller variable.

**Check your result.** Without ref, the parameter reaches 25 and the caller keeps 20. With ref, the caller prints 25.
