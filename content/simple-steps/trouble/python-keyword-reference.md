# Find why a total resets on every pass

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice loop adds 3, 4 and 5 but produces 5.

1. Write the value before and after each visit. Locate the assignment that sets the total to zero inside the loop.
2. Move initialization before the first visit in your local copy. Run the same three values and check the result.

**Check your result.** Keeping initialization outside the loop yields 12.
