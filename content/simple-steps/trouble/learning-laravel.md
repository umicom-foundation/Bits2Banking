# Use the same view key as the template

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local venue route passes a value under the name heading. The practice view reads title.

1. Find the two names in the course’s route and view examples. Write the intended value, Room bookings, beside the route key.
2. Use title consistently at the boundary in a practice copy. Refresh the local page or trace the view data map by hand.

**Check your result.** The view receives title with the value Room bookings. There is one consistent name from the route to the template.
