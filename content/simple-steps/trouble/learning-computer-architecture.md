# Find which quantity is storage capacity

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A beginner reads 8 GB and 256 GB from a practice computer's specifications and treats both as working memory.

1. Identify which line is labelled RAM and which is labelled SSD in the specification.
2. Mark where an open document is worked on and where its saved file is kept.

**Check your result.** The practice machine has 8 GB of RAM for working data and a 256 GB SSD for stored files.
