# Show when a summary could not refresh

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training screen shows a saved 620-cent summary. A new calculation request fails.

1. Keep the saved summary in view and label it Last successful calculation. Leave the new result field empty.
2. Record the service result as failed and check both screens that use the service.

**Check your result.** Both screens still show the saved 620 cents with its label, and both report a failed refresh with an empty new result.
