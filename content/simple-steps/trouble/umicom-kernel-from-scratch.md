# Find the last known boot observation

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A disposable emulator transcript has a first boot marker followed by an early exit, without the lesson’s normal completion marker.

1. Write the exact image path, digest and last complete marker that appeared. Keep the exit status beside it.
2. Compare against a successful transcript from the same profile in the full course.

**Check your result.** You can identify the last observed stage. The interrupted trace remains separate from the completed run.
