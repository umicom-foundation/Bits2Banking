# Spot an update with a different starting point

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Worker A's candidate update names checkpoint C07. Worker B reports an update in the same round but names checkpoint C06. The round is defined to accept updates only from C07.

1. Write each checkpoint beside the worker identifier and the common round number.
2. Apply the checkpoint requirement before averaging any values. Record the decision for each worker.

**Check your result.** Worker A passes the checkpoint check. Worker B is set aside with a checkpoint mismatch, leaving one candidate for the next check.
