# Find the first index beyond a slice

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A D worksheet has a read-only slice containing 6, 12 and 18. A request asks for index 3.

1. Read the slice length and list the valid zero-based indices.
2. Check the requested index against the length before attempting to read the value.

**Check your result.** The valid indices are zero through two. The request for index 3 is rejected by the check and no value is returned.
