# Find the unchanged part of a data register

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A handwritten 68000 trace starts D0 at hexadecimal 12345678. A byte move puts hexadecimal AB into D0.

1. Mark the two hexadecimal digits that represent the low byte of D0.
2. Change only those digits for the byte move and copy the other six digits forward.

**Check your result.** The next value of D0 is hexadecimal 123456AB.
