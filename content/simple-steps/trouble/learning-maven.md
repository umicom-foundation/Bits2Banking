# Separate a JAR timestamp from test evidence

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice build log reports tests skipped, while target contains an earlier JAR.

1. Read the lifecycle and verification lesson. Give the JAR creation and the test execution their own entries in a practice record.
2. Open the separate mock verification log and match its current test summary to the artifact’s project and run.

**Check your result.** The first record shows an available artifact and no current test execution. The verification result belongs only to the matching test run.
