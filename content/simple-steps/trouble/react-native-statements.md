# Find why a display filter changed a value

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local view initially shows two posted rows with a total of 700 cents. Selecting Pending makes the total display zero.

1. Trace the data used to count visible rows and the data used to show the source report’s posted total.
2. Give the total its source snapshot value and apply the same filter again in the practice copy.

**Check your result.** The filter changes the displayed rows. The posted total still reads 700 cents.
