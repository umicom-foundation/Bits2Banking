# Give the form control a submitted name

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local practice form has a visible Duration label. The submitted field list does not contain the entered value 45.

1. In the form lesson, compare the label’s for attribute, the control’s id and its name. Write the role of each beside it.
2. Keep the label association and give the field the name duration. Submit only to the course’s local practice service or trace the field list on paper.

**Check your result.** The submitted list now contains duration with value 45. The visible label continues to identify the same input.
