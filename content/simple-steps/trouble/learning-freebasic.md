# Reject a number with extra text

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

An input line contains 12min. A loose conversion would take the leading digits and silently accept the rest.

1. In a scratch version of the text input exercise, check every character before converting a whole-number field.
2. Try the plain input 12 and then 12min. Record conversion and refusal separately.

**Check your result.** The plain input gives 12. The second input is refused as soon as the letter m is found and updates no stored duration.
