# Refuse an empty order quantity

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional order passes all the local fixture checks except quantity, which is zero. The fixture starts with three saved requests.

1. Apply the quantity check before asking the test store to keep the request.
2. Read the validation result and count the requests in the test store again.

**Check your result.** The result reports that quantity must be positive, and the saved request count stays at three.
