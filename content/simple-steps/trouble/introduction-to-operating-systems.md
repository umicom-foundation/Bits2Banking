# Find which terminal showed the startup line

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A simulator exercise provides a host terminal log and a separate guest console log. Only the guest console says Guest ready.

1. Label the host process output and the guest console output before interpreting either log.
2. Find Guest ready in the labelled output and record exactly where it was printed.

**Check your result.** Guest ready is credited to the guest console. The host log contains no matching line.
