# Stop a report when a required amount is missing

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A disposable receipt document contains an identifier and date. The amount field is absent.

1. Use the lesson’s field contract and identify each item present in the sample. Mark the missing amount before choosing a total.
2. Test or trace a copy with a valid zero amount. Compare how each record gets described.

**Check your result.** Only the second copy contains a valid amount of zero. The first has a missing-field result.
