# Find whether startup reached the native rule

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice log contains a report that the local native library path could not be opened.

1. Mark where the library is located, loaded and called in the course model. Match the observed diagnostic to that stage.
2. Compare with a local run using the documented valid library path and one known input.

**Check your result.** The first run stops at loading. The valid path allows the native rule to return its own result.
