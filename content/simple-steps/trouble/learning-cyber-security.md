# Keep a test password out of application logs

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local sign-in unit test uses a fictional password called TrainingOnly42. A diagnostic line currently includes the field value.

1. Change the diagnostic output to record the outcome and omit the supplied password.
2. Run the test capture and search it for the fictional password. Check that the diagnostic still records the outcome.

**Check your result.** The capture contains the sign-in outcome and has zero occurrences of TrainingOnly42.
