# Find a vocabulary mismatch

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A saved training trace says token 6 is `door`. The reader’s vocabulary says token 6 is `window`.

1. Put the two vocabulary identities and the displayed ID in one table. Find the first mismatched word.
2. Repeat decoding with the vocabulary from the trace. Record which version belongs beside the output in your notes.

**Check your result.** Token 6 decodes as `door` in the matching vocabulary. The other catalogue needs a separate result record.
