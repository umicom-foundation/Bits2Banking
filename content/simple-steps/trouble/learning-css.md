# Keep an unbroken identifier inside its card

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A long practice reference made of uninterrupted letters overflows a results card at a 320-pixel viewport.

1. Find which text element exceeds the card's width in browser developer tools.
2. Set `overflow-wrap: anywhere` on the reference field in the practice CSS and check the same viewport.

**Check your result.** The reference wraps inside the card and this card adds no horizontal scroll to the page.
