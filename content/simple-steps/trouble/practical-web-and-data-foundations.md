# Find an amount expressed in the wrong unit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The practice JSON has amount 350 cents. A spreadsheet reports 350 pounds for the same ID.

1. Write the source value and its unit. Trace the row transformation into the spreadsheet.
2. Convert cents to pounds only where the report expects pounds. Recheck the same ID in JSON and in the spreadsheet.

**Check your result.** 350 cents is £3.50. The source and displayed values now agree on the represented amount.
