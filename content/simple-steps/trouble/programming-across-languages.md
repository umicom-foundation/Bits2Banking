# Find a decision changed during translation

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A rule says to pass when a count is at least 10. One translated version uses a strictly greater comparison.

1. Trace 9, 10 and 11 through both versions before running them. Record precisely where they disagree.
2. Apply the inclusive condition to the translated version and check all three values again.

**Check your result.** Only the boundary input 10 disagrees initially. The corrected versions both accept 10 and 11.
