# Include the final lesson in a loop

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Your plan lists lessons 1 through 3, but a practice loop using lesson < 3 prints only two lines.

1. Trace the comparison for lesson values 1, 2 and 3. Circle the first false comparison.
2. Use lesson <= 3 in the copy and trace the next value after 3 as well.

**Check your result.** The revised loop prints Lesson 1, Lesson 2 and Lesson 3. When lesson is 4 the condition is false and it stops.
