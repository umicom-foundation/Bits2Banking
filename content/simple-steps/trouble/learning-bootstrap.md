# Restore the keyboard outline on an action

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Tabbing to the practice Continue button gives it keyboard focus, but a custom style hides the outline.

1. Use Tab and the browser inspector to confirm the button has focus. Locate the custom outline rule.
2. Disable that rule in the practice copy and tab to the button again.

**Check your result.** The focused Continue button now has a visible focus indicator, and its position in the tab order stays the same.
