# Choose a stable receipt identity

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two training receipts have IDs R7 and R8 and the same customer label. A practice correction applies only to R8.

1. Trace which records a filter on the shared label would select. Write the two IDs before attempting a change.
2. Choose R8 using the document identity rule in the course. Set its status to reviewed in a practice record.

**Check your result.** The label selects two records. Filtering by R8 selects one, and R7 retains its original status.
