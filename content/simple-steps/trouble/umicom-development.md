# Identify which package the local build selected

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A small installed-SDK practice project configures against a different Framework checkout than intended.

1. Read the configured package location and compare it to the desired installed prefix. Keep both paths in your notes.
2. Use a new practice build directory and explicitly choose the intended prefix using the full lesson’s command.

**Check your result.** The new configure output identifies the intended package. The old build evidence remains available.
