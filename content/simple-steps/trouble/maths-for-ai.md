# Find why two matrices cannot multiply

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice tensor transformation tries to multiply a 2-by-3 matrix by a 4-by-2 matrix.

1. Write the shapes beside the matrices. Compare the dimensions where multiplication joins them.
2. Use the course example that has three rows on the second operand and predict the output shape.

**Check your result.** The original inner dimensions 3 and 4 differ. With a 3-by-2 second operand the output shape is 2 by 2.
