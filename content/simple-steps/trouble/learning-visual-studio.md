# Check which binary the debugger launched

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A learner edited the greeting in a practice C program. The debug run still shows the earlier greeting and the displayed target path belongs to another configuration.

1. In the course’s build-and-debug route, compare the active configuration, the output path and the executable selected for the run.
2. Build the intended configuration and choose its executable in the practice project. Run the local program again.

**Check your result.** The selected path matches the current build output and the run shows the new greeting.
