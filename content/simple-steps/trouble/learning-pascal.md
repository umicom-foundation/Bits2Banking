# Fix a loop that omits the final record

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice array is indexed from 1 through 3 and contains 4, 6 and 9. A trace visits only indices 1 and 2.

1. Compare the declared bounds with the loop limits in the course’s repetition lesson. List the visited positions and intermediate sum.
2. Use the actual final index as the inclusive Pascal loop limit. Trace the new loop with the same array.

**Check your result.** The earlier result is 10. The corrected trace visits 1, 2 and 3 and totals 19.
