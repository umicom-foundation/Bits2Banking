# Find an extra iteration

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A checked loop intended to visit 0, 1 and 2 also visits 3.

1. Write the current comparison beside each visit. Find the line that admits the unwanted final value.
2. Use the course example to compare the inclusive and strict stopping conditions in a separate local program.

**Check your result.** A strict comparison against 3 permits exactly the three intended visits.
