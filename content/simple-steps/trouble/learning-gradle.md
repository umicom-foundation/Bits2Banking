# Tell an executed check from a reuse

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A supplied training log shows :test UP-TO-DATE. A review note says the tests executed again.

1. Find the task name and outcome in the lesson’s incremental-run example. Label UP-TO-DATE as reused task evidence.
2. Compare that log with a second practice trace where the test task executes with a current test report. Mark the report associated with that run.

**Check your result.** The first note records reuse. The second records execution only when the log and report identify the current run.
