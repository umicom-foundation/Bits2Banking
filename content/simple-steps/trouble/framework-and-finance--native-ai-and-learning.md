# Check which source supports an answer

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local answer says the practice library closes at 5 pm. The stored notice it cites has expired. The current notice says 6 pm.

1. Compare the dates on the two notices before checking the answer text.
2. Run the exercise again with the current notice as the only source and compare the answer with the closing time on that notice.

**Check your result.** The supported answer says 6 pm and points to the current notice. The earlier 5 pm answer is marked unsupported by the current notice.
