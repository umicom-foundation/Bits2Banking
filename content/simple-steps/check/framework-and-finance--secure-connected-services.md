# Check whether a finding is ready for review

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice change-review form requires a finding ID and a local evidence reference. Case A supplies F7 with worksheet row 3. Case B supplies F8 and leaves the evidence field empty.

1. Try to submit case A to the local review list and read the returned status.
2. Try case B with the same rule and record whether it enters the list.

**Check your result.** The list contains F7 with worksheet row 3. The second result asks for an evidence reference and no F8 entry appears.
