# Check which positions in a report are populated

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch Odin reporter has exactly three fixed output slots. Its validated input reports values 2 and 7 in one case, and supplies no values in another.

1. Adapt the C-call sample’s fixed array declaration to draw three slots and add a separate occupied count in the scratch design.
2. Trace how the two inputs set that count and bound presentation. Check both the number of displayed values and their order.

**Check your result.** The first trace displays 2 and 7 in order and shows two occupied entries. The empty trace shows zero occupied entries and displays no placeholder value.
