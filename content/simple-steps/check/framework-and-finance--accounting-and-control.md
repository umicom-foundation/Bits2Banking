# Check a report value with and without a source reference

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two fictional daily report rows both show a 70-unit receipt. One links to source R8 and its posted journal row J2. The other has a date and amount but no source or journal identity.

1. Build a two-case lineage check that looks for both links in Explain where a report's numbers came from.
2. Trace each row back to the original receipt and record where the path ends.

**Check your result.** The first follows the chain from the report to J2 to R8. The second stops at the report and is flagged for missing lineage.
