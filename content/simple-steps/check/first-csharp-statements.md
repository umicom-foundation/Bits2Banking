# Check the lower bound of the running sum

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two fictional fixtures give TryPostedTotal two posted rows. In both cases the first amount is int.MinValue. The second amount is zero in A and -1 in B.

1. Trace the checked addition and out total in each test. Match the number of amount values to the states array.
2. Write two calls to the course Check helper or describe their expected observations on paper.

**Check your result.** Case A returns true and total -2147483648. Case B returns false and total 0.
