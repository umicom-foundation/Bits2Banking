# Check a complete record and a bad unit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A source row for T9 declares 210 cents. A second copy represents the amount as the text `two pounds`.

1. Write the schema’s expected type and unit. Validate or trace both inputs before putting either amount into the table.
2. Check which input makes a displayable numeric row. Keep the invalid copy’s reason beside its identity.

**Check your result.** The first row displays 210 cents. The string fails the numeric amount check.
