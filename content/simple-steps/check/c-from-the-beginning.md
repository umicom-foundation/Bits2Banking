# Check a function that returns a refusal value

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice call to RemainingLessons uses total 0 and completed 0. A second call passes total -2 and completed 0.

1. Use Writing and calling a function to trace the parameter checks independently.
2. Record each returned integer and label it either a count or the refusal value.

**Check your result.** RemainingLessons(0, 0) returns the valid count 0. RemainingLessons(-2, 0) returns the refusal value -1.
