# Check a visible row count and stored posted total

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A snapshot has two posted rows for 150 and 250 cents, and one pending row for 20.

1. Render the default and pending filters using the same fixture. Record visible counts and posted totals in separate columns.
2. Compare whether the chosen visual filter changes the report’s posted amount.

**Check your result.** The default view has three visible rows, pending has one, and the accepted posted total stays 400 cents.
