# Check the two reasons a token sequence stops

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A paper generator has a limit of two visible tokens and treats END as a stop marker. The first fixture returns tea, END. The second returns coffee, now, please.

1. Trace the first sequence and stop when the END marker arrives. Record which token became visible.
2. Trace the second sequence using the same limit and record where it stops.

**Check your result.** The first result is tea with stop reason END. The second result is coffee now with stop reason limit.
