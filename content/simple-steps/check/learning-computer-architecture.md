# Check two memory sizes written in bits

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A small hardware worksheet records buffers of 16 bits and 40 bits. The comparison column asks for whole bytes.

1. Convert the first capacity by grouping its bits into sets of eight.
2. Use the same conversion for the second capacity and verify by multiplying the number of bytes by eight.

**Check your result.** The capacities are 2 bytes and 5 bytes. Multiplying those counts by eight gives 16 and 40 bits.
