# Check that reverse traversal handles one and many values

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two D practice arrays contain [4, 9, 2] and [7]. A teaching loop uses foreach_reverse to print all values, one per line.

1. Mark each array's last valid position and follow the loop towards index zero.
2. Record the exact output order for each case and count how many values are printed.

**Check your result.** The first prints 2, then 9, then 4. The second prints 7 once.
