# Check the known and default paths of a Go switch

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local console recipe supports the command count and reports an unknown-command message for other values.

1. Call the switch with count and have that case report the fixture count of 3.
2. Call the switch with lookup and record which branch runs.

**Check your result.** The first call prints Count 3. The second takes default and prints Unknown command.
