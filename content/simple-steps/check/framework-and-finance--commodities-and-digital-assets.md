# Check that a reference belongs to the selected ledger

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A toy deposit intake accepts canonical history only from selected network L1. Both supplied observations carry reference D6 and 15 units. One is from L1 and one from L2.

1. Check the network identity before comparing reference and amount. Trace both cases against the stated intake scope.
2. Write whether each record enters the pending review for L1 and whether either case grants spendable credit at this step.

**Check your result.** The L1 observation enters pending review for 15 units. L2 is outside the selected network. Both cases grant zero spendable credit at this step.
