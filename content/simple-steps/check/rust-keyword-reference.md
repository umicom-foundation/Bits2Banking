# Check two arms of the same result enum

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local practice function returns either a count or an error label.

1. Use one allowed input and one documented refused input. Write the arm and result type you expect for each.
2. Match both examples using the lesson’s typed branching form and compare which information is used.

**Check your result.** Only the admitted result arm exposes a count. The refused case retains its error label.
