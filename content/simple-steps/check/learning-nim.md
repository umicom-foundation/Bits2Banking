# Check that a signed refusal survives the language bridge

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch Nim report calls the existing C function using the course’s declaration. Choose inputs 41 and 1000.

1. Write the expected results in two named cases using cint for both arguments and results.
2. Compare each signed result independently and reject a fixture that represents refusal as a large positive number.

**Check your result.** Input 41 returns 42. Input 1000 returns -1 as a signed value.
