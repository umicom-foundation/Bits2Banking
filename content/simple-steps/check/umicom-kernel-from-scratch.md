# Check two file-only media observations

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

You computed a digest for one diagnostic ISO. One inspection report records that ISO’s digest. A second report gives a different digest.

1. Record the intended boot profile. Compare each recorded digest with the digest you computed for the ISO file.
2. Save both comparisons. Attach the matching report to the ISO and record the other as unresolved.

**Check your result.** Only one report identifies the bytes of the inspected ISO. Keep the second comparison open until its file and digest are reconciled.
