# Check a form against its shared document model

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice document form requires a title. One fixture has the title Weekly notes. The second fixture leaves the title empty.

1. Pass the first form through the shared model and record its resulting document title.
2. Run the second through the same model and inspect its result and document count.

**Check your result.** The first fixture yields a document named Weekly notes. The second yields a required-title message and creates no additional document.
