# Check native status against the Java facade

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use one accepted fictional receipt from the full SDK example and its known refusal fixture.

1. Record expected statuses by running or tracing the C reference for both. Copy the amounts and types into the Java example.
2. Compare both outcomes through the Java facade and check that you did not change units.

**Check your result.** Each case has the same status in Java and native C when it uses the same representation.
