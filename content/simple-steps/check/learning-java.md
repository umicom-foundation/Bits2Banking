# Check a runnable JAR from two working directories

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A scratch runnable JAR prints Ledger ready when started successfully. There is no input file in this exercise.

1. Use the runnable-JAR lesson to plan one launch from the JAR’s directory and one from its parent using the JAR’s explicit path.
2. For each case record the exact JAR path selected and the first line. Treat any walk into a different JAR as a failing fixture.

**Check your result.** Both cases select the same artifact and print Ledger ready.
