# Check a repeatable output format

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom Fortran program prints a count followed by the unit visits. A reader needs zero and a three-digit value to appear in the same report format.

1. Use the first-program lesson to prepare an explicit integer and text output for the two inputs 0 and 128. Trim padding from the resulting lines in the scratch check.
2. Compare both lines to the agreed wording. Verify that the integer before the unit has no decimal point or leading zeroes.

**Check your result.** The checked lines are 0 visits and 128 visits.
