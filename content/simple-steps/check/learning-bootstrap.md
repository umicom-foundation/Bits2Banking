# Check that two visually similar card titles have heading structure

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local catalogue has two practice card fixtures. One title uses an h2 with the card title class, and the other uses a div with that same class.

1. Inspect the first card's accessibility tree or document outline and record whether its title is a level-two heading.
2. Repeat the check for the second fixture and compare the semantic results.

**Check your result.** The h2 fixture exposes one level-two heading. The div fixture exposes no level-two heading.
