# Check that each attached handler keeps its own count

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local widget exercise creates one handler at count 0 and a second handler at count 3. Each adds one to its own count on a click.

1. Use the retained-state lesson to write a case sending a click only to the first handler. Record both counts before and after.
2. Reset both fixtures and write a second case sending a click only to the second handler.

**Check your result.** The first case ends with counts 1 and 3. The second ends with counts 0 and 4.
