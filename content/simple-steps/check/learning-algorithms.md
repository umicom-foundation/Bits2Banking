# Check insertion sort on its two smallest inputs

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A course sorting exercise accepts a list of integer keys. One fixture is empty and the other has the single value 11.

1. Trace insertion sort on the empty fixture and count how many items are moved.
2. Trace the single-value fixture and check the output list for any change.

**Check your result.** The empty fixture remains empty without a move. The single-value fixture remains a one-item list containing 11.
