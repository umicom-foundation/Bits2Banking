# Check whether a Java report supports discovery

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice Java test task is reported as executed. Report A lists the expected test case preservesIdentity. Report B says zero tests.

1. Write an acceptance check that requires both an executed task and evidence of the named case in the accompanying report.
2. Apply it to the two sample records while holding the task outcome fixed. Record whether case discovery is demonstrated.

**Check your result.** Report A supports discovery of preservesIdentity. Report B fails the check despite its executed task.
