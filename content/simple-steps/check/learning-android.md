# Check a button at the count limit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local Android fixture permits at most five servings. Its Add button is enabled below the limit and disabled when the count reaches five.

1. Start the fixture at four and activate Add once, then record the count and button state.
2. Start a fresh fixture at five and check whether the Add action can run.

**Check your result.** The first fixture reaches five and disables Add. The second remains at five with Add disabled.
