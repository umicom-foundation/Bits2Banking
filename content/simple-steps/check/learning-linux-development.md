# Check both streams and status for a local program

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training C executable writes Room ready and returns zero for a valid input 4. A negative input is refused with diagnostic Count must be nonnegative and exit status 3.

1. Design one case for each input in the process lesson’s three-column trace. Keep standard output, standard error, and exit status separate.
2. Compare the observed or drawn records with their expected values before declaring the workflow acceptable.

**Check your result.** Input 4 gives Room ready on standard output, no diagnostic, and status 0. Input -1 has empty standard output, the stated diagnostic, and status 3.
