# Check the last accepted value and the first refused value

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local conversion permits values through 20. Choose 20 and 21.

1. Write the desired numeric result for 20 and the named error for 21 before editing the tests.
2. Use the full lesson’s error-aware call for both cases and compare the branches and written results.

**Check your result.** 20 reaches the accepted calculation. 21 uses the named error without an accepted replacement result.
