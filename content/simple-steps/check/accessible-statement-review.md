# Accept both a working filter and its readable fallback

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A reviewer needs two checks for the course statement with all three original rows. One run loads the script and one run uses a scratch copy with the script block omitted.

1. With the full page select Show only posted rows using Space. Write down the visible references, status and focus position.
2. Open the scratch copy and inspect the same three observations without trying to activate its disabled control.

**Check your result.** The scripted view keeps focus on the selected checkbox, shows 101 and 102, and says 2 rows shown. The fallback shows 101, 102 and 103, says 3 rows shown and leaves the checkbox disabled.
