# Check two signed branches including zero

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A checked-integer source example must return 1 for a negative value and 0 otherwise.

1. Write tests for −1 and 0. Use a supported condition form and record both expected outputs before running.
2. Use the course’s interpreter or compiled example for the same inputs and compare the results.

**Check your result.** The negative case returns 1 and zero returns 0.
