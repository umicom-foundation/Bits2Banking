# Check two visitors under the same rule

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A person may enter a synthetic workshop only if the booking is confirmed and room is available.

1. Use a case with both inputs true, then one with only booking confirmed. Write the expected action for each.
2. Translate the expression into two supported languages and check the same input table.

**Check your result.** Both implementations accept the first case and refuse the second for this rule.
