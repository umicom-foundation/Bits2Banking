# Check two branches of a file checklist

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A meeting checklist says to mark an existing local agenda as ready and otherwise mark request agenda. One paper folder listing contains agenda.txt, and a second lists only notes.txt.

1. Write the exact filename the instruction should look for and the two outcomes of its choice.
2. Trace each printed folder listing once, then record the status and any changed filenames.

**Check your result.** The first listing gives ready. The second gives request agenda. Both lists of filenames stay as they were.
