# Check an array lookup when an item is present or missing

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice list contains Filter, Kettle and Cup in that order. Write a function that reports a zero-based position when it finds an exact match.

1. Ask the function to find Kettle and check the reported position.
2. Ask it to find Tray and record the explicit missing result.

**Check your result.** Kettle is found at index 1. Tray is reported as missing.
