# Check two requests with different fields

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A mock active consent includes a masked name and currency. Case one asks only for currency. Case two asks for an unrelated field.

1. Mark every field against the consent’s allowed list. Predict what each request can receive.
2. Apply the lesson’s local consent check or paper trace and keep the two results separate.

**Check your result.** The currency request meets the field check. The unrelated field does not belong to the permitted projection.
