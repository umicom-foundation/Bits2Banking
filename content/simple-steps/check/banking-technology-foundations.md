# Check a repeat with and without changed terms

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two local retries use accepted reference P20. The original instruction names account R6 and 450 USD cents. One retry matches it exactly, and the other asks for 460 cents.

1. Use Keep a payment retry from changing the balance twice to trace reference lookup and normalized field comparison.
2. Write the outcome of each retry and how many new postings the two retries together create.

**Check your result.** The first retry returns the recorded result. The changed amount reports a conflict. Both retries together create zero new postings.
