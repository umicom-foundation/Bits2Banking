# Check a bounded list handler on both sides of the limit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local fixture accepts at most two task names. Its input form passes a list to PHP.

1. Following the bounded-list lesson, prepare one request with Elm and Ash and another request adding Cedar as the third item.
2. Check the count before writing a result. Record whether anything is accepted when the list is too long.

**Check your result.** The two-item input yields Elm and Ash. The three-item input yields Too many tasks and adds no accepted list.
