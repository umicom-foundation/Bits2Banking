# Check two literal titles in the same view

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Supply the two practice titles `Open hall` and `Music & talks` to a local template.

1. Write the exact visible headings before rendering each input. Check the second heading preserves the ampersand as text.
2. Inspect the result after both inputs. Keep the edited title separate from the page structure check.

**Check your result.** The headings display `Open hall` and `Music & talks`. The same title element remains in place for each result.
