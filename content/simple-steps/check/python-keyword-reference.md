# Check a default and a specific choice

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A tiny report function labels numeric zero as `empty` and other permitted values as `ready`.

1. Use the lesson’s branch and return expressions to predict the labels for inputs 0 and 2.
2. Run or trace the function with those values and write the returned labels exactly.

**Check your result.** The function returns `empty` for 0 and `ready` for 2.
