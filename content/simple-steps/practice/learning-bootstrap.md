# Check the order in a narrow layout

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A page has a search control, a result heading and a two-column list.

1. Open the course’s responsive example at a normal width. Record the order you get when stepping through controls with Tab.
2. Open its narrow view. Check that the search still comes before the results in the usable page order.

**Check your result.** The narrow view changes layout and keeps the task order available to a keyboard user.
