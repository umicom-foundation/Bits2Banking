# Check a single edit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Your document contains `receipt`. You insert the letter s at the end.

1. Number the cursor positions from zero. Mark position 7 at the end of the existing text.
2. Write the result of the insert and the new cursor position. Apply undo and compare the restored bytes.

**Check your result.** The new text is `receipts`, with the cursor after its eighth byte. Undo restores `receipt`.
