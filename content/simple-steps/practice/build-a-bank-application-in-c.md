# Give each practice transfer an identity

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Start from a fictional account balance of 2,000 cents. Apply an outgoing transfer of 350 cents with the ID T-14.

1. Use the course’s transfer exercise to record the input, initial balance and resulting balance.
2. Try the same ID a second time in your notes. State the handling rule before looking at the final balance.

**Check your result.** A single accepted transfer leaves 1,650 cents. A repeat of T-14 should follow the application’s duplicate-handling path without posting another movement.
