# Convert a timed shift entry

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A venue caretaker needs 7 minutes to complete a checklist. The log stores seconds.

1. Write a C statement that stores 7 in a named integer and multiplies it by 60. Use the output pattern from the course.
2. Change the minutes to 9, build again and check the second output.

**Check your result.** The first run prints 420 seconds. The second prints 540 seconds.
