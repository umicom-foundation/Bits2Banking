# Read a small input and its result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice register trace begins with input values 6 and 9.

1. Use the lesson’s addition routine to identify input registers and record the result.
2. Repeat with the values in the opposite order. Keep the expected destination visible in your trace.

**Check your result.** Both traces yield 15. The routine writes its result to the destination described in the full lesson.
