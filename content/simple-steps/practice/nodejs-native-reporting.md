# Compare an input snapshot and its local display

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local native report supplies a currency, amount and status.

1. Write down the values and types required by the adapter in the course. Pass one approved local sample through the adapter.
2. Refer to the course’s refusal case. Check what the display should retain if the next sample has a missing amount.

**Check your result.** The accepted sample displays its values. The refused replacement leaves the established report visible.
