# Check an accepted and refused value

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the course’s small error-aware function with one valid practice input and one outside its documented range.

1. Record the return type and choose one example value for each outcome.
2. Run or trace both paths and write a separate expected output for each.

**Check your result.** The valid case produces a result. The refused case retains its explicit error outcome.
