# Follow an instruction across two reports

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional payment P8 has a received report and a later settlement observation.

1. Record each report type and the payment ID. Compare the status implied by the first one before examining the second.
2. Write the rule that permits settlement to appear only after evidence linked to the same ID is present.

**Check your result.** Receipt appears first. Settlement becomes known after the matching second report is received and checked.
