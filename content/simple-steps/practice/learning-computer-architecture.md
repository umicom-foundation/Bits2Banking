# Trace a value between memory and a register

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A sample memory location holds the value 42.

1. Draw the memory location and a register. Label the load direction and move the number on paper.
2. Now put 99 in the register. Trace a store in the opposite direction and identify the changed location.

**Check your result.** Load puts 42 in the register. Store writes the selected register value 99 into the memory location.
