# Compare two stored names in a scope

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The practice example has a value of 3 in an outer scope.

1. Declare a practice value of 8 under the same name inside the lesson’s inner-block layout.
2. Write which value is read inside and immediately after the inner block. Check both against a run if your tools are ready.

**Check your result.** The inner read uses 8. The read after the inner block uses the outer value 3.
