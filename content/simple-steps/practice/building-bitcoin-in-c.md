# Check the classroom validation order

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local teaching block has a parent reference, a payload and a value to test against the exercise’s rule.

1. Use the course fixture to list those three fields in the order they are checked.
2. Change only the parent reference in a local practice copy. Trace the point where the classroom validator refuses it.

**Check your result.** The changed copy is refused on its parent reference and does not become the latest accepted record.
