# Check a loop that skips a zero

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the practice list `[2, 0, 4]`.

1. Write a loop trace using the course’s skip example. Mark where the zero is skipped.
2. Add the other values and compare the result with a local run.

**Check your result.** The loop visits three entries and adds 2 and 4, giving 6.
