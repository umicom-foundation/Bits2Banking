# Check which environment owns a tool

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

You have a disposable practice environment and the normal terminal environment.

1. Use the course’s location check before and after activating the practice environment. Record the two results.
2. Run the version check in both environments. Close the practice environment and check the location one more time.

**Check your result.** The active environment owns the selected executable during the exercise. The normal location returns after leaving it.
