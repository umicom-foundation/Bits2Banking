# Find where the debugger stopped

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use a local practice program with one line assigning a value and a following output line.

1. Set a breakpoint on the assignment in the course’s debugger. Start the local run.
2. Inspect the variable, execute that line and inspect it again before allowing the output.

**Check your result.** The watch view changes after executing the assignment. The output matches the value you observed.
