# Draw a selector truth table

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use a two-input selector with A low and B high.

1. Apply the lesson’s selector rule with control low. Record which input appears on the output.
2. Apply it again with control high. Compare the two entries with the local simulation testbench.

**Check your result.** With the example’s A-at-low convention, output changes from low to high as control changes from low to high.
