# Find where one build result appears

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the course’s small Maven example with its documented JDK.

1. Run the project’s test command. Find the test output and identify one case named by the report.
2. Open the project descriptor and write which project supplies that test. Add the command and result to a short check record.

**Check your result.** The log and report refer to the same project and test case.
