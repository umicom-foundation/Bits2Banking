# Show a title as visible text

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the legacy local template exercise and its sample title field.

1. Set the title to `Sales <July>` in a practice copy, then identify the place that handles plain text for HTML display.
2. Compare the text in the browser with the value supplied by the data model.

**Check your result.** The browser displays the title’s angle brackets as text, and the heading keeps its original structure.
