# Find a value in an ordered list

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The sorted list is 2, 5, 7, 9, 12. Find 9 using the midpoint method.

1. Start with the entire range. Read its midpoint and keep the range that could contain 9.
2. Repeat with the new range and write down each inspected value.

**Check your result.** One valid midpoint trace compares 7 then 9. The final position is the fourth entry.
