# Repair the structure of a short document

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Write a practice report with one opening report tag and one entry child.

1. Close the entry before closing the report. Compare the result with the nesting example from the lesson.
2. Swap the two closing tags in a copy. Trace which open element the parser is waiting to close.

**Check your result.** The first document is nested correctly. The changed copy has the closing tags in the wrong order.
