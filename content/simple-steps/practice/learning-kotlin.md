# Give an optional value a safe display

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice form contains one record with a name and one where the name is absent.

1. Use the lesson’s nullable representation. Write the result you expect for each record.
2. Try the example’s default display path, then change the missing name to `Meeting room` in your practice copy.

**Check your result.** The absent name uses the chosen default. The named record displays `Meeting room` after the edit.
