# Connect a button to one result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The practice window has one button and a status label.

1. Find the callback connection in the example. Run it locally using the documented setup and click once.
2. Compare the label with the text set by the callback. Close the window and record whether the event you checked occurred before shutdown.

**Check your result.** The click changes the label to the callback’s text. Closing the window ends the practice run.
