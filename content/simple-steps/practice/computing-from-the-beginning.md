# Follow one scanned entry

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A venue uses a scanner to enter the code A17 and show it on a screen.

1. Write the scanner, the program and the display across one row. Put A17 under the part that supplies it.
2. Sketch how the program could save the same code in a file. Add that destination to the diagram.

**Check your result.** The scanner is the source of input. The display and saved file are separate destinations.
