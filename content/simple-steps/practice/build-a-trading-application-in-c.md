# Check a partial fill

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A paper buy order asks for 10 units. Two execution reports fill 3 and 4 units.

1. Write each report on its own line. Apply them in arrival order and keep a running filled total.
2. Calculate the remaining quantity. Add a third report for the exact remainder and check the order status.

**Check your result.** The first two reports fill 7 units and leave 3. The final 3-unit report completes the order.
