# Follow a queue with a fixed limit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice queue has room for two records. Insert A, then B, then try C.

1. Record the state after each insertion. Check the queue’s full behavior before taking an item out.
2. Remove the first record. Insert C again and write the resulting order.

**Check your result.** The third insertion first meets a full queue. After removing A and inserting C, the order is B then C.
