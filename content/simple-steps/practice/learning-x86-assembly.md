# Check a carry with a small addition

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use an 8-bit classroom example that adds 250 and 10.

1. Write the full decimal result. Find the byte that remains after reducing modulo 256.
2. Trace the same operands through the lesson’s addition example and record the carry separately.

**Check your result.** The full result is 260. The low byte is 4 and the unsigned carry is set.
