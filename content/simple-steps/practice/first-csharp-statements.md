# Count a filtered set of records

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Three practice receipts have states Ready, Pending and Ready.

1. Copy the three rows into the source exercise’s record format. Filter to Ready and count the results.
2. Change one Ready state to Pending and rerun the same filter. Keep the ID with each result.

**Check your result.** The first run returns two records. The changed copy returns one, and its original ID remains visible.
