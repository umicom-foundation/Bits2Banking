# Follow a field to its reader

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local fixture contains one short transaction record and a function that reads it.

1. Find the field definition and the point where its bytes enter the reader. Write down the order of the first two reads.
2. Mark one size or range check you can see in the reader. Use a paper trace to explain when the field becomes usable.

**Check your result.** The notes identify a source definition, a reader and the validation boundary instead of assuming that parsing is complete at the first byte.
