# Check what a component receives

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local example component needs a heading and a list with four entries.

1. Pass the heading and list as props in the course’s example. Sketch what the component should render.
2. Remove one entry in the owning state and compare the component’s next result with the prior display.

**Check your result.** The list changes from four entries to three when the parent supplies the new data.
