# Trace the conditional branch

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A loop uses a count of 3, 2, 1 and then 0.

1. Draw one row per count. Use the course’s branch pattern to decide whether to repeat or stop.
2. Count the repeated actions and mark the first visit that exits the loop.

**Check your result.** The loop performs three actions, then stops on the zero count.
