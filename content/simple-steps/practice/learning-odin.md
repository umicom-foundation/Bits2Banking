# Follow a fixed-size array

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice array has three readings, 2, 4 and 8.

1. Use the course’s array example to list each index and value.
2. Check the permitted index range before selecting the last entry. Record the result of adding all three values.

**Check your result.** The permitted indices are 0, 1 and 2. The last value is 8 and the sum is 14.
