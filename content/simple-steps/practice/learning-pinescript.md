# Compare a toy series over a fixed window

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom series has three values, 4, 5 and 9. Use a two-value moving window.

1. Write the first window containing 4 and 5 and calculate its mean.
2. Advance the window one place. Compare the result with the same values in the lesson’s moving-average example.

**Check your result.** The two completed windows yield 4.5 and 7. This is an arithmetic exercise for synthetic values.
