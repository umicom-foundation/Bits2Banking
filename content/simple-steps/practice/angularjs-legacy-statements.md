# Trace a filter through an old screen

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A statement model contains two posted entries and one pending entry.

1. Find the model and template binding in the course’s example. Write the initial number of displayed rows.
2. Follow the pending filter from the input control to the displayed list. Count the rows in the underlying model again.

**Check your result.** The pending filter shows one row. The original model still has three entries.
