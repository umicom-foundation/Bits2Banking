# Name the output of each build stage

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

You have a practice C source, an object file and a linked system component.

1. Write the file name produced by compiling, then the file name produced by linking.
2. For one stage, record a result that shows it succeeded before using its output in the next stage.

**Check your result.** The compile stage produces an object. The link stage consumes objects and produces the linked component.
