# Use a decision at a boundary

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice entrance rule permits an age of at least 18. The inputs are 17, 18 and 19.

1. Read the course example for `if`. Put each input into the same comparison and predict its branch.
2. Change the condition to greater than 18 in a practice copy. Check which prediction changes.

**Check your result.** With at least 18, 18 and 19 pass. With greater than 18, only 19 passes.
