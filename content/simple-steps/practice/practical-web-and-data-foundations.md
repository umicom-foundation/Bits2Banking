# Follow a record through three formats

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional posted row has ID B12 and an amount of 365 cents.

1. Write it in the lesson’s JSON shape and identify the ID, state and signed amount fields.
2. Use the lesson’s table and spreadsheet exercises to show the same row. Compare the amount in all three formats.

**Check your result.** B12, posted and 365 cents agree in each representation.
