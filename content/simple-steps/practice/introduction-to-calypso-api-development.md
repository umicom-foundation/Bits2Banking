# Keep source and displayed fields aligned

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A synthetic trade record contains ID D5, currency EUR and amount 900.

1. Use the course’s local example to map the three input fields to the three displayed fields.
2. Change only the currency in your local example and identify where a displayed discrepancy should appear.

**Check your result.** The ID and amount remain recognizable. The currency change is visible in its own field.
