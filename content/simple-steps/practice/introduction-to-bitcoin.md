# Trace one shared-record change

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two classroom copies have the same history through record 8. A new entry appears in one copy only.

1. Mark the latest shared position and the new entry. Keep the source of each observation visible.
2. Write what evidence each participant needs before treating the new entry as part of its own verified copy.

**Check your result.** Record 8 remains the last shared position. The new entry is pending review in the second copy.
