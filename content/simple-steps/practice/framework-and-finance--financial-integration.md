# Reproduce a disputed transfer

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One practice system reports amount 2,500 cents for ID T8. A second system reports 2,050 cents for the same ID.

1. Write the source and value for each observation on separate lines. Check that the units match before comparing amounts.
2. Calculate the difference and attach both observations to the practice evidence record.

**Check your result.** There is a 450-cent difference. Both source values remain visible and the mismatch can be checked again.
