# Count only completed entries

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice table has three rows. Their states are Complete, Pending and Complete.

1. Use the course’s `WHERE` pattern to select Complete and count the result.
2. Change the pending row to Complete in a disposable copy and repeat the same query.

**Check your result.** The count is 2 in the original and 3 after the practice state change.
