# Check the result of a shared status call

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A small C project returns one of two Framework statuses after a local operation.

1. Find the public header and the local example’s output line. Record the expected message for success.
2. Trace a known refusal in the same contract and record the status message separately.

**Check your result.** The two inputs produce distinct status lines from the shared status function.
