# Track a delayed report

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice service emits report R21 and the recipient receives R20 a second time.

1. Draw a two-row table for sent and received identities. Mark the record expected next.
2. Route the repeated R20 to the duplicate check. Write what must arrive before you can apply R21.

**Check your result.** The duplicate R20 leaves the current record unchanged. R21 requires its own arrival and validation.
