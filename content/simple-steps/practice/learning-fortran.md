# Total three recorded readings

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the numeric readings 2, 6 and 8 in the course’s small program.

1. Follow its array example to store the values in order. Write the running sum after each entry.
2. Calculate the mean using real division and compare it with integer division on the same operands.

**Check your result.** The sum is 16. The real mean is about 5.33. Integer division gives 5.
