# Tell a draft from a saved file

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local practice file contains `total = 17`. An editor draft contains `total = 19`.

1. Open the saved file from a second view before saving. Write down what each view shows.
2. Save the editor draft, then open the stored file again from the second view.

**Check your result.** Before saving, the stored value is 17 and the draft is 19. After saving, the stored file shows 19.
