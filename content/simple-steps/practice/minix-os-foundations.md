# Follow one local request to completion

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A classroom guest process requests a file read from its service.

1. Draw one box for the process and one for the server. Add an arrow for the request and a separate arrow for its reply.
2. Mark the point at which the process can use the returned result. Compare your trace with the course’s IPC exercise.

**Check your result.** The caller can match the result to its request when the reply is received.
