# Find a control total mismatch

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictional report expects debits of 2,000 cents and credits of 2,000 cents. The first export shows credits of 1,800 cents.

1. Write the debit and credit totals side by side. Calculate the difference and preserve the original report observation.
2. Sketch which report checks should run before a new export can take the place of the earlier version.

**Check your result.** The first report is short by 200 cents on credits. The discrepancy is recorded before a replacement is accepted.
