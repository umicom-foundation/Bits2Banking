# Compare a result across two callers

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two practice callers pass the same signed value to one C boundary.

1. Write the function’s argument, output and return status from the course header. Use one allowed practice value in both callers.
2. Try a documented refusal condition in both caller examples. Compare the state and outputs separately.

**Check your result.** Both callers agree for an allowed value and preserve the C boundary’s distinction between an accepted result and a refusal.
