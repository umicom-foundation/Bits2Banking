# Count items in a managed collection

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A small practice vector contains values 12 and 18.

1. Use the course example to add one value, 20. Read the result of the size operation.
2. Remove the last value using the collection operation shown in the full lesson. Read the size again.

**Check your result.** The sizes are 3 after adding and 2 after removing the last element.
