# Tell register and memory values apart

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice register contains 6. A selected memory location contains 12.

1. Use the course’s move syntax to trace memory into the register. Keep a row for each location.
2. Repeat with the opposite direction using new source values. Write which location actually changes.

**Check your result.** Memory-to-register copies 12 into the register and leaves the selected memory value at 12.
