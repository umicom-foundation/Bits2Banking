# Check two local request records

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two fictional AI requests share one input, but use different context limits.

1. Write the model identity, input identifier and selected limit for each request. Mark the settings that differ.
2. Find the result each caller may keep if the shorter context is rejected by the practice contract.

**Check your result.** The traces identify the differing limit. A rejected request has a refusal record and does not replace an accepted result.
