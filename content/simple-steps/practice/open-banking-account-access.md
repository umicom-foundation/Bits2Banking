# Check one fictional consent

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training consent allows a masked account name and currency for a read request.

1. Write the allowed fields and the requested fields next to each other. Check both names before permitting any data to be read.
2. Add a field outside the exercise’s scope to a second request. Compare its outcome with the original.

**Check your result.** The two allowed fields match the first request. The expanded request needs refusal or a narrower projection according to the course contract.
