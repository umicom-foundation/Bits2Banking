# Trace one local input field

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A fictitious form sends the value `Cold brew` in a name field.

1. Locate the local route and field-reading code in the course’s exercise. Write the field name and expected value.
2. Repeat with an empty value in the local fixture and note what should happen before a result is saved.

**Check your result.** The first trace carries `Cold brew`. The missing name uses the form’s local validation path.
