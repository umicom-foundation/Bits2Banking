# Group readings in a loop

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice list contains 10, 5 and 25 minutes.

1. Use the course’s loop example to add the values. Print the accumulated total after each addition.
2. Change the middle reading from 5 to 15 and rerun the check.

**Check your result.** The original intermediate values are 10, 15 and 40. The altered list totals 50 minutes.
