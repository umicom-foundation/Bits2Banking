# Check a clean C run after an edit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A recipe uses 5 minutes. Its helper should display the time in seconds.

1. Open the [coffee program and its compile command](../c.md). Set the minutes to 5 in your practice file, build, then run.
2. Set the minutes to 2, save, build again and check the next run’s output.

**Check your result.** The program prints 300 seconds, then 120 seconds after the successful rebuild.
