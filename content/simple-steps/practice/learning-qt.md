# Inspect an update from a signal

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local sample window connects a control to a change in a display label.

1. Find the signal and receiving function. Write down the expected display value before interacting.
2. Invoke the control once in the configured local example. Compare the resulting label with the receiving function.

**Check your result.** The connected function accounts for the displayed result after the control activates.
