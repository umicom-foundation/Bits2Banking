# Compare two argument registers

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A handwritten trace starts with 7 in the first input register and 8 in the second.

1. Use the lesson’s addition example to identify the registers that provide each value and take the result.
2. Swap the input values and repeat your trace. Check that the result still belongs to the specified destination.

**Check your result.** The result is 15 in both traces. The input positions change while the result register stays the same.
