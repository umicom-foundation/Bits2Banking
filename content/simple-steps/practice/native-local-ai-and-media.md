# Check the request budget before generation

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One toy local request needs 80 context units and the selected local provider has a budget of 64.

1. Write the requested and supported amounts next to the existing provider-selection example.
2. Choose a smaller practice request of 48 and trace the capacity check again. Keep the provider identity the same.

**Check your result.** The first request exceeds the available budget. The smaller request fits this particular check.
