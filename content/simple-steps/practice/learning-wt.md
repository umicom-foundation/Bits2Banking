# Map a button to a request result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local course example has a button and the status text `Waiting`.

1. Identify the callback that handles the interaction. Mark the route from the control to the displayed status.
2. Use the documented local example to invoke the button and compare the resulting text with the callback.

**Check your result.** The status text after the action is controlled by the supplied callback.
