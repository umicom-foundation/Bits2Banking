# Check a service plan before launch

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice plan has `display` depend on `storage`.

1. Trace the dependency exercise in the existing hosted parser. Record the expected service order on paper.
2. In a second practice copy, remove the storage declaration and leave display requiring it. Trace the check before any launch.

**Check your result.** The valid plan puts storage before display. The copy stops at the plan check because storage is missing.
