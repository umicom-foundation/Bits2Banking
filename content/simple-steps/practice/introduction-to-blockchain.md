# Read three linked receipts

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training record links to the immediately earlier entry. There are three entries in the example.

1. Write the identifier of each entry and copy it to the next row’s previous-reference column.
2. Swap in a different identifier for the second row in a new copy and check the third row again.

**Check your result.** The original three links agree. The third row’s reference no longer matches the changed second row.
