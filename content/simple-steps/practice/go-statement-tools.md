# Keep pending rows out of a posted check

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A training CSV has posted amounts of 750 and −125 cents and one pending amount of 900 cents.

1. Use the supplied statement format. Write down the expected posted total before running the example.
2. Change the pending state to posted in a new copy and repeat the check against that copy.

**Check your result.** The original total is 625 cents. The changed fixture totals 1,525 cents.
