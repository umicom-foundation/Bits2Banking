# Tell two local routes apart

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The course’s loopback server has one known page and a route that has no handler.

1. Use the course’s local fixture to request the known page. Record the status and the first useful body line.
2. Request the missing training route and record its status separately. Compare both results against the course example.

**Check your result.** The known page reports success. The missing route is reported separately and has its own expected status.
