# Follow one dependency to a service

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local course example calls a small service supplied to a Java component.

1. Draw the caller and provider. Identify which line in the example wires the dependency.
2. Use the supplied test configuration and predict which service provides the result. Compare with one successful local test outcome.

**Check your result.** The test supplies a known provider and can identify which implementation returned the result.
