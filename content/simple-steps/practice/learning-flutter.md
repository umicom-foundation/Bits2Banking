# Check a local counter after a rebuild

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The course’s sample has a count of zero and one button that adds one.

1. Run the local example using the course’s setup. Press the button twice and write down the visible number.
2. Find the expression that reads the count when the view rebuilds. Predict the value after one more press and check it.

**Check your result.** The screen shows 2 after two presses and 3 after the third.
