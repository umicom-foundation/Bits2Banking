# Tell an absent field from a zero

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two fictional receipt documents have the same ID shape. One has an adjustment of zero and one omits this field.

1. Write both documents in the notation shown by the course. Run or trace the field check with both inputs.
2. Record the query outcome and whether a value exists. Keep the amount column for values that are present.

**Check your result.** A present zero has a value of zero. The document without the field has no adjustment value to display.
