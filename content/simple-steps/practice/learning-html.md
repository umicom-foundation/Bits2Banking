# Check heading order and accessible labels

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Make a local practice page for venue hours with a title, two sections and one search field.

1. Use the course’s markup example to write a single page heading and two section headings. Give the search field a visible label.
2. Open the resulting file in a browser and use Tab to reach the search field. Compare the headings with the document outline you wrote.

**Check your result.** The page has one top-level heading, two subheadings and a search field whose purpose is visible.
