# Check the name of a class and file

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Create a practice Java class named `Report` with one output line.

1. Save it as `Report.java`. Run the course’s source-file or compile-and-run command for the installed Java version.
2. Change only the output value and repeat. Keep the public class name and filename unchanged.

**Check your result.** Both runs start at the same class. Only the line printed by the program changes.
