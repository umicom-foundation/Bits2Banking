# Keep a trusted previous result

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

The practice statement’s last accepted total is 780 cents. A new row has an invalid amount.

1. Put the prior total and invalid row in separate boxes. Trace the row validation before using it in a total.
2. Fix that row to a posted amount of 220 cents in a separate copy. Calculate the sum if the corrected row is accepted.

**Check your result.** The refused change leaves 780 cents. The corrected posted addition gives 1,000 cents.
