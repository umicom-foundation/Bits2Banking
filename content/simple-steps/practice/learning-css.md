# Check that text remains readable at two sizes

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use a heading, one filter and one results box from the course practice page.

1. Open the page wide and write down which elements fit side by side.
2. Narrow the display and inspect the same controls. Check how the typed labels and focus indicator remain visible.

**Check your result.** The layout can move elements onto separate lines while retaining the labels and keyboard focus indication.
