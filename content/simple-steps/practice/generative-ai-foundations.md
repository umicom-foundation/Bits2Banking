# Compare a tiny denoising trace

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A toy pixel value starts at 12. Two supplied correction steps add −3 and −2.

1. Write the starting value and apply the correction steps in order.
2. Compare the intermediate values with a second run using the same corrections. Label this trace as a small example.

**Check your result.** Both traces read 12, 9 and 7. The intermediate steps provide the expected evidence for this exercise.
