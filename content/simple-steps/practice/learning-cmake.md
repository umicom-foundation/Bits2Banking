# Tell configuration from compilation

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the course’s small CMake program and a fresh private build folder.

1. Configure into that folder. Write down where the generated build files appear.
2. Build the program and run its named check. Find which project line supplied the name of the check.

**Check your result.** The configuration generates build rules. The build creates the executable. CTest shows the registered check and its result.
