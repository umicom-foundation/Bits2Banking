# Separate a counter result from its view

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the local training counter with a starting value of zero.

1. Run the course’s sample in its documented emulator. Press the counter button three times and record the visible value after each press.
2. Return to the course’s code and identify which value owns the count and which line displays it.

**Check your result.** The values are 1, 2 and 3. The display depends on the stored counter value.
