# Check what a read-only command reports

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice directory has `notes.txt` and `report.txt`.

1. Use the existing lesson’s listing and read commands on that practice directory. Record both file names and the first line of the notes.
2. Run the read command with a deliberately missing practice name and observe its diagnostic before returning to the current file.

**Check your result.** Listing and reading the two valid files succeed. The missing path is reported as a separate error.
