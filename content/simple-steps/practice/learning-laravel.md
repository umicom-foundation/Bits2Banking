# Follow one value from a route to a view

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local practice route supplies the title `Room bookings`.

1. Point to the route, the value passed by the controller and the place the template displays it.
2. In the course’s local project, change only the title to `Venue bookings` and refresh the practice page.

**Check your result.** The same route renders the changed title. The presentation is updated from the supplied value.
