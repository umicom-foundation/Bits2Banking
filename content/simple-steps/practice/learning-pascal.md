# Compare two results in a small program

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice program needs to convert seconds to whole minutes. Use 180 seconds first.

1. Use the course’s assignment and integer division examples to calculate the result.
2. Repeat with 185 seconds. Write the leftover seconds separately using the remainder idea from the exercise.

**Check your result.** Both inputs give three whole minutes. The remaining seconds are 0 and 5.
