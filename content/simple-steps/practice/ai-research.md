# Keep a small experiment record

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two local timing runs use the same file. The first reads 128 rows and the second reads 126.

1. Write the input name, program revision, settings and observed count for each run.
2. Add a third row for a rerun using the two original settings. Record which result would reproduce each run.

**Check your result.** The original observations stay separate. A difference of two rows remains open until you compare the read conditions.
