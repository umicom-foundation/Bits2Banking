# Keep the boot transcript with the image identity

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the course’s disposable emulator run and record the input-image digest it actually loads.

1. Start the guest using the existing lab instructions. Write down the earliest boot marker you see.
2. Look at the reported final marker and preserve it beside the digest. Keep the result for this boot mode only.

**Check your result.** Your record names one image, one emulator run and the final marker seen in that run.
