# Read the source-location markers

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use two test lines in the existing D source-location example.

1. Write the file name and line number you expect for each marker before running it.
2. Add one blank line above the second marker, recompile and compare the locations again.

**Check your result.** The marker after the new line moves down by one line. The earlier marker’s location stays the same.
