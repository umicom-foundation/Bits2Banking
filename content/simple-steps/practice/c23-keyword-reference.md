# Name and check a constant

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice form allows up to four items on a receipt.

1. Use the course declaration example to give the limit a name and the value 4. Compare requested counts of 3, 4 and 5.
2. Write which cases meet an inclusive limit and repeat with the named limit changed to 5.

**Check your result.** At a limit of 4, the first two counts fit. At a limit of 5, all three fit.
