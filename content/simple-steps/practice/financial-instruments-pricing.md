# Check the unit in a discount calculation

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A made-up practice cash flow pays £105 in one year. Use a classroom rate of 5 percent.

1. Write the rate as 0.05. Divide the promised payment by 1.05.
2. Multiply your result by 1.05 to check that it returns the original one-year payment.

**Check your result.** The one-year discounted value is £100 in this exercise.
