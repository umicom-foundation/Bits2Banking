# Keep arithmetic out of the screen

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Two application screens display the same practice total of 430 cents.

1. Draw one box for the calculation and one for each screen. Put the amount and status on each connection.
2. Change the mark-up of one screen. List the results that should remain identical between screens.

**Check your result.** The shared calculation still yields 430 cents for both. Only the chosen presentation changes.
