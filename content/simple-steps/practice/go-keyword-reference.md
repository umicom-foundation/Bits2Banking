# Check one loop and its stopping point

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice slice contains 2, 4 and 7.

1. Use the course loop shape to list the visits by index and value.
2. Stop the loop just before the value 7. Add only the values visited before that stop.

**Check your result.** The first two visits add to 6. The final entry does not contribute.
