# Check a conversion with a clear unit

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice entry reads 72.125 kilograms.

1. Write the whole part and the fractional grams. Use the course parser example to check the combined integer.
2. Try one invalid suffix in a practice copy. Check that a refused input leaves the prior accepted value available.

**Check your result.** 72.125 kilograms becomes 72,125 grams. The invalid suffix has a refusal instead of a replacement value.
