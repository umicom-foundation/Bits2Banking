# Build a small filtered list

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local statement array has three entries. Two are posted and one is pending.

1. Use the course’s list filter example to select posted entries. Keep a note of the original array length.
2. Run the filter again for pending entries and check both the returned length and original length.

**Check your result.** The filtered lengths are 2 and 1. The original array still has three entries.
