# Keep a setting out of the native rule

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A lesson configuration names a local library and supplies a bounded practice input.

1. Record which setting chooses the library. Find which part of the native function checks the input.
2. Trace a copy that changes the library location while keeping the input the same. Record the two kinds of result separately.

**Check your result.** Location controls whether the library can open. The native input rule applies after the example makes a call.
