# Trace a required result through two inputs

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A lesson function accepts a bounded unsigned input and reports an explicit error when a value is outside the exercise’s range.

1. Copy the permitted range. Choose one value inside it and one value just outside it.
2. Use the example’s return type and error handling to write each outcome. Check the returned result or refusal in both cases.

**Check your result.** The accepted input follows the result path. The other produces the exercise’s explicit error without a numeric result.
