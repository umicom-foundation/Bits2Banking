# Separate open, read and close results

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A local report file holds one line. A second example names a missing file.

1. Draw three boxes for opening, reading and closing. Mark what each stage needs from the previous stage.
2. Trace the present-file case, then stop the missing-file case at the stage that refuses it.

**Check your result.** The first case reaches read and close. The missing-file case stops at open and never produces a line.
