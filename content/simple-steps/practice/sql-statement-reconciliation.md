# Distinguish an empty group from zero

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

One practice account has movements of +40 and −40 cents. A second has no rows.

1. Use the guide’s summary pattern to calculate posted totals for both accounts. Write which account has a row in the summary.
2. Apply the lesson’s comparison query and preserve a separate marker for a missing total.

**Check your result.** The first account’s calculated total is zero. The second has no matching total unless the query deliberately supplies one.
