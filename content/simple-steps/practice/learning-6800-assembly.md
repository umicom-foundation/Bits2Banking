# Track a register through an addition

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

For a classroom trace, accumulator A initially contains 08 in hexadecimal and the next addition contributes 03.

1. Write the starting value and follow the accumulator exercise’s addition step.
2. Write the result in hexadecimal and decimal. Trace it into the course’s next stored value.

**Check your result.** 08 plus 03 gives 0B in hexadecimal, which is 11 in decimal.
