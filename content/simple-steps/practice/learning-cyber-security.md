# Map where a notes app needs a check

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

An imaginary notes program imports a file chosen by a user.

1. Draw the file picker, validation step and destination store. Mark which stage receives outside data.
2. Write a defensive check for preserving the current record and state what the user should see if admission fails.

**Check your result.** Your diagram shows that validation runs before a write and that refusal leaves the existing record available.
