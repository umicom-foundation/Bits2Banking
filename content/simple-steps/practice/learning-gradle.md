# Locate the test output

![Umicom Foundation](../../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Use the course’s sample in an isolated checkout with the documented JDK.

1. Use its Gradle command to list the test result. Record whether the command succeeded and where the report appeared.
2. Make a local change to one expected result. Rerun the checks and read the first named failure in the report.

**Check your result.** The report identifies the changed case. A passing run names the same project and reports a successful result.
