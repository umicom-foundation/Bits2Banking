# Keep the unit with a time conversion

![Umicom Foundation](../../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

A practice alarm begins in 11 minutes.

1. Use the course variable and `Print` examples to show the time in seconds. Write a unit next to the expected result.
2. Change the minutes to 12, save, then run the same example again.

**Check your result.** The results are 660 seconds and 720 seconds.
