# Bits2Banking video scripts

Video scripts belong in `content/videos/scripts/<course>/<lesson>.md`, matching the `content/videos` folder already in the repository.

These are written presenter scripts with scene timings, visual directions and references. They are **not** videos or voice recordings. Each script can be used by a human presenter, Umicom AuthorEngine or a future approved native media toolchain. Keep on-screen equations aligned with the HTML and Markdown lessons.
