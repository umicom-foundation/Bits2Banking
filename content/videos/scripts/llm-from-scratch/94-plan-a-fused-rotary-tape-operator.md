# Video Script — Planning optimisation without losing correctness

**Series:** Bits2Banking | **Author:** Sammy Hegab | **Format:** narrator + visual storyboard | **Recording status:** script only (no video produced)

## Intended audience
Newcomers from any background. Explain all mathematical symbols before displaying a full formula. Use clear UK English. Do not use childish greetings or irrelevant demonstrations.

## Script and on-screen direction
Opening [0:00–0:40] — Compare a three-step physical production line with two possible software computation graphs. Explain “fusion” as reducing intermediate work, not changing the numerical result.

Mathematics [0:40–2:50] — Rotate [1,0] by 90 degrees to get [0,1]. Explain transpose as reversing the rotation on an incoming gradient. Show both axes and label all quantities. Stop to define the chain rule.

Architecture [2:50–4:30] — Show Framework tape as sole allocation owner and rotary primitive as shared mathematical service. Talk through failure atomicity, memory budget and preserving the old implementation for audit.

Review [4:30–5:40] — Work a purely hypothetical allocation example: 600 bytes to 400 bytes saves 200 bytes or about 33.3%. State clearly that no performance result has yet been measured. On-screen links: Maths Unit 20 and LLM Lesson 94.

## Production notes
Use captions, high-contrast readable fonts, pauses after each numerical step and a static summary card. All examples use the same verified arithmetic as the companion HTML and Markdown lesson.
