# Video narration and storyboard — Every vocabulary logit matters

**Bits to Banking · Umicom Foundation**  
**Author:** Sammy Hegab · **Format:** Educational narration with screen directions.

## Learning objective

Why matching generated IDs cannot prove numeric equivalence, and why nonfinite values invalidate the test.

## Scene 1 — Define the question

**Visual:** Course title over the canonical Transformer and K/V store. Display one fixed checkpoint digest icon, a prompt and an unchanged context length.

**Narration:** "A useful result begins with identical inputs and a known mathematical reference. We are testing which numbers remain the same, and precisely when those numbers are permitted to change."

## Scene 2 — Work the example

**Visual:** Show two three-token logit vectors that share an argmax but not probabilities. Animate a 260-column comparison table, highlight a mismatching column, then display the declared absolute-plus-relative threshold. Move from tensor mathematics to the native `UmiAiTrainingInferenceParityCompare` diagnostic.

**Narration:** "The visible steps can be repeated with ordinary arithmetic and arrays. Each reported value has a unit: a token position, a float element, a byte count, or a time interval. Those are different kinds of evidence."

## Scene 3 — Connect to native C23

**Visual:** Show the Framework public C ABI beside a course Markdown file. Draw arrows from the canonical model and the incremental candidate to the comparison report.

**Narration:** "The implementation belongs to Umicom Framework. The course explains the public contract and provides an exercise, but does not introduce a second hidden model or substitute a Python calculation for the native code."

## Scene 4 — Learner check

**Visual:** Pause on a question card: "What does this result prove, and what does it not prove?" Then reveal a clear distinction between numeric parity, cache ownership and elapsed-time measurement.

**Narration:** "A complete engineering explanation includes evidence and its limitations. A smaller operation count alone is not a latency benchmark."

## Closing recap
