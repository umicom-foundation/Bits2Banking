# Federated jobs and immutable identities

**Bits2Banking video narration and storyboard · Sammy Hegab · Umicom Foundation**

## Learning outcome

Explain the demonstrated concept using synthetic data and reproduce the numerical example. No illustrated screen is evidence of an implemented remote training network.

## Narration timeline

00:00–00:50: Draw the base checkpoint and three independent dataset shards. Explain that training changes weights but admission only records task permission.

00:50–02:30: Show a worker ticket with job ID, serial and slot. Explain the difference between a process-local ticket and a digital signature.

02:30–04:00: Calculate 50 KiB+50 KiB>96 KiB and demonstrate the reservation release after completion.

04:00–05:00: Ask the viewer what must be verified before a bank dataset can be used. Reveal that a SHA-256 value alone is not a licence.

## Visual description and accessibility

Provide a caption for every on-screen equation and a transcript for each narration segment. Avoid colour-only distinctions between an accepted and a rejected worker. Clearly label any hardware/network metrics as illustrative unless they come from independent measurements.
