# Video storyboard — Organising lessons as verified knowledge

**Umicom Foundation · Bits2Banking**  
**Narration:** professional UK English · **Duration:** approximately 8–10 minutes  
**Status:** script only; not recorded or model-generated training material

## Scene 1 — Why location matters (0:00–1:20)

**On screen:** a clean directory view containing `content/courses`,
`content/lessons` and `content/videos/scripts`.

**Narration:** “An article can be published in several formats. We need one
clear home for each type, so the same lesson can be read, presented and taught
without accidentally creating competing sources.”

## Scene 2 — One concept, several formats (1:20–3:10)

**On screen:** connect lesson ID `btb:llm:093` to the Markdown manuscript,
its HTML course page and the video narration. Trace the exact relative
paths; do not present these files as interchangeable copies.

**Narration:** “The identifier represents a concept. A file path represents
one presentation. When we update the content, we review every representation
that depends on the source.”

## Scene 3 — A catalogue is not a proof (3:10–4:50)

**On screen:** show a 94-lesson catalogue with simple green ticks indicating
files found, and separate grey indicators for `not reviewed` and
`training permission not assessed`.

**Narration:** “A successful structural check means the expected page exists.
It does not prove the mathematics, the educational accuracy, or the legal
permission to train an AI model on that page.”

## Scene 4 — How RAG differs from model training (4:50–7:30)

**On screen:** two paths from approved evidence. Path A: index, retrieve,
cite, answer. Path B: rights review, curate, partition, train, evaluate.

**Narration:** “Retrieval-augmented generation finds evidence when a question
is asked. Model training changes weights. We should never mistake a readable
source for an approved training dataset.”

## Scene 5 — Practical review (7:30–9:30)

**On screen:** open the complete HTML catalogue, Lesson 93 and its existing
Markdown and video companions; show `training_permission: not_assessed`.

Ask viewers to explain which documents they would need before approving a
source for a future training run. Link the supplementary written lesson and
the Framework Knowledge Centre contract.

## Production and accessibility notes

Use readable 16:9 captions, accurate visible paths, steady motion and plain
numbered steps. There is no live network dependence and no invented test
outcome. Existing author credits and diagrams remain unchanged.
