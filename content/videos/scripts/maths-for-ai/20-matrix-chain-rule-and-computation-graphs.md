# Video Script — The chain rule without advanced mathematics

**Series:** Bits2Banking | **Author:** Sammy Hegab | **Format:** narrator + visual storyboard | **Recording status:** script only (no video produced)

## Intended audience
Newcomers from any background. Explain all mathematical symbols before displaying a full formula. Use clear UK English. Do not use childish greetings or irrelevant demonstrations.

## Script and on-screen direction
Opening [0:00–0:40] — Start with w=3 and two cards: double it, then square the result.

Calculation [0:40–2:40] — w=3, u=2×3=6, L=6²=36. Define every letter. Explain the two rates of change dL/du=2u=12 and du/dw=2. Multiply to get dL/dw=24.

Application [2:40–4:20] — Connect this simple graph to Q/K weight projection and reverse-mode automatic differentiation without introducing an unexplained tensor formula.

Review [4:20–5:00] — Learner repeats with w=2 and checks gradient 16. Link to Maths Unit 20 and LLM Lesson 94.

## Production notes
Use captions, high-contrast readable fonts, pauses after each numerical step and a static summary card. All examples use the same verified arithmetic as the companion HTML and Markdown lesson.
