# Video Script — How close is close enough?

**Series:** Bits2Banking | **Author:** Sammy Hegab | **Format:** narrator + visual storyboard | **Recording status:** script only (no video produced)

## Intended audience
Newcomers from any background. Explain all mathematical symbols before displaying a full formula. Use clear UK English. Do not use childish greetings or irrelevant demonstrations.

## Script and on-screen direction
Opening [0:00–0:30] — A simple currency reconciliation: £10.004 against £10.000, explaining that these are illustrative analytical values, not valid payable currency amounts.

Calculation [0:30–2:30] — Subtract and take absolute value, giving 0.004. Explain symbols a, b, atol, rtol and ≤ one at a time.

Example [2:30–3:40] — Compute allowable combined difference 0.001 + 0.001×10 = 0.011. Compare error 0.004 and limit 0.011.

Review [3:40–4:20] — Invite viewers to explain why a failed test threshold must not be raised just to obtain a pass. Link to Maths Unit 19 and LLM Lesson 93.

## Production notes
Use captions, high-contrast readable fonts, pauses after each numerical step and a static summary card. All examples use the same verified arithmetic as the companion HTML and Markdown lesson.
