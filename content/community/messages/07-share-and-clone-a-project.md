# Share a practice project and clone it

Before sharing, type -> git ls-files
Read that list. Only publish files you intend to share.
For your own practice project, replace YOUR-ACCOUNT in -> gh repo create YOUR-ACCOUNT/notes-practice --private --source . --remote origin --push
This command creates the online repository and uploads commits.
