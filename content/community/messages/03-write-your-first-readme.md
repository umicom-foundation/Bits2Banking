# Write and read your first Markdown file

Next we will create a small note. In a new practice folder, type -> Test-Path .\README.md
If it says False, type -> Set-Content .\README.md "# My first notes"
Read it with -> Get-Content .\README.md
Set-Content replaces text. Add-Content adds text at the end.
