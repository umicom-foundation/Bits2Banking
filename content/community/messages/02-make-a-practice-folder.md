# Make a folder for your practice work

Let us choose a place for the exercises. Type -> Set-Location $env:USERPROFILE
Then -> New-Item -ItemType Directory -Path "Umicom-Practice"
Enter it with -> Set-Location "Umicom-Practice"
Check your place with -> Get-Location
