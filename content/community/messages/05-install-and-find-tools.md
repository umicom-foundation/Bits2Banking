# Install and find your everyday tools

Before installing again, check what you already have. Type -> Get-Command pwsh, git, gh -ErrorAction SilentlyContinue
For a missing Git installation, use -> winget install --id Git.Git --exact --source winget
After installation, open a fresh PowerShell window and type -> git --version
