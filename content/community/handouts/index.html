Your first development steps

Let us start with one small task at a time. You do not need programming experience. The first step is opening a terminal and finding your current folder. Each lesson explains what to type, what the command means and what you should see.

Work in a practice folder you choose. Stop and check the result before moving on. If something is unfamiliar, use the explanation on the same page; the related courses are there when you want more detail. Existing courses and lessons remain available.

  1. Open PowerShell and find your place
    Open a terminal, identify the shell and find the folder it is using.
  2. Make a folder for your practice work
    Create a practice folder and move into it without touching product source.
  3. Write and read your first Markdown file
    Create a README, add a sentence and open it in a text editor.
  4. Copy, rename and preview a deletion
    Keep a practice copy and understand what a file command will change.
  5. Install and find your everyday tools
    Check PowerShell, Git, GitHub CLI and an editor without installing duplicates.
  6. Record two versions with Git
    Create a local repository, inspect a change and record two commits.
  7. Share a practice project and clone it
    Publish your own practice repository deliberately, then download a separate copy.
  8. Set up the Windows C toolchain
    Use one consistent compiler, build system and library environment.
  9. Write, compile and run a C program
    Turn a small C source file into an executable and recognise each step.
  10. Build and test a small notes project
    Separate reusable C behaviour from its caller and test the boundary.
  11. Follow a button into Umicom Framework
    Trace a real desktop action from its button to the shared Framework function and its regression test.
  12. Read a build log and choose the next step
    Tell configuration, compilation and test failures apart and keep evidence of the first useful diagnostic.
