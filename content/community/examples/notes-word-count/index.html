Build and test the project, one step at a time

Build the copy in your practice folder

  1. Open PowerShell in the copied project folder. It should contain CMakeLists.txt and the include, src and tests directories.
  2. Make the UCRT64 tools available on the command search path. Run each command separately. Stop at the first nonzero exit code.
$env:Path = "C:\msys64\ucrt64\bin;$env:Path"
cmake -S . -B build -G Ninja
cmake --build build
ctest --test-dir build --output-on-failure --no-tests=error
.\build\notes-word-count.exe

CTest should show two passing tests. The program should print Words: 4. On Linux, use the same configure, build and test commands with GCC, CMake and Ninja. Run ./build/notes-word-count from the copied practice folder.

Read the counting rule

The C function borrows a string. Space, tab, carriage return, line feed, form feed and vertical tab mark word boundaries. A null pointer returns zero. The unit test exercises that rule and the console test verifies the displayed result.
