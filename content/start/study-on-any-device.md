# Study Bits2Banking on any device

![Umicom Foundation](../assets/branding/umicom-wordmark.svg){ .umicom-wordmark .umicom-wordmark-light width="215" }
![Umicom Foundation](../assets/branding/umicom-wordmark-on-dark.svg){ .umicom-wordmark .umicom-wordmark-dark width="215" }

Choose a course, open its quick guide and work through one small example. Use the course title and lesson heading to find the same place on another device.

## Open the lesson

| Where you are studying | How to find your place |
| --- | --- |
| Computer or mobile browser | Open [Bits2Banking on GitHub Pages](https://umicom-foundation.github.io/Bits2Banking/). Use the menu or search to find the course title. **Learning in Simple Steps** has short instructions you can use beside the full course. |
| Bits2Banking desktop reader | Follow the [offline reader guide](../umicom/bits2banking-desktop-reader.md). Load the manifest from the same release as its lesson files. Pick the course guide and then the lesson title. |
| Another Bits2Banking website | Check the release provided by that host and look up the same course title. A host can serve the same published reading files from its own address. |

Start with the [technology topic map](technology-topic-map.md) to choose a subject, [Learning in Simple Steps](../simple-steps/index.md) to follow one task, or the [contributor wiki](../wiki/index.md) to find product documentation. These links open the learning source you can browse on a phone or a computer.

To read this overview, the topic map, the guide catalogue and the course-maintenance wiki offline, load `learning-packs/study-on-any-device.json` from the library folder.

## Choose how to do an exercise

1. Open [Practise a small example](../practice/index.md). Check the requirements beside the exercise before you start.
2. For Bash and PowerShell practice, read the result you should see, run one command, then change one input. The written steps remain available when the interactive module cannot load.
3. For exercises that need a compiler or Umicom’s configured local host, read the lesson on the device you have. Keep the example and its expected result so you can run it later on a computer with those tools.
4. When you change devices, write down the course title, lesson heading and last step. If a file is missing from an offline pack, use the equivalent web lesson or open the complete pack for that release.

A desktop pack verifies its own lesson files. The browser supplies the controls for browser-specific exercises. A future phone app can select the same lesson paths through the catalogue once that reader is available.
