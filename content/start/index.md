# Start here

## New to computers? Start before the technical chapters

[Computing from the Beginning](../lessons/00-getting-started/index.md) assumes no computing knowledge. Eight lessons explain following a course, input and output, files, memory, instructions, commands and system layers. Paper activities are enough to begin.

[Find connected learning routes](systems-learning.md) links these foundations to existing lessons and the OS and Kernel courses.


A computer programme is a set of instructions that a computer can follow. You will learn to understand those instructions, write them, check that they work and use them to build useful applications.

## Start with the computer

Begin with [Inside a computer](../lessons/01-computers/01-inside-a-computer.md). Learn what the processor, memory and storage do. Then explore [binary information](../lessons/01-computers/02-bits-and-logic.md) and how the [CPU executes instructions](../lessons/01-computers/03-cpu-and-memory.md).

## Learn programming

Follow the [programming chapters](../lessons/02-programming/index.md) to learn how to describe a task as instructions and test the result. Continue into [Assembly, C, C++ and Java](../lessons/03-native-code/index.md), or explore [web development](../lessons/04-web/index.md).

## Build and work with others

When you are familiar with files and commands, study [Git and software engineering](../lessons/05-engineering/index.md). You can then [prepare a development computer](../lessons/06-umicom/24-development-setup.md) and [build with Umicom Framework](../lessons/06-umicom/25-use-the-framework.md).

## Continue into other subjects

The [business and financial lessons](../lessons/07-practical-domains/index.md) explain project management, accounts, accounting, treasury and trading. No financial account or live trade is needed; the examples use simulated data.

A chapter is complete when you can explain the main idea and carry out its exercise, including understanding the result when something does not work.

## Explore purpose, faith and ethics

You can also read [Islam: Blueprint for Life](../v001_islam_blueprint_for_life/index.md). It connects the Islamic understanding of purpose, responsibility and fairness with trade, modern banking and the use of technology for society. The chapters are available as a separate book, so you may begin there or with the computing lessons.

## Follow the full learning roadmap

The [learning roadmap](../roadmap.md) links the practical Assembly, C23, build-engineering, web-server, Kernel and cross-language workshops. Begin with the computer chapters if machine instructions or memory are unfamiliar.
