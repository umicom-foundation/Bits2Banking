Pick a problem that sounds useful. You can read about any area in the list, then follow one local course or first lesson at your own pace. Start with [the connected learning paths](connected-learning.md) if you are new to files, programs or maths.

A course link opens a related set of lessons. **First lesson** opens a small exercise or a short course. **Foundation** points to nearby learning that builds the skills for this topic. **Planned** marks a topic whose own Bits2Banking lessons are still to come.

Use [Practise a small example](../practice/index.md) to find an exercise and see where it runs. The new practice courses teach a small set of tasks in depth. Use the course outline to see which topics you will cover.

## Choose a small Umicom project

1. Try the [native statement web lab](../umicom/native-statement-web-lab.md) to see a browser form ask Umicom WebServer for a number calculated with Umicom C. Read [Learning HTML](../courses/learning-html/index.html) first if a form is new to you.
2. Open the [Bits2Banking desktop reader guide](../umicom/bits2banking-desktop-reader.md) when you want to read the statement workshop in a native Framework application.
3. Follow [Framework development](../courses/umicom-development/index.html) after making a small program. Save a practice copy, change one rule and write down the result you expect before you run it.

Bits2Banking uses its own practice ideas. The subject map draws on the [W3Schools tutorials](https://www.w3schools.com/tutorials/), [reference index](https://www.w3schools.com/references/) and [certification topic list](https://campus.w3schools.com/collections/certifications).

The worked examples on this site follow a short practice cycle. Read the task, predict the result, run the example and try one change. The [W3Schools editor catalogue](https://www.w3schools.com/tryit/) illustrates how a lesson can put the example and result close together.
