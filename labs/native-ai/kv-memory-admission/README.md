# Native KV memory capacity laboratory

This lesson uses the authoritative Umicom Framework `UmiAiTrainingInferenceMemoryPlan` library; no duplicate local arithmetic implementation is supplied.

Read LLM Lessons 313–328 and Mathematics Units 185–196, then build the Framework's standalone laboratory at `learning/native-ai-inference-memory-plan`. Check the native unit test for the 24 MiB example, concurrent session budget rejection and an overflowing integer product. Raw KV payload is not peak resident memory and is not a performance measurement.
