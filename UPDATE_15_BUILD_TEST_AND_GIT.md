## Build Umicom Education — Windows UCRT64

```powershell
Set-Location "C:\umicom\Umicom-Applications"
$env:Path = "C:\msys64\ucrt64\bin;$env:Path"

cmake -S ".\framework\tools\umicom-education" `
    -B ".\build\umicom-education" `
    -G Ninja `
    -DCMAKE_C_COMPILER="C:\msys64\ucrt64\bin\gcc.exe" `
    -DBUILD_TESTING=ON

if ($LASTEXITCODE -ne 0) { throw "Education configuration failed." }

cmake --build ".\build\umicom-education" --parallel 2
if ($LASTEXITCODE -ne 0) { throw "Education compilation failed." }

ctest --test-dir ".\build\umicom-education" --output-on-failure
if ($LASTEXITCODE -ne 0) { throw "Education tests failed." }
```

Expect 22 CTest cases, including two new scheduler-trace tests. The earlier
20 native tests are retained. The Windows outcome must be observed rather than
assumed from the Linux qualification.

The new C23 command reads a safe synthetic fixture generated by CTest:

```powershell
$Education = ".\build\umicom-education\bin\umicom-education.exe"

& $Education schedule-trace --file `
    ".\build\umicom-education\education-schedule-trace-test\fixture with spaces\round robin.sch"

if ($LASTEXITCODE -ne 0) { throw "Schedule-trace inspection failed." }
```

It should begin `Scheduler trace: 11 records` and report two admissions,
four dispatches, one wait, one wake and two exits.

requires its Python interpreter to render the educational website.

```powershell

& $Python ".\tools\check_mkdocs_config.py" --syntax-only
```

`Test-Path` should return `True` before the local preview starts. The
existing ten *Islam: Blueprint for Life* chapters must remain in the navigation.
