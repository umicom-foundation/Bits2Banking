LLM from Scratch: Markdown manuscripts

This companion keeps the editable lesson manuscripts in a bounded native catalogue. The lesson files and their resource identifiers are preserved. The HTML course remains available through its original manifest.

  1. Use the complete Bits2Banking checkout as the library folder.
  2. Enter learning-packs/llm-from-scratch-manuscripts.json as the manifest path and load it.
  3. Open a manuscript from the list below. Reading source examples does not execute them.
  4. For the HTML lessons, select the separate learning-packs/llm-from-scratch.json pack. Links outside the currently selected pack can be refused by the native reader.

A checkpoint includes its pack identity, revision and resource identity. Existing checkpoints are retained; moving a manuscript to this companion does not automatically migrate its earlier progress record. Review that earlier record separately rather than marking the new entry completed without evidence.

The shared stylesheet, SVG wordmark, SVG icon and ICO are declared resources in both packs. Browser presentation and the native structured reader still require separate qualification.
